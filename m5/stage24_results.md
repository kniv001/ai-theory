## 模型

```
α 基因（食性偏好 0-1——可变异可遗传——初始 0.5±0.3 多样性）
目标价值 = 回报/距离 × 紧迫性 × 食性权重（植物×α / 生物×(1-α)）
专业化收益：吃植物效率 ×(0.5+α) / 吃生物效率 ×(1.5-α)（专业者高效——泛化者无收益）
繁殖变异：α ±10%——自然选择驱动
```

## 两个核心发现

### 发现 1：捕食冻结（食肉生态位无法涌现的条件）

```
体型单层化：所有生物趋同大体积（1.6——大 = 捕食优势 + 防御）
→ 小体型灭绝（无底层猎物）→ 捕食者无猎物
→ 食肉不可行 → 食草主导（α→1）
```

**真实生态的捕食者需要**：① 体型分层（小猎物层 + 大捕食层）② 或猎物密度波动
③ 或猎物逃跑行为——本模型缺这些 → 捕食冻结——**生态位分化不是自动的——
需要"底层的多样性"**（食物链 = 体型层级——单层 = 无捕食）

### 发现 2：进化 = 生存优势（exp4 强结果）

```
固定杂食（α=0.5）：灭绝（0）——泛化策略在中等资源下失败
进化组：存活 108——α 专业化（食草）→ 高效利用植物 → 繁殖 → 扩散
```

**"固定策略灭绝" = 进化价值的量化证明**——自然选择（α 漂移）vs 固定策略——
进化组存活、固定组灭绝——**用户实验的"AI 训练"核心结果**（进化训练出适应策略
vs 固定策略失败——框架外环的价值）。

生态位**没有自动涌现**（捕食冻结）——这本身是重要发现：**生态位分化需要
底层多样性（体型分层）**——单层体型 = 单生态位（食草）——真实生态的
食物链 = 体型层级结构（小→大）——**下一步（若继续）：体型分层收益
