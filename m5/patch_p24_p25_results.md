## P24：间隔优势 ∝ 间隔/半衰期比 ✅

| λ_s（软区衰减） | τ（半衰期） | 优势比（间隔 0.5→8 天） | 单调增 |
|---|---|---|---|
| 0.3 | 2.31d | 1.00 → 1.01 → 1.03 → 1.06 → **1.12** | ✅ |
| 0.5 | 1.39d | 1.00 → 1.01 → 1.03 → 1.06 → **1.13** | ✅ |
| 1.0 | 0.69d | 1.00 → 1.01 → 1.03 → 1.06 → **1.13** | ✅ |

**P24 兑现**：优势比随间隔/半衰期比**单调增**（三种 λ_s 一致——曲线不重叠 = 由比值决定非绝对值——C97"写回饱和"机制的定量确认）。

**新发现（不完善处深化）**：优势比上限仅 ~1.13（远低于真实实验 2x+）——
**缓存-写回模型的间隔优势有结构上限**——真实间隔效应的强度需要额外机制
（R42 重放的强化效应——重放 = 写回的放大器——待建模——记录为 R161 #3 深化）。

## P25：噪声-同步竞争 ✅

| K（临界区密扫） | 无噪声 r | 噪声 0.4 r | 衰减 |
|---|---|---|---|
| 0.45（临界下） | 0.34 | 0.34 | 0.00 |
| 0.50（临界） | 0.32 | 0.37 | −0.05 |
| **0.55（刚过临界）** | **0.53** | **0.48** | **0.05（全场最大）** |
| 0.60 | 0.56 | 0.60 | −0.04 |
| 0.70 | 0.73 | 0.71 | 0.02 |
| 0.80 | 0.86 | 0.85 | 0.01 |
| **1.50（强区）** | **0.97** | **0.97** | **0.00** |

**P25 兑现**：临界区最脆弱（K=0.55 噪声衰减全场最大）/ 强区完全鲁棒（0.00）——
**噪声 = 降低有效 K 的机制**（近临界最敏感——同步域参数域的噪声面完成）。

**诚实说明**：噪声的绝对破坏不大（≤0.05——同步 basin 大——加性噪声整体鲁棒——
与 stage1c exp4 的"超鲁棒"一致）——但**相对梯度成立**（临界 vs 强区）——
框架预测：**噪声敏感的窗口 = 临界区**（生物含义：噪声环境下湖的形成需要更强的
耦合——"嘈杂环境中的注意力要求更高"的机制面）。
