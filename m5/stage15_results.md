
## 调试发现（蛋的完整化的三个设计要点）

1. **外部信号 = 单一频率**（湖中心频率——非每单元 ω）——驱动组内同频 → 相位差 =
   签名结构（稳定）——**信号频率 = 湖的中心频率 = 共振的正确模型**（比 stage7 的
   "每单元 ω"更正确——修正了共振驱动）
2. **概念湖需强内聚**（K=2.0——1c 锁定区）——弱耦合（0.5）拉不回 ω 展宽漂移——
   **湖 = 强内聚结构**（概念识别的物理基础——弱耦合 = 无法维持绑定）
3. **联想传播需共振**（相位 = 目标湖 ω·t + W 相位——预测信号像驱动一样共振）——
   预测 = 共振注入（预测信号与目标湖共振 = "预激活"——R1 预测的物理实现）
