## 模型

```
关系层扩展：isa/attr/act + cause（第四河道）
K_cause 方向性：因果句（"因为A所以B"）→ 前件 A → 后件 B 方向沉积（A 是 B 的原因）
  ——因果方向 = 河道方向（R2 预测河下行——"为什么B？" = 沿河道上行检索 A）
属性补充：attr 句 29→91（"苹果很甜""天很蓝"——补 stage40 短板）
```

## 意义

1. **因果 = 有方向的河道**（R2 验证）：不是无类型关联——A→B 与 B→A 明确不对称——"因为下雨所以带伞"的因果结构进入河道方向
2. **"为什么" = 沿河道上行检索**（C74-01 机制化）：问"为什么B" → 查 K_cause 列（B 的原因集合）——**回答 = 检索到的结构（可审计）——不是生成式编造**——GOAL 红线"可解释"的语言层兑现
3. **属性河道成形**（attr 6 湖——甜/圆/软 属性词湖）——isa/attr/act/cause 四河道齐备——语言内关系类型完整
4. 因果湖粗（模板字桥接）——"因为/所以"是所有因果句共享的结构词——模板层与内容层分离是后续（C20-02 模板槽位）
