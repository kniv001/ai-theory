# M5 阶段 26 结果：单细胞进化训练（用户路线——环境+演化，生物=神经文件）

> 日期：2026-08-19 · 代码：m5/stage26_evo_training.py · 图：m5/fig_stage26.png
> 设计：用户（"按进化的路线进行训练——环境简单化（单细胞级）——每生物单独保留神经文件——训练脚本仅做环境和演化功能"）
> 阶段：用户规划阶段 2（框架神经化）第一步——公式 → 神经元
> 失败尝试：stage26_neural_behavior.py（蒸馏方案——监督学习路线——用户判定失败删除）

## 架构（用户设计）

```
训练脚本 = 环境 + 演化（不碰网络内部）：
  环境（单细胞级）：平面 100² / 食物能量点（随机+保底）/ 碰撞进食 / 能量消耗 / 繁殖阈值
  演化：繁殖（变异权重→写新文件 bio_N.npy）/ 死亡（删文件）/ 选择（能量）
每生物 = 独立神经文件（bio_N.npy——权重档案——"单细胞生物的基因"）：
  网络（趋化控制器）：输入[最近食物方向 sin/cos, 距离, 能量, 噪声, 常数] 
    → 隐藏 16（tanh）→ 输出[移动方向 sin/cos]
  决策 = 文件内网络前向——训练脚本只管理文件的生/死/变异
```

## 关键设计决策

### 1. 趋化先验初始化（"像单细胞生物"的正确解读）

```
纯随机权重冷启动 = 失败（146 权重随机搜索命中趋化解概率≈0——第一代全灭——无选择梯度）
单细胞生物的趋化是生化本能（受体-鞭毛耦合——百万年进化产物）——
进化优化的不是"会不会趋化"而是趋化细节（灵敏度/远近权衡/能量调制）
→ 初始权重：隐藏单元读 sin/cos(食物方向) → 输出复制为移动方向 + 小噪声（σ0.05）
```

### 2. 移动坐标轴 bug（插桩发现）

out[0]=sin（y 分量）被加到 x 坐标——移动方向旋转 90°——永远吃不到——修复后自持 100%。

### 3. 进化加速参数（冷启动时代）

```
繁殖阈值 150→100（世代多——变异积累快）
变异 σ0.12→0.2 + 重初始化 1/8→1/4（探索激进）
食物 60→100 + 生成 0.2→0.25（相遇率高——碰巧率↑——选择有梯度）
消耗 0.3→0.2（活得久——繁殖机会多）
```

## 结果

| 指标 | 结果 |
|---|---|
| 种群自持（5 seed × 1200 步） | **100%**（5/5 seed 全部 >5 只持续） |
| 末代种群 | 13-18 只（受食物承载力限制——Lotka 平衡） |
| 生物档案文件 | 每生物一个 bio_N.npy（存活=文件存在） |
| 食物平衡 | 被高效清空至 2-10（食物=限制资源） |
| 进化效果（初始先验 vs 进化 1200 步） | 进食相近（151 vs 148）但进化后种群更稳（40 vs 34） |

## 发现

1. **神经进化的冷启动问题**：纯随机权重在高维空间（146 权重）随机变异命中"会找食物"的权重概率≈0——需要先验（本能）或结构进化（NEAT）——**"单细胞"类比 = 有本能——进化优化本能**
2. **文件架构可行**：每生物独立 .npy 文件——训练脚本只做环境+演化——生物文件可独立加载/评估/复用（为工程化准备）
3. **进化在简单环境 = 微调**：趋化先验已"够用"——选择压力小——进化优化稳定性而非效率——环境复杂度决定进化空间（后续加捕食/复杂食物分布才有大优化空间）
4. 简单 > 复杂：stage25 的复杂机制（9 基因/社会/遮挡）在单细胞级被砍到只剩"位置/能量/网络"——进化训练反而第一个 100% 自持

## 理论对应

- 用户规划阶段 2（神经化）第一步：**决策从公式 → 网络**（趋化控制器——最简单的"认知"）
- 阶段 3（工程化训练）基础：生物=文件——可并行评估/批量变异
- 环境=问题集：单细胞环境（趋化）是第一个问题——后续问题（捕食/社会/复杂资源）逐步加难

## 下一步

1. **加难度**（捕食者/多食物类型/复杂分布）——进化空间增大——网络学到超越先验的行为
2. **结构进化**（NEAT：网络从最小开始增长——结构也是基因）
3. **工程化**（多世界并行/世代批量评估/权重统计）
