## 模型（框架版词嵌入——不是查表向量，是动力学原语）

```
T_in：字 → 该字本征频率 ω 的振荡信号（驱动相位 = ω·t——共振才进入——stage7 发现）
  字身份 = 频率（ω_i 线性分布 0.5-4.0——200 字）
单元 = 复值振荡器（γ=0.8 泄漏 + ω 本征 + 驱动 D）
T_out：单元幅度读出 → 字识别（幅度最高 = 当前字）
关联：沉积-侵蚀（R5——dW/dt = ε·e·conj(z) − λW）——句内全对 + 距离衰减
语料：15 句正常简单语句（"今天天气很好"/"我喜欢学习"…——句间 5 步空窗）
```

## 关键调试（插桩驱动）

| 问题 | 根因 | 修复 |
|---|---|---|
| 识别 4/5（'民' 读出'气'） | γ=0.3 衰减太慢（13 步后残留 82%——前字干扰） | γ→0.8（快衰减——注入间隔干净） |
| 联想全空 [] | 语料短句 ≤8 字——滚动窗口（>8 才弹）**从未触发**——W 从未写入 | 句内全对沉积 + 距离衰减（相邻强/远弱） |
| 联想错误（学→展） | act 跨遍不清零——高频字膨胀 | act 每遍清零（窗口语义） |
| 侵蚀压过沉积 | 侵蚀每步 ×0.995^720≈0.03 | 侵蚀每遍一次（低频关联消退） |
| KeyError '习'/'科' | 字表截断（200 名后语料字被丢） | 语料字符集优先收录（_CORPUS_CHARS + _CHARS_RAW） |
| 超长字符串语法错误 | 200 字单行 | 分多行拼接 |

## 意义

1. **符号湖第一块砖落地**：真实文字（中文单字）→ 复值动力场——转导层打通——共振准入（stage7 发现）直接用于字符
2. **"字身份 = 频率"的可行规模**：200 字 × 频率空间（0.5-4.0 rad）——分离度 0.81——频率分辨率充足——3500 字需扩展频率范围/分层
3. **沉积-侵蚀从语料学关联**：正常简单语句 → 共现 W——"学→习"排名 1——**词级关联从数据涌现**（stage38 无监督湖涌现的前奏——目前签名预置（频率分配）——下一步：签名自组织）
4. **正常简单语句原则落实**（用户指示）：训练先建立在正常简单的语句上——语料由浅入深（后续加长句/复杂句）
