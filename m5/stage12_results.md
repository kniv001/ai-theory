# M5 阶段 12 结果：P31 元学习验证 — 习得先验 ≈ 进化先验（h₀ 可训练）

> 日期：2026-08-18 · 代码：m5/stage12_meta_learning.py · 图：m5/fig_stage12.png
> 理论对照：R168（h₀ 双层训练）/ C8 双环（进化 = 最慢训练）/ P31

## 设计

```
嵌套递归任务（开放段随机 → 闭合段逆序配对——远端依赖）
三学习者：
  无先验（bigram——纯统计）
  有 h₀（LIFO 预置——进化先验）
  元学习（从数据中学配对统计——习得先验——数据驱动的 LIFO）
```

## 结果（10 次重复）

| 学习者 | 准确率 | 与无先验比 |
|---|---|---|
| 无先验（bigram） | 0.328±0.013 | 基线 |
| 有 h₀（预置——进化） | 0.442±0.008 | +0.114 |
| **元学习（习得——数据驱动）** | **0.457±0.023** | **+0.129** |

**裁决：✓ P31 兑现**——元学习 > 无先验 ✓ + 元学习 ≈ h₀ ✓（0.457 vs 0.442——
习得先验与进化先验等价）——**h₀ 可训练——层级偏好从数据中习得——不必须进化预置**。

## 意义

**R168 的仿真确认**：先验可以是训练出来的（元学习——个体早期从嵌套输入中
习得配对结构——固化——用于新结构）——进化先验（h₀）与习得先验**功能等价**：

```
进化（百万年）训练出的偏好 ≈ 个体（早期）训练出的偏好
→ 先验 = 训练的时间尺度谱（R168 确认）
→ 强先天论再削弱：即使没有进化预置——早期经验也能"训练出"结构偏好
```

**框架的完整图景**：没有任何组件必须是"天生"的——进化给了基础倾向（h₀——
可能也是外环训练的）——早期经验可习得等价偏好（元学习）——**先验-经验
连续谱在仿真中兑现**。

## 不完善处（新）

1. 元学习者只学"配对统计"（简单先验形式）——更一般的"结构类型学习"
   （多类层级模板——深度偏好）未测
2. 元学习阶段与应用阶段分离（先学后用）——真实的"渐进元学习"（边学边固化）
   未建模
3. 与 stage11 的关系：stage11 的 h₀ 优势（0.049）在本阶段被元学习复制
   （0.129）——**偏好来源（进化 vs 习得）不影响功能——验证了两者等价**——
   但 stage12 的元学习优势大于 stage11 的 h₀ 优势（0.129 vs 0.049）——
   因为配对统计更精准（数据驱动 vs 通用 LIFO）——**习得先验甚至略优于通用
   进化先验**（针对性更强）——值得记录
