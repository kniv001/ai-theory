# M5 阶段 1a 结果：复值单元最小仿真

> 日期：2026-08-18 · 代码：m5/stage1a_complex_unit.py · 图：m5/fig_stage1a.png

## 结果摘要

| 实验 | 结果 | 判定 |
|---|---|---|
| **exp1 无驱动衰减** | 数值-解析最大误差 **5.9e-10**；幅度半衰期 1.386s（=ln2/γ ✓）；相位旋转 1.00Hz（=ω/2π ✓） | ✅ **C1-01 数学验证**（原语方程行为与解析解精确一致） |
| **exp2 脉冲驱动（RPE 式）** | 三次脉冲均产生响应（峰值 0.227/0.189/0.191——幅度被推离零点）→ 脉冲后按 γ 衰减恢复 | ✅ **R8 脉冲价值信号的动力学**（误差/价值脉冲 → 状态更新 → 泄漏恢复——短暂价值信号与 C6-03 活动状态一致） |
| **exp3 双单元耦合锁定** | K=0 漂移（1.885 rad/s = 频率差 0.3Hz ✓）→ K=0.5 近临界 → **K≥1.0 锁定**（相位差斜率≈0）——临界 K∈(0.5,1.0)；锁定相位差随 K 增大趋同（1.23→0.24 rad） | ✅ **C5-02 机制验证**（相位锁定涌现 + 临界耦合 = 湖形成条件——与 Kuramoto 理论一致：临界耦合 ∝ 频率失谐） |
| **exp4 耦合延迟 → 相位差** | 双向对称延迟 0.3 rad → 稳态相位差 **0.150 rad = 0.3/2**（对称双向各贡献一半——理论一致） | ✅ **C1-03 相位 = 延迟载体初步验证**（W 相位编码传导延迟——单向耦合 → 全延迟可 M5 后续测） |
