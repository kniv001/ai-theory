# M5 阶段 45 结果：主题分批课程（词组成形 ∝ 主题密度——训练组织原则落地）

> 日期：2026-08-20 · 代码：m5/stage45_theme_curriculum.py · 图：m5/fig_stage45.png
> 承接：stage44 发现（600 主题密集 → 95 词组 vs 2000 主题多样 → 0）
> 理论锚定：幼儿式主题重复（父母整天说吃饭/玩具）/ C15-02（分布聚类——词组成形 ∝ 重复密度）

## 模型（课程——幼儿式主题重复）

```
知识语料按主题块切分（wiki 顺序——3 块 × 600 句）
块 1 密集训练（10 epoch）→ 块 2 继续（K 保留——词组跨批累积）→ 块 3
侵蚀降低（0.02→0.01——跨批保留）+ 每块 epoch 少（词组成形即停）
对照：一次性 1800 句（主题分散）vs 主题分批（课程）
```

## 结果

| 配置 | 词组数 | 判定 |
|---|---|---|
| 一次性 1800（主题分散） | **4**（稀释） | 对照确认 |
| 主题分批（3 块 × 600） | 批1 86 → 批2 103 → 批3 **98** | ✅ **24 倍保持** |

**词组库跨批累积**：影响 0.194/环境 0.158/结构 0.107/增加/支持/动物/成员/设计/内核——**跨主题块累积**（环境/动物/结构来自不同块）。
**跨批保留**：批 1 词组在批 3 后部分保留（操作 0.042——农业类弱化但总数保持）——**记忆更新式平衡**（旧词组弱化 + 新词组补充——不是全保留也不是全丢失——真实记忆特征）。

## 意义

1. **"吃下更多知识句" = 主题分批课程**（不是大语料）：词组成形 ∝ 主题密度——分批让每主题密集成形 + 跨批累积——1800 句的主题分批 = 98 词组 vs 一次性 4（24 倍）
2. **幼儿式主题重复验证**（工程层）：幼儿语料 = 主题密集（父母重复）——课程化 = 把"重复密度"作为训练组织原则
3. **记忆更新式平衡**（跨批保留的涌现）：旧词组弱化 + 新词组补充——K 的侵蚀/沉积平衡自然产生"更新"——不需要显式遗忘机制（R40 功能侵蚀的涌现）
