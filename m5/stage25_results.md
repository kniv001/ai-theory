```

捕食能量 = 3.0×猎物体积×猎物饱食度×肉类转换度（能量流守恒：植物→猎物→捕食者）
```

## 核心发现

### 发现 1：捕食链涌现的完整条件链（stage24→25 的每次失败都是一环）

```
① 植物保底（pezzza：外生补充）→ 植物不灭绝（否则全灭）
② 捕食=突袭+冲刺（Wilson）：冲刺距离 ≥ 移动步长（否则离散化漏窗——永远无法发动）
③ 追逐=加速度决胜：追速 = speed+accel（否则与猎物同速——flee 后追不回）
④ 追猎锁定：价值×3 持续追一只（否则每帧换目标——距离永不收敛）
⑤ 猎物反应延迟：冲刺用本帧距离判定（否则 flee 同帧抢先——竞态死锁）
⑥ 转换度保底：食肉者吃草饿不死（否则 α 低者活不到捕食条件——鸡生蛋死锁）
⑦ 风险调整 ×p_success：杂食者成功率低→追猎价值低→不追（否则全体互相捕食——崩溃）
⑧ 追逐燃能 0.6/步：失败追逐的机会成本（业余者追不起）
⑨ 偶发大突变 3%：捕食者灭绝后低 α 种子重注入（否则基因库丢失——生态位永不恢复）
⑩ 空间密度对齐 pezzza：120 只/200×200（否则相遇率不足——捕食频率为 0）
```

**每一步都是插桩数据驱动的修复**（不脑内推理——统计打脸就改）——从"捕食 0 发生"到"69% 存活"。

### 发现 2：能量流守恒 = 捕食链的货币

捕食能量 = 3.0 × 猎物体积 × 猎物饱食度 × 肉类转换度——**猎物吃的植物变成它的饱食度，捕食者吃掉猎物获得这些能量**——能量在链中传递（植物→食草→食肉）——金字塔结构由能量损耗自然涌现（食肉者 2-6 只 vs 食草 20-60 只）。

### 发现 3：体积三参数分解（用户设计决策）

用户指出"体积没有现实对应"→ 分解为 **mass（代谢/防御/速度/能量包）+ storage（饱食上限——耐饿）+ intake（单次摄入）**——每个参数有真实生物学对应（体重/脂肪储备/消化能力）。

### 发现 4：体型分层弱涌现（生态学解释）

食草体积 0.31-0.61 波动未稳定大于食肉——**大体积防御收益（p_success 惩罚）与代谢成本（0.35m/步）在平衡点附近**——捕食压力中等时小体积（省能+灵活）不落下风。真实生态：体型分层需要强捕食压力或资源分层——本模型捕食压力（69% 存活）中等——分层是弱趋势。这是生态学正确的结果（不是 bug）——记录为发现。

## 感知二维化 + 遮挡（R122 补——用户："参数细分" + "加入遮挡"）

### 模型改动

```
感知二维化：视野距离基因 vision_g（0.7-1.3 × 30 格）+ 视野角基因 fov_g（0.6-1.5 × 120°）
  独立变异遗传——远视窄角（伏击捕食者）vs 广角近视（防御觅食）可涌现
遮挡：视线 a→b 连线上的第三个对象（生物/植物——垂直距离 < 2 且投影在线段内）= 挡住
  ① 植物目标：被挡不可见（不写记忆）——草丛挡食物
  ② 捕食目标：被挡看不见猎物——捕食失败
  ③ 威胁检测（flee）：猎物被植物挡住看不见捕食者 = 突袭窗口
  ——遮挡让伏击成为真实通道（捕食者藏草丛接近——猎物反应不及）
```

### 结果（5 seed × 1200 步）

| seed | 食肉存活 | 食草存活 | 捕食者峰值 |
|---|---|---|---|
| 0 | 26% | 100% | 8 |
| 1 | **100%** | 100% | 13 |
| 2 | 79% | 81% | 10 |
| 3 | 59% | 61% | 5 |
| 4 | 82% | 100% | 7 |
| **平均** | **69%** | 88% | — |

主判定（3 seed × 600 步）：**食肉 88%（peak 12）/ 食草 100% = ✓ 捕食链自持**。
对比：二维食性仅 47% → 加遮挡 69%——**遮挡是捕食链增强的关键机制**（伏击可行 + 觅食竞争加剧）。

### 发现

1. **遮挡 = 突袭通道**：猎物被植物挡住看不见逼近的捕食者——flee 失效窗口——伏击成功率上升——捕食者收益大增
2. **遮挡 = 觅食障碍**：植物互相遮挡——觅食效率降——食物竞争加剧——肉偏好者转向捕食的动机更强
3. **感知形态分化**：vision_g/fov_g 独立进化——远视窄角伏击型 vs 广角近视防御型有涌现空间（观察中）
4. 性能代价：遮挡检查（点到线段距离）每步 ~38ms——可接受

## 巡航/极速拆分（R122 补——决策维度 +1）

```
cruise_g / sprint_g 独立基因（0.7-1.3/0.85-1.3——变异遗传）：
  巡航速度 = tradeoff(mass)×(0.8+0.3×cruise_g)——日常觅食/迁移（低能耗）
  极速 = max_speed(mass,accel)×sprint_g——逃跑（flee 用 sprint）/追猎（chase=sprint+accel）
  逃跑燃能去除（0.1 也缩水捕食回报——能量流守恒传导——机会成本已够）
  sprint_g 大突变 5%±0.3（高极速种子快涌现）+ 下限 0.85（0.7 时捕食者追不上）
```

### 结果

主判定（3 seed × 600 步）：**食肉 68%（peak 8）/ 食草 100% = ✓ 捕食链自持**。
多 seed 平均 56%（6-95%）——比拆分前（84%）弱——**军备竞赛代价**。
意外收获：exp2 体型分层 ✓（食草 0.48 > 食肉 0.31——狮子-牛模式——巡航拆分让食草变大）。

### 发现：逃跑军备竞赛（捕食链弱化的生态学解释）

```
猎物 flee 用极速——逃跑速度是猎物最直接的防御（选择压力最大——每只猎物都被吃威胁）
→ 猎物 sprint_g 进化快（单基因——收益直接）
捕食者要 sprint+accel 双高（追速=sprint+accel）——两基因耦合——进化慢
→ 不对称军备竞赛：防御性状（逃跑速度）进化快于捕食性状（追猎速度）
→ 捕食链天然弱于拆分前（固定 trade-off 时无军备竞赛）
```

**真实生态学对应**：猎物-捕食者军备竞赛中防御性状通常进化更快（红皇后效应）——捕食者靠爆发（加速度）和数量/协作弥补——模型复现了这种不对称。尝试 accel 加成 1.5 打破竞赛 → 捕食过猛（食草崩 47%）——1.0 是平衡点。

## 社会层（文化环 R27——用户："群居要补充社会层"）

### 模型改动

```
社会层 = 文化环落地（进化环 ✓ 基因 / 文化环 ✓ 本机制 / 个体环 ✓ 决策）：
  同类识别：α_p/α_m 欧氏距离 < 0.35 且空间距离 < 15 = 群成员（同生态位 = 社会认同）
  ① 食物信号：看到植物 → 广播给近邻同类（同伴记忆写回——"那边有吃的"——群体觅食效率↑）
  ② 警报传播：群成员 flee → 近邻同类恐慌（即使没看到捕食者——羊群效应——
     恐慌方向 = 远离警报者——群体级威胁感知——突袭难度↑）
  ③ 空间聚合：不显式做（共享食物记忆自然让同类聚向同一资源区）
```

### 结果

主判定（3 seed × 600 步）：**食肉 86%（peak 8）/ 食草 100% = ✓ 捕食链自持**——双生态位 ✓（食草 31 + 食肉 3）。
多 seed 平均 **71%**（22-100%）——比军备竞赛低谷（56%）大幅恢复。

### 发现：文化环 = 军备竞赛的解药

```
社会层对抗军备竞赛（红皇后）：
  食物信号 → 群体觅食效率↑ → 食草者更容易吃饱 → 繁殖↑ → 猎物基数↑ → 捕食者食物多
  警报传播 → 突袭成功率↓（猎物群体警觉）→ 捕食者被迫提高猎杀质量（大猎物）→ 体型分层
  → 双生态位更稳（食草 31 + 食肉 3——社会层让捕食链从 56% 回到 86%）
```

**理论对应**：ai-theory R27 三环——个体环（决策）无法独自解决军备竞赛（基因层对抗）——**文化环（信息共享）改变了博弈结构**（群体级信息让防御和觅食都规模化）——三环耦合的仿真证据。

## 生物如何思考？（用户问题——决策机制总览）

**答案：不是神经网络——是手工公式决策 + 基因进化调节。**

### 当前决策结构（个体环——决策环五层）

```
感知层：扇形视野（距离×角度基因×遮挡）→ 威胁检测（冲刺覆盖+社会警报）→ 空间记忆读取
评估层：目标价值 = 回报/d × 紧迫(1+2×(1-饱食/100)) × 锁定(×3) × 成功率 × (0.5+risk)
        回报 = 植物 16×转换(α_p)×intake(mass) 或 肉类 3.5×mass×satiety×转换(α_m)
选择层：每步选价值最高的目标（best 竞争）——flee 优先于觅食
执行层：巡航（觅食）/冲刺（逃跑）/追逐（追猎=极速+加速度——燃能）
反馈层：饱食度增减（吃/失败/消耗）——繁殖条件（>120）
```

**智能的位置**：决策公式是设计者写的（我们手工设计的机制）——9 个基因只是调节公式里的系数——进化改变系数但不改变公式结构。生物本身**不学习**（同情境→同反应——除随机数）。记忆=缓存（非学习）、社会层=广播（非学习）。
