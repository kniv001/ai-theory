# M5 阶段 32 结果：功能分化（阶段 D——体细胞/生殖细胞分工）

> 日期：2026-08-19 · 代码：m5/stage32_differentiation.py · 图：m5/fig_stage32.png
> 研究支撑：[Volvox 生殖-体细胞分化综述](https://www.sciencedirect.com/science/article/abs/pii/S1369527403001437)（glsA 体积决定命运/regA 抑制）· [PLOS Comput Biol 发育可塑性模型](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1000805)（基因抑制→分工快速涌现）· [Kirk 十二步程序](https://www.semanticscholar.org/paper/A-twelve-step-program-for-evolving-multicellularity-Kirk/8d72528287b972d3fb00c8b85cfdb6b0c03ea2f1)（体积递增序列）

## 模型（研究驱动的 5 项修正）

```
① 发育可塑性（PLOS 模型）：c（细胞命运）= 网络输出第 4 维——细胞根据环境实时决定命运
   ——不是基因硬编码——符合用户"神经=细胞"原则
② 体积决定命运（glsA）：s>1.05 直接=生殖细胞 / s<0.7=体细胞 / 中间=网络可塑
③ 不对称分裂 + 能量储备：子代能量 ∝ 体积（大子代多储备——撑过光合退化期——分化冷启动解）
④ regA 式抑制：体细胞繁殖阈值 110（牺牲繁殖——专职光合 ×1.8——利他代谢）
   生殖细胞阈值 34（快繁殖）+ 繁殖=释放新群体（-90% 能量——母体解散）
⑤ 群体生命周期：生殖细胞释放完整新群体（1 大生殖 + 2 伴生体细胞——出生即聚合分工）
   ——单个大细胞独立后光合退化饿死——群体断链——必须成套释放
```

## 结果（seed109——完整分化生命周期）

```
t=  0 生殖 13 / 体细胞 44 / 簇 3
t=250 生殖 21（繁殖！）/ 簇 29
t=500-2250 稳定 17 只：生殖 2 / 体细胞 10（+全能 5）——自持 100%
```

**分化稳定共存**：生殖细胞（被供养）+ 体细胞（专职光合）+ 全能（中间可塑）——三态共存——生命周期持续运行。

## 关键调试（插桩驱动）

| 问题 | 根因 | 修复 |
|---|---|---|
| 分化未涌现（全灭绝） | 能量共享零和（体细胞 1.2 被生殖 0.2 抵消） | 体细胞专职 ×1.8——分工乘法效应 |
| 生殖细胞比例失控 | 生殖无限并入本簇——全簇饿死 | 群体生命周期（释放新群体 + 母体解散） |
| 生殖细胞从未繁殖 | 能量卡 46.6 vs 阈值 58.9（插桩证实） | 阈值曲线 1.5-1.2c（34.4 < 46.6 ✓） |
| 新群体断链 | 单大细胞独立饿死 | 伴生体细胞成套释放 |
