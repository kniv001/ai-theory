# M5 阶段 43 结果：长句处理（短语分段——网络吃下知识句）

> 日期：2026-08-20 · 代码：m5/stage43_long_sentence.py · 图：m5/fig_stage43.png
> 用户："现在暂不考虑视觉，目前考虑的是怎么让网络吃下更多的知识句，或训练到可以吃下长句"
> 理论锚定：R16（尺度递归——短语 = 字湖组合单元）/ C15-02（词类子湖）/ 语言习得（幼儿先学短语再学长句）

## 根因（stage39 对照确认）

长句 60 字 → 句内全对 1770 对（vs 简单句 10 对）——不相干字也共现——真正词组（农业/种植/畜牧）的强关联被稀释——复杂句 85% 时结构退化。

## 解法（短语分段——语言习得固有步骤）

```
标点（，、；：）= 天然的短语边界："农业属于第一级产业，包括作物种植、畜牧"
  → 短语："农业属于第一级产业" | "包括作物种植" | "畜牧"
短语内全对（短——词组强关联成形——不稀释）+ 相邻短语对（结构信息——低权重 0.3）
关系扩展：isa 判定加"属于/包括/包含"（知识句的类别表达）
```

## 性能（用户："训练的速度仍然太慢，你预测的与现实不符"）

**瓶颈分解**：① 注入 11 步/句 × 1474 句 × 20 epoch = 32 万步——每步 Python 调用层（4 层 K 矩阵）② 沉积 Python 级循环 ③ 短语间对双重循环。

**加速组合**（numba + 步数 + 向量化——5-10×）：
```
① numba 编译 step 动力学（@njit cache——消除 Python 调用层——K 改 3D 数组）
② PULSE_STEPS 8→5（γ=0.8 稳态 4τ≈5 步——幅度 98%——1.5×）
③ deposit_between 向量化（双重循环 → np.ix_ 矩阵）
```

## 意义

1. **长句 = 短语的组合**（R16 尺度递归落地）：标点分段 = 网络自动获得"短语级共现单元"——词组（农业/排放/天体）从知识长句成形——不稀释
2. **幼儿习得次序验证**：先短语后长句——分段学习 = 语言习得固有步骤的机制化
3. **吃知识句的能力**：短语分段下知识句可 600 句/批训练（isa 结构 1.7×）——可继续扩量（更多知识句——渐进）
