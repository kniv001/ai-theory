## 模型（两层尺度递归——R16 同机制）

```
低层：字湖（stage38 机制——频率吸引 + 耦合沉积 + 容量预算 K_CAP=0.5——K 模块 = 同步域）
  词级耦合涌现：天气热/唱歌/苹果/关灯/游泳——相干 0.9+
句子 → 湖级签名（每湖总幅度——句子的"湖级签名"）
高层：话题湖——湖间耦合 L（窗口共现：相邻 5 句窗口——主题内多句共享湖对 → 强信号）
  话题湖 = L 强耦合模块（跨域合并 R22——湖的组合）
数据：corpus_simple_natural.txt（302 句——我生成的自然主谓宾——家庭/动物/自然/饮食主题有序）
```

## 结果

| 实验 | 结果 | 判定 |
|---|---|---|
| exp1 字湖涌现 | **38 模块**（≥2 字——K 阈值 0.08 + 容量 0.5）——词级耦合：天气热(0.98)/老师教(0.99)/学生(0.96)/游泳/打球/苹果/关灯/香蕉/葡萄/蜜蜂采蜜 | ✅ 词组 = 湖单元 |

| exp4 尺度递归 | 字湖 38 → 话题湖 6——两层同机制（K 模块/L 模块——R16） | ✅ |

## 关键发现

1. **词级湖 = 耦合单元**（湖2[书明背包清]≈"小明背书包"、湖3[老师教虎]——句子碎片耦合）——词不是预置的分词——是耦合涌现的单元（真实：中文无空格——分词是学习产物）
2. **话题 = 多句共享模式**（窗口共现）：相邻单句对共现太稀疏（每句激活 2-3 湖——全湖对背景噪声沉积）——**5 句窗口内共享湖对 = 话题信号**（主题内多句同湖 → 强；跨主题弱）——窗口 = 话题的最小时间尺度
3. **简单句训练验证**（用户原则）：302 句主谓宾——字湖/话题湖全部涌现——简单语料够用（阶段 A 完成）——混合语料（+知识层）是下一步加难

## 关键调试

| 问题 | 根因 | 修复 |
|---|---|---|
| 语料只有 8 句 | 长度过滤 lo=8（简单句 3-8 字被滤） | lo=3 |
| 湖3 巨型（100+ 字） | K 阈值 0.05 太宽（高频功能字桥接） | 阈值 0.08 + 容量 0.5 |
| 话题湖 1 个（L 全连通） | 相邻单句共现稀疏 + 阈值 0.01 宽 | 窗口共现（5 句）+ 阈值 0.05 + 容量 1.0 |

## 意义

**层级湖（字→句→话题）落地**：两层同机制（K 模块）——R16 尺度递归验证——句子通过湖级签名进入高层——话题 = 湖的组合（R22 跨域合并）。字湖（微观——词组单元）+ 话题湖（宏观——语义话题）——从 302 句简单主谓宾涌现。
