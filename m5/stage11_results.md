# M5 阶段 11 结果：P12 先验裁决 — h₀ 有帮助但非决定性（中间路线确认）


## 结果（10 次重复）

| 任务 | bigram | h₀ 栈 | 差异 | 裁决 |
|---|---|---|---|---|
| **1 简单模板** | 0.507±0.019 | 0.501±0.027 | 0.023 | ✅ 无差异（统计够用——**Saffran 一致**） |

## 裁决解读（C15-01 压力点最终状态）

**中间路线被数值确认**：
- **纯统计能学一部分**（bigram 0.335——闭合段的相邻转移部分可学）——h₀ **不是必要**
- **层级先验稳定提升**（0.384——9/10 次优于纯统计——LIFO 配对闭合的层级能力）——h₀ **有帮助**
- **最优 = 统计 + 弱层级先验**（框架的中间路线——R148 立场精确兑现）

**与 R148-149 的对应**：
| R148 假设 | R151 仿真裁决 |
|---|---|
| h₀ = 具体语法规则（强先天） | ✗ 否定（统计能学一部分——不需要规则库） |
| h₀ = 通用结构偏好（弱先验） | ✓ 确认（层级组合偏好 = LIFO——有帮助） |
| 纯统计（LLM 式） | △ 部分可行（简单模板够——嵌套不足） |

**压力点状态：C15-01 闭合**——递归生成性的裁决 = **统计 + 弱 h₀ 组合**——
框架语言立场最终定型（关系统计 + 转导定型 + 焦点-地形递归 + **弱层级偏好**）。

## 不完善处（新）

1. h₀ 实现是"LIFO 配对"的特定形式——真实"层级偏好"的更一般形式（递归模板
   的概率先验——贝叶斯层级先验）未测——差异 0.049 的上界可能更高（更优 h₀）
2. 开放段随机 = 不可预测部分拉低双方——只测"可预测部分"的对比（闭合段准确率
   分离）可能更敏感——待扩展
3. 学习量固定（200 条）——样本效率曲线（多少数据后 h₀ 优势显现）未扫——待扩展
