# M5 阶段 13 结果：P10 谎言负担 ∝ 地形偏离度（仿真先验）

> 日期：2026-08-18 · 代码：m5/stage13_lying_cost.py · 图：m5/fig_stage13.png
> 理论对照：R73（说谎 = 低忠实度表达决策）/ P10（负担 ∝ 偏离——Vrij 认知负荷测谎机制）/ R42（重放固化）

## 模型

```
地形 = 概念空间（语义距离）
真话 = 直接读取真实位置（成本 ≈ 0——重建贴合地形）
谎言（偏离 d）= 输出偏离地形 d 的位置（编造量 = d——构造新内容——认知负荷）
检测 = 负担信号 > 检测阈值（R36 身体信号——Vrij 认知负荷测谎）
```

## 结果摘要

| 实验 | 结果 | 判定 |
|---|---|---|
| **exp1 负担 ∝ 偏离** | 单调递增（0.01 → 6.00）——大幅谎言编造量大负担高 | ✅ **P10 前半**（Vrij 机制：编造 = 认知负荷） |
| **exp2 检测阈值** | 负担 > θ_detect（1.0）才可检测——**偏离 d ≤ 1.0 检测不到**（贴近真话） | ✅ **P10 后半**（越贴近真话越难检测——负担低于检测阈值） |
| **exp3 重复说谎** | 负担指数下降（3.00 → 0.78）——谎言河道建立（R5 沉积）——熟练说谎者负担低 | ✅ **谎言固化**（R42 重放——"熟练说谎"——检测变难——Vrij 预测：职业说谎者难测） |

## 意义

**P10 兑现（仿真先验）**——说谎的认知负担机制（Vrij 认知负荷测谎的框架版）：
- 编造量 ∝ 偏离（负担 = 构造新内容的认知成本）
- 检测 = 负担阈值（身体信号——R36）——**贴近真话的谎言（偏离 < 阈值）= 检测不到**
- 重复说谎 → 固化 → 负担下降 → 更难检测（"熟练说谎者"）

**框架的 R73 机制（说谎 = 忠实度参数）获得负担面仿真**——说谎不是"另一套机制"
（递归原则）——是地形偏离的编造成本（C73 精确化）。
