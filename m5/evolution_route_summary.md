## 3. 阶段详解

### A 光合（stage27-28）——单细胞进化训练 + 结构进化

- **stage26 冷启动失败**：纯随机权重（146 个）在随机搜索中命中"会找食物"的概率≈0——无选择梯度——**单细胞有本能（趋化先验：隐藏单元读 sin/cos → 输出复制 + 小噪声）——进化优化的是本能细节而非"会不会"**
- **stage27 NEAT**：结构也是基因——5/5 自持 + 4/5 长出隐藏节点——**结构 = 环境复杂度镜子**（趋化线性——隐藏层无优势——结构缓慢生长）
- **stage28 多光斑**：单点光源 = 公共悲剧（承载力 3 崩溃）；6 光斑 → **分散结构涌现（18 只 = 6×3）** + 趋光 16.6→0.9 + 群体感应输入（crowd）——5/5 100% 自持

### B 异养（stage29-30）——混合营养连续谱 + 细胞机制

- **τ = 网络输出第 3 维**（sigmoid——行为层实时决策）：光合 ×(1-τ)^1.8 权衡（φ≈1.8——Ward&Follows）；吞噬接触 τ 优势 + 饿才吞（e<80——消化——猎物喘息）；初始偏置 -0.5（tanh 线性区——变异可见）
- **异养行为全 seed 涌现**（15-48 次吞噬）+ **混合营养平衡 τ=0.30**（泛化者最优——研究预测）；纯异养生态位未持续（光受限不够极端）
- **stage30 生态位三维**：防御 d（被吞概率 1/(1+exp(6Δd))，代价 0.1d）+ 体积 s（大难吞/光合 0.75+0.25·S_MIN/s）+ 威胁感知逃逸（N_IN 9）——**吞噬军备竞赛持续（69 次/seed）——防御在压力下维持（d=0.21）——体积分化（0.69-0.97）**

### C 多细胞（stage31）——环境梯度驱动聚合

- **6 机制扫描**：资源分层 ★（簇 8-11——87% 自持——外层光合/内层营养）；防御/压力/共享弱涌现但世界崩；迁移/繁殖无效——**环境梯度驱动聚合比黏附基因更自然**
- **30 seed 普遍性**：聚合涌现 97%（簇≥5）/ 强聚合 83%（簇≥8）/ 自持 95%——不是 seed 偶然——**稳健生态学结果**
- **真实对应**：海洋 DCM 深绿层（叶绿素最大值层——浮游植物聚集在密度跃层）——模型复现真实海洋分层聚集

### D 分化（stage32）——稀有涌现（研究驱动 5 修正）

```
① 发育可塑性（PLOS 模型）：c（细胞命运）= 网络输出第 4 维——环境实时决定命运——非基因硬编码
② 体积决定命运（glsA）：s>1.05 生殖 / s<0.7 体细胞 / 中间可塑
③ 不对称分裂：子代能量 ∝ 体积（大子代多储备——分化冷启动解）
④ regA 式抑制：体细胞繁殖阈值 110（牺牲繁殖——专职光合 ×1.8）vs 生殖细胞阈值 34
⑤ 群体生命周期：生殖细胞释放完整新群体（1 大 + 2 伴生体细胞——-90% 母体解散）——断链修复
```

- **seed109 完整分化生命周期**：生殖 2 / 体细胞 10 / 全能 5 三态共存——自持 100%
- **多 seed 敏感（1/5）——分化 = 脆弱平衡**——阈值曲线 1.6-1.3c 是 7 参数扫描最优——**但稀有本身 = 真实**（volvocine 分化多次独立演化但每次罕见——模型复现罕见性）
- 关键调试：能量共享零和（体细胞 1.2 被生殖 0.2 抵消）→ 专职 ×1.8；插桩证实生殖能量卡 46.6 vs 阈值 58.9 → 阈值曲线下移

### E 信息处理层（stage33/33b）——信号共享 → 协调移动

- **stage33**（基于分化世界——脆弱传导）：协调峰值 0.35 但种群灭绝——信息处理层需要稳定多细胞世界
- **stage33b**（基于稳定聚合体——stratify 85% 自持）：信号共享（群体光方向 N_IN 13）+ 协调度统计（成员方向 cos 相似度）——**协调涌现 seed503 0.77**（成员方向一致——Volvox 鞭毛同步类比）
- **协调需进化学习**（seed 波动 0.3-0.8——不是瞬时奖励而是世代选择）——信息处理层初步验证

## 4. 关键发现清单

1. **神经进化冷启动**：纯随机权重无梯度（146 权重命中率≈0）——单细胞有本能（趋化先验）——**进化优化细节而非能力有无**
2. **环境梯度驱动聚合 > 黏附基因**（DCM 深绿层真实对应——97% 普遍）——多细胞涌现的生态学路径
3. **分化 = 稀有涌现**（生态学真实——volvocine 罕见）——模型复现罕见性而非强行稳定
4. **协调 = 信息处理层**（信号共享 → 成员一致行动——Volvox 鞭毛同步）——需要稳定社会 + 世代选择
5. **三环耦合**（stage25）：进化×文化×个体——军备竞赛 → 社会层解药
6. **简单 > 复杂**：stage25 复杂机制（9 基因/社会/遮挡）在单细胞级被砍到只剩"位置/能量/网络"——进化训练反而第一个 100% 自持——**进化需要干净的选择梯度**
