# M5 阶段 6 结果：τ-重放模块（R42 多巴胺间接化——R161 #10 解决）

> 日期：2026-08-18 · 代码：m5/stage6_tau_replay.py · 图：m5/fig_stage6.png
> 理论对照：R42（多巴胺间接化：RPE → τ 标记 → 重放 → 流量 → 硬化）/ R11（旧式直接）/ R47（睡眠巩固）

## 模型

```
间接化（R42）：学习事件 → 价值 v → |v|>θ → τ 标记（不直接改 W/H）
             → 睡眠/空闲重放：标记项被重放（流量）→ H 硬化 + W 维持
直接化（R11 旧式对照）：v 直接加 H（一次完成）
```

## 结果摘要

| 实验 | 结果 | 判定 |
|---|---|---|
| **exp1 标记选择性** | 6 项标记（|v|>0.5）/ 4 项未标记 | ✅ 标记 = 重要事件（τ = 价值门控） |
| **exp2 重放选择性** | 标记项 H=**0.225** vs 未标记项 **0.000** | ✅ **τ→重放→硬化——间接链工作**（未标记项零硬化——完美选择性） |
| **exp3 保持率** | 间接 **1.01x**（0.270→0.271——重放对抗侵蚀——维持）vs 直接 **0.70x**（0.413→0.287——纯衰减） | ✅ **R42 验证：重放维持记忆**（睡眠巩固——"睡一觉记得更牢"） |
| **exp4 时间分布** | 直接 = 单次完成 vs 间接 = 时间分散的硬化（多轮重放） | ✅ 间接化 = 时间分布（R42/R47 睡眠固化的机制） |

## 关键发现（调试暴露的机制——理论深化）

**重放需要"自维持"**：第一版重放 ∝ 软区 W（燃料）——W 衰减后重放失效——
修复：重放**主动重新激活**（W 维持 + H 硬化）——这印证了 R70（痕迹保留——
标记的项可被重新激活）——**重放不是"消费燃料"而是"重新激活痕迹"**——与
R42"τ 触发重放→重复流量"一致——**重放的自维持 = 记忆巩固的正反馈**（重要记忆
被反复重放 → 越来越深——C19 记忆深度机制）。

## 不完善处（新）

1. τ 是 0/1 开关——真实 τ 应有强度（|v| 大小 → 标记强度 → 重放频率）——强度化待扩展
2. 重放触发时机固定（每轮）——真实睡眠的 REM 周期结构未建模
3. 重放与 1b 缓存-写回的整合未做（重放 = 写回的事件化实现——两个模块合并待整合）

  最小机制**——框架的"多巴胺不直接改河道"立场在仿真中成立
