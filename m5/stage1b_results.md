# M5 阶段 1b 结果：沉积-侵蚀仿真（缓存-写回模型）

> 日期：2026-08-18 · 代码：m5/stage1b_deposition_erosion.py · 图：m5/fig_stage1b.png
> 理论对照：C96-01（缓存-写回）/ C97-01（软-硬耦合 dH/dt=k·S）/ C95-01（间隔效应）/ **P1（遗忘三阶段）**

## 模型

```
软区（缓存 S）：dS/dt = −λ_s·S + 学习输入（λ_s=0.5/天——半衰期 1.4 天）
硬区（结构 H）：dH/dt = k·S − λ_h·H（k=0.3/天 写回；λ_h=0.01/天 慢蚀）
总记忆 M = S + H
```

## 结果摘要

| 实验 | 结果 | 判定 |
|---|---|---|
| **exp1 遗忘三阶段** | 半对数斜率：早期 **−0.148** / 中期 **−0.032** / 后期 **−0.010**（/天）——严格递减（|s1|>|s2|>|s3|） | ✅ **P1 验证**（快段 S 丢失主导 → 中期写回减速 → 后期 H 慢蚀——预测的三阶段形状出现） |
| **exp2 间隔 vs 集中** | 间隔 H(40d)=**1.736** > 集中 1.654（**1.05x**） | ✅ 间隔效应（S 满时写回饱和——C97 机制验证）——**注意：效应弱（1.05x）——真实实验通常更强（参数校准问题——见下）** |
| **exp3 写回 ∝ 软区存量** | 三种 S 水平下 slope/S = **0.168 常数**（S=0.5/1.0/2.0 → 0.084/0.168/0.337） | ✅ **dH/dt = k·S 验证**（C97 核心方程——比值恒定 = k 的稳态近似） |
| **exp4 阈值复习（Anki）** | 阈值复习（S 降到 0.3 时复习）H(25d)=**5.107** > 固定间隔 5.073 | ✅ SM-2 原理（复习时机 = S 降阈值——C95 间隔效应的机制基础） |

## 不完善处记录（理论保持开放）

1. **exp2 间隔优势仅 1.05x——弱于真实实验**（经典间隔效应可达 2x+）——原因：集中复习间隔 0.5 天（S 半衰期 1.4 天——0.5 天时 S 仅降到 ~0.7——写回未充分饱和）——**真实实验的强间隔效应需要"间隔 ≫ S 半衰期"**——预测：间隔优势 ∝ 间隔/半衰期比——**这给出可检验预测 P24：间隔效应强度 = 间隔时长与软区半衰期的函数（可参数化扫描验证——待后续）**
2. 模型参数（λ_s=0.5、k=0.3）为示意值——生物校准（艾宾浩斯曲线拟合）待后续
3. 事件模型简化（复习瞬间写入——无"重放时长"维度）——R42 重放的时长效应待 1c+ 扩展
