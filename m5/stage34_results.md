## 诊断（stage32 分化脆弱的根因）

**stage32 的问题：分化 1/5 seed——脆弱平衡。** 分析：s（体积）绑定命运（glsA），但 **s 没有生态学收益**——s 的漂移是偶然的（变异 ±20% 随机游走）——所以"体积决定命运"只能靠幸运的 s 漂移触发 → 分化 = 参数临界幸运，而非生态涌现。

## 深化机制（2 项修改——全部研究驱动）

```
① 营养吸收 ∝ 体积：深层营养 = 0.25 × clip(s, 0.2, 1.6)
   ——大细胞吸收强（真实：大细胞储存容量/吸收表面积大）
   ——深层营养层收益 ∝ s → 大 s 深层驻留可行（不靠共享也活）、小 s 必须浅层光合
   ——体积-生态位耦合 → s 演化有方向 → glsA 绑定自然触发
② 遗传群体共享（gid 继承母体——共享池按 gid——胞质桥等效）
   ——真实 Volvox：群体 = 克隆后代——细胞质桥全身共享——共享不依赖空间接触
   ——生殖细胞深层吸营养也能被体细胞供养（跨层无需空间相邻——stage32 接触闭包断链问题消除）
③ glsA 绑定保留：s>1.05 生殖 / s<0.7 体细胞 / 中间网络可塑
④ 生命周期保留：生殖繁殖 = 新 gid 成套释放（1 大 + 2 伴生体细胞——-90% 母体）
```

## 消融实验（辨别主驱动——3 seed × 1500 步）

| 模式 | 机制 | 分化 | 种群 |
|---|---|---|---|
| both（stage34） | 营养×s + gid 共享 | **5/5** | 大（100-228） |
| size_only | 营养×s + 空间簇共享（stage32 原版） | 3/3 | 中（20-92） |
| gid_only | gid 共享 + 固定营养 | 3/3 | 大（125-162） |

**两条独立路径都能产生分化**（stage32 两者皆无 → 仅 1/5）：

- **路径 A（生态位并存——size_only）**：营养×s 让大 s 深层独立自足（0.25×1.3 净收 > 成本——不靠共享）+ 小 s 浅层光合自足——**分化 = 体积生态位分离本身**（分工不依赖共享池——Volvox 体细胞确实独立光合）
- **路径 B（群体供养——gid_only）**：遗传群体共享 = 群体级保险——生殖细胞（光合退化）被克隆群体供养——生命周期闭环
- **both = 两路径叠加**：5/5 且种群最大——**分化 = 多重冗余机制**（真实进化同样如此）

## 生态学意义

1. **分化 = 体积生态位的涌现**：环境奖励两种体型（小 s 浅层光合强 / 大 s 深层营养吸收强）→ s 双峰演化 → 体积决定命运（glsA）自然触发——**不是参数巧合而是生态位分化**
2. **遗传群体 = 分化的载体**：真实多细胞 = 克隆群体（胞质桥共享）——共享不依赖空间接触——跨层分工可行
3. **分化 = 多重冗余机制**：生态位并存（营养×体积）与群体供养（gid 共享）**各自独立足以**驱动分化——真实进化中的多重保障
4. **聚合-分化耦合**（阶段 C 发现延续）：聚合（空间）与分化（遗传）在真实进化中是同一件事的两面——克隆群体既聚集又分工
