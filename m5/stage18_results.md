# M5 阶段 18 结果：蛋文明 — 多代知识积累（R27 文化环仿真）

> 日期：2026-08-18 · 代码：m5/stage18_egg_civilization.py · 图：m5/fig_stage18.png
> 理论对照：R27（三环：进化→文化→个体）/ R67（社会记忆）/ C53（判据）

## 模型

```
多代蛋群（20 代 × 4 蛋）：
  继承组：下一代继承上一代 W（文化传递——"站在前人肩上"）
  无继承组：每代从零学（个体主义——对照）
  每代：继承 + 个体学习（2 个新序列）
```

## 结果摘要（四实验全过）

| 实验 | 结果 | 判定 |
|---|---|---|
| **1 知识积累** | 继承组 **3.5 → 61.0**（17 倍增长）vs 无继承组 2.0→2.5（持平） | ✅ **文化积累**（R27 文化环——知识跨代增长） |
| **2 社会记忆** | 移除一蛋 → 知识保留 **81%** | ✅ **知识在群体**（个体死亡不丢失——R67 群体记忆） |
| **3 判据** | 多代后相干 **0.964** | ✅ 文明不破坏个体判据 |
| **4 知识共享** | 全体蛋知识趋同（6.5/7.5/7.5/7.5——标准差 0.43） | ✅ 继承 → 文化同质化（全体共享） |

## 意义：R27 三环的文化环仿真确认

```
进化环（参数选择——外环）   —— 未建模（本阶段聚焦文化）
文化环（知识跨代传递）       ✅ 本阶段：继承 = 知识积累（17 倍）
个体环（个体学习）           ✅ 个体学习每代进行（新序列）
```

**"站在前人肩上"的最小机制**：继承（W 复制）→ 每代从上一代知识开始 + 新学习 →
知识单调积累（17 倍）——无继承 = 每代从零（持平）——**文化 vs 个体主义的
决定性差异被仿真量化**。

**社会记忆**：知识在群体（每蛋有副本——一蛋死亡保留 81%）——个体死亡 ≠
知识丢失（R67——"群体对个体的记忆"——蛋群的群体记忆）。

**文化同质化**：继承 → 全体蛋知识趋同（共享）——"文化共同体"（R70 群体同步
的知识面——共识的长期版本）。
