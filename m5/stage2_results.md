# M5 阶段 2 结果：S1 决策环最小仿真（联想树 → 竞争 → 选择 → 回写闭环）

> 日期：2026-08-18 · 代码：m5/stage2_decision_ring.py · 图：m5/fig_stage2.png
> 理论对照：R120/R129（决策环五层）/ C104（候选生成）/ C105（截止）/ P6（注意力=硬化控制杆）/ R60（自由感）/ C77（习惯）

## 模型（五层闭环的实现）

```
① 输入：query q（价值注入）
② 数据层：联想展开（A[q]×W 激活——候选 = 超阈项——强河道先行）
③ 服务层：价值累积竞争（drift + 噪声——第一个到阈值者胜出——决策时间 = 到达时刻）
④ 行为层：选择（胜出候选）
⑤ 反馈层：回写（W_winner += η——沉积）
```

## 结果摘要

| 实验 | 结果 | 判定 |
|---|---|---|
| **exp1 联想展开** | 候选按激活强度排序（0.989/0.957/0.881/0.869——严格递减） | ✅ **C72/C104**（强河道先行——候选生成 = 联想展开） |
| **exp2 决策时间 vs 价值接近度** | Δv=0.02 → **6.77s** vs Δv=1.0 → **3.21s**（价值越接近决策越慢） | ✅ **DDM/R60 自由感**（决策时间 ∝ 1/Δv——价值接近 = 犹豫 = 自由感——与 Ratcliff 理论一致） |
| **exp3 截止（成本交叉）** | 搜索成本 0.8→展开 2 层 / 0.9+→1 层（成本↑ 展开↓） | ✅ **C105 截止机制**（边际收益 < 搜索成本 → 停止） |
| **exp4 回写（P6）** | 回写后同 query 重测：胜率 **19/20**（决策时间 7.18→6.82） | ✅ **P6 兑现**（注意力 = 硬化控制杆——聚焦的河道沉积更深——后续决策偏向） |
| **exp5 闭环演化** | 1000 决策：W 标准差 **0.228 → 2.970**（13 倍分化） | ✅ **闭环 + 习惯雏形**（高频项增强——正反馈——C77 习惯形成的机制雏形） |

## 不完善处记录（理论保持开放）

1. **决策环是"连续累积"简化**——真实 R120 环的"候选重新生成"（联想展开与评估交替）
   未建模——exp2 的 DDM 行为是基础版——扩展待阶段 3（双环互接时自然引入）
2. **回写只对胜者**——R42 多巴胺间接化（τ 标记 → 重放）未建模——标记-重放链是
   下一层精度（待 P25 扫描扩展）
3. exp5 分化极快（13 倍）——无侵蚀项（λ）——真实地形有侵蚀平衡（R40）——
   **正反馈 + 侵蚀的平衡 = 地形稳态**（待后续加 λ 项验证——预测：W 分布收敛到
   稳定偏斜而非无限分化）

## 阶段 2 结论

**决策环五层全部可计算复现**：注入（exp1 起点）→ 数据层（exp1 联想展开）→
服务层（exp2/3 竞争+截止）→ 行为层（exp4 选择）→ 反馈层（exp4/5 回写+演化）——
**R120/R129 的"一切 = 选择"在数值上成立**（选择 = 累积竞争的胜者；回写改变地形 →
下次选择改变——环的持续过程性验证）。
