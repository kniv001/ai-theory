# M5 阶段 22 结果：用户的进化实验扩展 — 食物 → 植物（复制性 + 传播性）

> 日期：2026-08-18 · 代码：m5/stage22_plant_ecology.py · 图：m5/fig_stage22.png
> 设计：用户（"将食物转换为植物（复制性，传播性-非接触复制）"）
> 理论对照：R27（三环——植物 = 生态内生的食物环）/ Lotka-Volterra（捕食-资源动力学）

## 模型

```
植物：位置 + 年龄
  复制性：成熟后（age>10）在附近 ±10 产生新株（概率 0.08）
  传播性：成熟后远处 10-50 播撒种子（概率 0.04——非接触复制——风传播）
  容量上限 400（生态容量——防爆炸）
生物：同 stage21（速度×体积 trade-off / 饱食度 / 捕食——吃植物 +8）
```

## 结果摘要

| 实验 | 结果 | 判定 |
|---|---|---|
| **1 植物-生物共存** | 500 步后：生物 **92** / 植物 **400**（初始 50） | ✅ **植物生态自持**（复制+传播 > 被吃——食物链平衡） |
| **2 植物扩散** | 半径 18 → **40**（容量饱和下扩散全平面——传播性工作） | ✅ 非接触复制 → 远处殖民 |
| **3 动力学** | 生物 65±**15**（波动——捕食-资源反馈） | ✅ **Lotka-Volterra 类振荡** |
| **4 植物 vs 随机食物** | 植物：生物 105/食物 400（**自持内生**）vs 随机：生物 500/食物 72（**注入外生**） | ✅ **植物 = 可持续生态**（食物供应生态自身维持） |

## 核心发现

1. **植物 = 内生食物链**：食物供应由生态自身维持（复制+传播）vs 随机食物 =
   外生注入（依赖外部生成）——**"可持续性"涌现**（食物环闭合——R27 的
   生态版）
2. **捕食-资源振荡**（exp3）：生物-植物波动（±15）——Lotka-Volterra 类反馈
   （吃植物 → 植物减 → 生物饿 → 植物恢复——经典捕食者-猎物动力学从
   "蛋 + 植物"涌现）
3. **容量上限 = 生态容量**：植物 400 饱和（复制+传播与容量平衡）——
   "环境承载力"的涌现（K 值——Logistic 生态学）

## 意义

**用户的实验扩展完成**：随机食物 → 自组织植物生态——生态从"外生供给"升级为
**"内生可持续"**——这是"造蛋到造脑"生态化的关键一步：蛋的世界有了
**可再生的食物基础**（植物 = 生态的"生产环"）——后续可加：季节/天敌/共生。
