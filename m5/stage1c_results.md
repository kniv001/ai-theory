# M5 阶段 1c 结果：多单元同步域仿真（Kuramoto——湖的机制验证）

> 理论对照：C5-02（湖 = 相位锁定群体/分裂=退锁/合并=同步）/ R2（大湖群架构）/ 工程 4 问

## 结果摘要

| 实验 | 结果 | 判定 |
|---|---|---|
| **exp1 全局耦合相变** | N=20：K_c ≈ **0.5**——r 从 0.13 跳到 1.0 的清晰相变（K≥0.5 完全锁定） | ✅ **湖形成条件**（临界耦合 ∝ 频率展宽——Kuramoto 理论一致） |
| **exp2 规模临界** | 同 ω 样本控制：K_c 稳定在 **0.5**（N=10/20/50——规模无关——均值场一致；N=5 例外因频率样本少） | ✅ **工程问 2**：同步临界 ≈ 规模无关（均值场性质）——湖的规模由耦合密度决定非单元数 |
| **exp3 分裂/合并** | K 时变：r = 0.99 → **0.25** → 0.99（锁定→退锁→再锁定） | ✅ **C5-02 分裂=退锁/合并=同步**（耦合强度门控湖的存在——与 R10 闸门一致） |
| **exp4 噪声容限** | K=2 时 σn=0~1.0 全程 r=0.99（超鲁棒） | ✅ **工程问 1**：强耦合同步对加性噪声极鲁棒（拉回力 >> 噪声）——**噪声容限 ∝ K/σω**（弱 K 区噪声敏感待扫描） |
| **exp5 局部湖（模块化）** | K_in=3.0/K_out=0.02：组内相干 **0.853** + 组间 **0.233**——**4 个小湖并存** | ✅ **R2 大湖群最小演示**（组内强耦合 = 湖；组间弱耦合 = 湖间弱关联——模块化结构涌现局部同步域） |
