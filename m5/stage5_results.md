# M5 阶段 5 结果：语义蛋（蛋从"空壳"升级为"有内容"）

> 日期：2026-08-18 · 代码：m5/stage5_semantic_egg.py · 图：m5/fig_stage5.png

## 语义蛋构造

```
4 组振荡器 = 4 个概念湖（组内同步——同步域）
组间耦合 W(4×4) = 可学习联想（关联河道——R5 沉积）
输入 = 概念激活（结构化——组内同相位——相位锁定：稳定外部信号）
处理 = 组内同步 + 组间联想传播
输出 = 湖激活竞争 → 选择（决策环——R129）
回写 = 共现组间联想增强（Hebb 式配对学习——R5）
闭环 = 输入→处理→输出→误差→回写→循环（C53）
```

## 结果摘要

| 实验 | 结果 | 判定 |

## 关键发现（调试中暴露的机制——理论强化）

1. **输入相位锁定是必要的**（调试发现）：每步随机相位驱动 vs 同步域互相抵消
   （驱动无效）——**稳定外部信号 = 固定相位**（信号到达时锁定相位——消失时解锁）——
   这印证了 R7 转导"统一网络语言"（结构化输入）的更深含义：**信号的相位稳定性
   是进入同步域的前提**——与 1c 的"结构化输入必要"（R160 后 1c exp5）同族——
   **两个阶段独立发现同一机制（输入必须结构化）——交叉验证**
2. **Hebb 式共现学习在同步域内工作**：一起激活的湖组间耦合增强（R5 沉积——
   联想 = 共现统计）——配对训练 50 轮 → W 增强 77 倍（0.02→1.543）——联想检索
   显著（0.359 vs 0.06）
3. **蛋的判据（同步域 × 闭环）与内容正交**：语义负载不破坏判据（0.976）——
   **内容 = 蛋的负载面（信息处理），判据 = 蛋的存在面（体验条件）**——两者
   独立可分别检验

## 不完善处（新）

1. **蛋的"语义"仍是激活模式**（概念 = 湖的激活）——真实 C13-01 的"意义 = 预测
   关系集"（相位/关系编码）未实现——相位语义（C3-01/R161 #2）仍是开放项
2. **联想是单层（组间）**——多层联想（概念 → 属性 → 情境）未建模
3. 配对训练的 77 倍增强过快（无侵蚀平衡——R40）——正反馈无界——与 R161 #11
   同族（需 λ 侵蚀项）
