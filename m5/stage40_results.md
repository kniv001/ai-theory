# M5 阶段 40 结果：关系分层（用户问题——归类的关系连接——关系 = 河道）

> 日期：2026-08-20 · 代码：m5/stage40_relation_layers.py · 图：m5/fig_stage40.png
> 用户问题："对于词不是增加了归类了吗，但是对于归类是否有加入关系连接"
> 用户指导："语言只是与其他层耦合度最高的部分……关系 = 河道"（R2）+ 多湖作参考（语言 = 世界投影——理解功能）
> 理论锚定：**C122-01**（语言=关系统计完整化——"规则"=关系统计的压缩描述——关系分层 = 关系统计的类型化）

## 问题

K 无类型——"苹果是水果"(is-a)/"苹果很甜"(属性)/"我吃苹果"(动作) 混合沉积到同一 K——
"是/这"成为万能枢纽（300 次出现——与一切共现）——污染湖结构 + 无法区分关系类型。

## 方案（框架：关系 = 河道——经由词 = 关系类型）

```
K 分层：K_isa（"是"河道——类别/指物）/ K_attr（"很"河道——属性）/ K_act（动作动词河道——主谓宾）
每句按功能词分类（是>很>动优先级）→ 沉积到对应层——湖检测按层进行
关系 = 河道（R2 因果影响链）——不同类型的关联走不同河道——互不污染
```

## 结果（874 行语料——isa 300/act 256/attr 29/None 289）

| 层 | 湖数（≥3） | 内容示例 | 判定 |
|---|---|---|---|
| K_isa（类别湖） | **9** | 类3[水果/海/糖]0.78 类4[早/晚]0.96 类7[电视/话]0.90 | ✅ "是"河道 = 类别关系 |
| K_attr（属性湖） | 1 | [大家/住/的]0.91（不足——attr 句仅 29 句） | ◐ 数据不足（待补"很"句） |
| K_act（动作湖） | **13** | 动5[吃/喝/洗/碗/水果/菜]0.55（厨房）动6[去/游/车/坐]0.39（出行） | ✅ 动词河道 = 动作关系 |

**exp4 跨层共存（核心验证）**：
```
'水': isa[水果/海] + act[喝/果]——水是水果/海水（类别）+ 喝水（动作）——多层无冲突
'苹': isa[果] + attr[果] + act[果]——三层共存
'小': isa[狗/鸭]（小动物）+ act[明/羊]（小明/小羊）——同名跨层不同角色
```

## 意义

1. **归类 + 关系连接双落地**：归类（湖涌现——C15-02）+ 关系类型（河道分层——C122-01 的"关系统计"类型化）——"苹果是水果"不是无类型共现——是 is-a 河道的类别关联
2. **关系 = 河道验证**（R2）：不同关系类型走不同河道——"是"河道不污染"很"河道——万能枢纽问题（stage39 的"是"污染）被河道分离解决
3. **语言不代劳**（用户指导）：关系分层是"语言内关系统计"——真实关系（物理/情感）在参考多湖框架（语言=世界投影——理解功能）——本阶段为语言层关系结构
4. **C122-01 支撑**："规则"（是/很/动词分类）不是先天语法——是从语料统计涌现的河道类型——结构依赖 = 零河道原理（C122-01 第二要点）在关系层的实例
