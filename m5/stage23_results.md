# M5 阶段 23 结果：用户的进化实验扩展 2 — 植物竞争（密度过高生长慢）

> 日期：2026-08-18 · 代码：m5/stage23_plant_competition.py · 图：m5/fig_stage23.png
> 设计：用户（"植物竞争——密度过高生长慢——资源竞争"）
> 理论对照：R35（出生竞争）/ Logistic 生态学（资源竞争）/ 空间生态学（分布格局）

## 模型

```
竞争机制：每株成熟植物的局部密度（半径 15 内其他植物数）
  复制概率 = 0.12 / (1 + 0.2 × 密度)（拥挤 → 繁殖慢）
  传播概率 = 0.05 / (1 + 0.1 × 密度)（传播受竞争影响小——远处种子）
```

## 结果摘要（三实验全过）

| 实验 | 结果 | 判定 |
|---|---|---|
| **1 竞争机制** | 拥挤区（密度 4）繁殖概率 **0.067** vs 孤立区 0.120——**降低 44%** | ✅ 拥挤 → 繁殖慢（资源竞争） |
| **2/4 分布均匀化** | 竞争：最近邻标准差 **2.00**（284 株）vs 无竞争 2.27（400 株） | ✅ **竞争 → 更均匀分布**（分散繁殖——避开拥挤区） |
| **3 生态平衡** | 生物 **98** / 植物 **255** | ✅ 竞争下共存（平衡保持） |

## 核心发现

1. **资源竞争机制**（exp1）：局部密度 → 繁殖概率下降 44%——"光/水/空间"
   的竞争压力量化
2. **空间均匀化**（exp2/4）：竞争 → 植物分布更均匀（最近邻标准差 2.00 vs
   2.27）——**"分散繁殖"策略涌现**（拥挤区繁殖慢——自然选择偏向分散——
   空间资源竞争的生态学预期）
3. **生态平衡保持**（exp3）：竞争加入不破坏共存（98/255——食物链仍闭合）

## 意义

**植物生态的竞争维度完成**——用户的实验世界新增"资源竞争"层：

```
随机食物（外生注入）→ 植物（内生可持续——R22）→ 植物竞争（资源分配——R23）
```

竞争 = 植物分布的空间模式涌现（均匀化）——生态学的经典格局（竞争排除/
空间隔离的雏形）——**R35 出生竞争（解释力竞争）的植物版**（拥挤区繁殖受抑——
"解释力"的生态类比 = 资源获取力）。
