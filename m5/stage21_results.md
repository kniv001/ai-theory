## 模型（用户设计的最小实现）

```
100×100 平面 / 食物随机生成（rate 可调）
生物：speed + volume·0.8 = 1.5（trade-off——体积大慢/小快）
      饱食度衰减 ∝ 体积（大体积消耗快——trade-off 另一面）
决策：目标价值 = 回报/距离 × 紧迫性（饱食度低 → 紧迫性高）
接触：食物 → 饱食度+10；小生物（体积<自己×0.9）→ 吃掉（对方死亡）
繁殖：饱食度>120 → 分裂（变异 ±10%）/ 死亡：饱食度≤0
```

## 结果摘要

| 实验 | 结果 | 判定 |
|---|---|---|
| **1 基线** | 种群 30 → **500**（增长——食物链闭环）——平均体积 1.64 | ✅ 种群维持 |
| **2 密度效应** | 稀疏/密集都 500 饱和 + 体积 1.63/1.61——**捕食链自持**（捕食不依赖外部食物——小生物吃食物→大生物吃小生物——金字塔） | 📌 **发现：捕食 = 主导选择压力**（密度效应被捕食掩盖） |
| **3 捕食演化** | 体积 0.91 → **1.58**（捕食优势被选择） | ✅ 适者生存 |
| **4 演化轨迹** | **体积 0.89→1.30↑ 速度 0.78→0.46↓**（trade-off 演化转移——清晰） | ✅ **参数演化被自然选择驱动** |

## 核心发现

1. **捕食链自持**（exp2）：稀疏食物下种群仍饱和——因为捕食（大生物吃小生物）
   不依赖外部食物——**食物链金字塔自持**——密度效应被捕食掩盖——
   **捕食 = 主导选择压力**（吃一个生物回报 > 觅食差异）
2. **trade-off 演化转移**（exp4）：体积↑速度↓——捕食压力选择体积（能吃别人）
   ——速度（觅食效率）被放弃——**选择压力决定 trade-off 的平衡点**——清晰的
   演化轨迹（这是用户实验最漂亮的输出）
3. **饱食度 = 价值信号的涌现**：紧迫性（饱食度低 → 觅食紧迫）驱动决策——
   生物的行为 = 价值驱动的决策环（R60 空间版）——**框架内环工作**
