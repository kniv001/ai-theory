## 诊断（stage33b 协调不稳定的根因）

**stage33b 问题：协调 seed 波动（0.3-0.8）**。分析：协调无生态学收益——选择压力弱。且无昼夜周期（恒光）——浅层光合净收 > 深层营养——下潜无收益——**迁移没有价值**（数据：中心 y 稳定 26-28——全体驻留浅层）。

## 深化机制（研究驱动）

```
① 资源按群体中心深度（迁移 = 群体级行为——全体成员共享同深度资源）
   ——浅层光合（cy<45）/ 深层营养（cy>55）——过渡带两边弱
② 成员移动平均 = 群体中心位移——协调度高 → 中心迁移快（一致才快）
   ——协调 = 群体级资源采集效率——直接生态收益 → 进化选择压力
③ 昼夜周期（DVM 驱动力——真实）：夜间浅层光 ×0.1（浅层驻留者挨饿）→ 强制迁移
   ——相位 sin/cos 输入（前馈网络无记忆——显式时间信号 N_IN 15）
④ 信号共享（群体光方向广播）+ 能量调制（e/150 输入——低能下潜/高能上浮）
⑤ 克隆群体协调遗传基础（同 gid 基因组相似）+ stage34 分化世界
```

## 关键发现：分化-协调张力

**群体中心资源利于协调（迁移有意义）但损害分化**——生殖细胞（深层驻留）的个体生态位被"群体中心化"抹平（资源按群体中心而非个体深度——体积收益只在群体中心深时全体有效）。这是真实张力：Volvox 中两者共存（分化 + 鞭毛同步）——模型里资源耦合把两者对立——下一步：资源混合（群体级 + 个体级）。

## 性能优化（路径 A——CPU 向量化——用户："让显存加快"）

### 诊断：慢在循环与种群爆炸
- 逐细胞版瓶颈：O(n²) 邻居扫描 + 每繁殖一次 np.vstack + 逐删 O(N²)
- 营养 0.4 太富 → 种群爆炸（seed203 上千细胞）→ O(n²) 拖垮（后台 30 分钟+ 未完成）

### stage35v 三处根本优化

```
① cKDTree 邻居查询（O(n log n) 替代 O(n²) 距离矩阵）——大种群的根本修复
② bincount 批量累加（替代 np.add.at——快 10-100×）+ 预计算索引
③ 繁殖缓冲步末合并 + 批量 kill（布尔掩码替代逐删 O(N²) 复制）
+ 营养回 0.25（参数修复——种群可控——生物学合理）
```
