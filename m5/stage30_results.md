# M5 阶段 30 结果：细胞多维机制（阶段 B 扩展——防御/体积/威胁逃逸）

> 日期：2026-08-19 · 代码：m5/stage30_cell_defense.py · 图：m5/fig_stage30.png
> 用户："对于细胞加入更多的机制，比如防御等等参数，目前的结论还是不够"

## 模型（生态位三维）

```
基因（身体——慢尺度——变异遗传）：
  防御 d（细胞壁——细菌肽聚糖）：被吞概率 = 1/(1+exp(6×(d_i-d_j)))——代价 +0.1×d 代谢
  体积 s（0.3-1.7）：被吞概率 ×(s_j/s_i)（大难吞）——光合 ×(0.75+0.25×S_MIN/s)——
    吞噬收益 ×s_j（大猎物能量多）
网络（行为——快尺度）：
  输入 9：光方向/距离/光强/拥挤 + 威胁方向/距离（最近 τ 高邻居）——学逃逸
  输出 3：移动 + τ（营养策略）
吞噬：τ 优势 + 防御差概率 + 饿才吞（e<80——消化——猎物喘息）
```

## 核心结果

1. **吞噬军备竞赛持续**（69 次/seed——45-101 波动）——不再是 stage29 的初期爆发
2. **防御在吞噬压力下维持**（d 0.21——无压力时退化的对照：光斑承载力低时 d→0.15）——
   **防御=环境依赖的正确生态学**（吞噬压力强→厚壁被选择；无压力→壁浪费）
3. **体积分化**（seed 间 0.69-0.97——大小策略差异涌现）
4. **混合营养平衡保持**（τ 0.30——研究 1：混合营养是常态）
5. 纯异养生态位仍未持续（光充足环境——研究 2 预测正确）

## 关键调试

| 问题 | 根因 | 修复 |
|---|---|---|
| 种群崩溃 0% | 体积光合惩罚 0.5+0.5×min/s 太狠（降 32%）+ 壁代价 | photo_eff 温和化 + ABS_RATE 补偿 |
| 吞噬只在初期 | 光斑承载力 1-2 只——细胞分散不接触 | 光强 0.45→0.7 + 拥挤共享 0.15→0.08（生物膜密度） |
| 防御退化 0.15 | 无持续吞噬压力——壁代价无收益 | 高猎物密度 → 军备竞赛持续 |
