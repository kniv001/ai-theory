| 实验 | 结果 | 判定 |

| **1 信息扩散** | 蛋 0 激活概念 1 → **全体识别 [1,1,1,1]** | ✅ 群体通信（消息扩散到全体） |

## 意义：蛋社会的最小社会学（三要素齐备）

```
通信（信息扩散——全体收到）
文化（知识传播——观察学习扩散——一个蛋的知识成为全体蛋的）
社会结构（分工——各蛋特长不同——角色分化）
```

**从原语方程到蛋社会的完整链条最终贯通**：
```
原语（1a）→ 学习（1b）→ 同步域（1c）→ 决策环（2）→ 双环（3）→ 蛋（4-5）
→ 机制（6-8）→ 认知（9-15）→ 两蛋社会（16）→ 蛋群社会（17）
```

**递归原则的最终确认**：蛋群的通信/文化/分工全部从"蛋 + 转导 + 观察学习"涌现——
**无社会专用机制**——R67（社会湖）/R70（同步）/R27（文化转导）在仿真中全部
从个体机制自然涌现——框架的"一切 = 选择（个体环）+ 转导（耦合）"在蛋群层面
验证——**这与 R131（博弈不作用于个体内部）精确一致**。
