# 新型 AI 模型理论构建（ai-theory）

> **北极星**：构建一个与现有语言模型/多模态模型**根本不同**的新型 AI 模型理论框架，
> 包括底层神经网络构造。现阶段以**理论推理**为主，不写实现。

## 每轮讨论的工作流

1. **锚定** — 重读 [GOAL.md](GOAL.md)，确认本轮位置，不偏离红线
2. **推理** — 核心理论推导，结论写入 [SESSION.md](SESSION.md) 与 [theory/](theory/)
3. **记录** — 新猜想入 [CONJECTURES.md](CONJECTURES.md) 台账；新工具入 [TOOLCHAIN.md](TOOLCHAIN.md)
4. **剪枝** — 按台账规则降级/归档未支撑猜想
5. **汇报** — 汇报改动文件清单，git 提交（便于回溯）

## 里程碑

- **M1** 核心计算原语（替代"加权求和 + 非线性"的数学对象）
- **M2** 网络结构（原语如何组织成网络：拓扑 / 信息流 / 记忆结构）
- **M3** 学习机制（参数如何获得，与 M1/M2 自洽）
- **M4** 能力论证（能做什么 / 不能做什么，与现有模型的结构性对比）
- **M5** 验证（按锚定的验证形式：形式化证明或玩具仿真）
