## 2. 要点 1：判断 = 地形内一致性检验（"真假" = 认知标记）

R49 验证循环（重构 + 验证收敛）——但**验证的标准是什么？用户：不是现实，是记忆及信息**：

```
"这是真的吗？" = 新信息与既有河道的兼容性检验（R103 挂载兼容）：
  ✅ 一致性检验通过（与相似传闻/刻板印象/信任来源的河道兼容）→ 判定"真"
  ❌ 冲突（与既有河道矛盾）→ 判定"假" → 惊讶（R10 误差）
```

**"真/假" = 认知标记**（一致性检验的结果）——与"随机"（C111-01 不可预测性标记）
对偶：

| 标记 | 判定 | 检验对象 |
|---|---|---|
| 随机 | 不可预测 | 规律性 |
| **真假** | **一致/冲突** | **与既有地形的一致性** |

- 与现实的关系是**间接的**（经转导 R7 输入的现实片段参与检验——但检验的主体是
  地形）——所以**支持性河道足的谣言能通过验证**（内部一致 = 判定为真——即使外部
  为假）；陌生真消息也能被判定为假（无支持河道——不兼容）
- 与 C90-01 一致：偏差 = 用河道强度代概率（判断真伪同样用河道一致性——代表性/
  可得性偏差正是"支持性河道足"的效应）
- **验证链条的输入源本身失真**（传播者的重建输出）——验证 = 用失真的输入检验
  一致性——"以讹传讹"的闭环：判断依据的河道本身就是传播产物

## 3. 要点 2：变形 = 读取-重组统一机制（谎言与真实无分别）

每次传播 = 一次读取-重组（R69——复现 = 模板实例化 + 剩余河道 + 噪声——记忆被
每次重建修改 R58）。**传播 = 表达决策（R73）+ 重建机制（R69）**：

| 偏离源 | 机制 | 意图 |
|---|---|---|
| 重建噪声 | 模板实例化误差（R58——侵蚀深度不均——修饰词槽位被替换） | 无意 |
| 重建偏向 | 趋利重建（R98——传播者记忆的价值偏向） | 半自动 |
| 故意修改 | 忠实度参数下调（R73——说谎 = 选择低忠实度） | 有意 |

**真实与谣言共享同一管道**（用户："没有分别"）——忠实度参数（R73）不是真假区分，
是**偏离控制参数**：真实消息传播 = 忠实度参数高但重建噪声仍使走样（无意的）；
谣言 = 忠实度参数低（有意的）+ 重建噪声叠加。"越传越走样" = **重建在每一跳
都叠加噪声**（误差累积——每次传播者都贡献一层变形）——真实消息同样越传越走样
（"传话游戏"——框架预测：真实消息传播同样指数变形——只有去重直引/转写才能保真——
转写 = 读取-重组的最小化——但仍非零）

**为什么传（转发的选择）**：转发 = 选择（⑤ R129）——价值注入 = 社交收益
（分享新信息 = 社交资本 R67/R82 地位——"我知道你不知道"）+ 情绪共鸣（R91 同理心
镜像——情绪内容转发冲动）+ 自我确认（R98——传播强化自我河道）。

## 4. 谣言完整链（三问闭合）

```
为什么信？  判断 = 地形内一致性检验（非现实对照）——支持性河道 → "真"
为什么变？  每次传播 = 读取-重组（R69）——重建噪声+偏向+故意——真实谣言无分别
为什么传？  转发 = 选择（R129）——价值注入 = 社交资本+情绪共鸣+自我确认
```

**与 R103 连接**：传播 = 博弈（R131 预测循环经转导耦合）——每条谣言 = 一串
"题目-参考答案"的变形传递——每个接受者把失真的输出当题目。
