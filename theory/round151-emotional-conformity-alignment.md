## 2. 情绪从众 = 无决策的自动对齐（环外机制）

```
他人的参考答案（输出）
  → 转导进入我的环（S2——R131）
  → 与我的预测/参考答案比较：误差 e
  → |e| < θ（偏差阈值）：直接修正我的参考答案——无评估无竞争——
     A1 平滑更新（D 小 = 正常预测修正）——【环外旁路——无决策级联的一种】
  → |e| ≥ θ：惊讶（R10 误差驱动——显著性）→ 进入决策环
     （候选：对齐/独立/部分对齐——评估——选择）
```

**情绪从众 = 决策环的旁路**（R120 边界——与恐慌/梦/幻觉同族：无决策级联）——
区别：恐慌 = g 失效的失控旁路；情绪从众 = **低误差的正常旁路**（系统设计的
默认对齐——R120 的"旁路级联"家族新增成员：**自动对齐**）。

**与 A1 的连续性**：对齐 = 预测更新的社会版——预测编码本来就"误差小时直接
更新预测"（R1——D = 现实−预测——平滑修正）——**他人的参考答案 = 我的"现实"的
一部分**（S2 博弈耦合——他人输出是环境输入）——所以对齐 = 预测更新的必然——
**不需要"从众机制"——只需要他人输出作为现实输入**（递归原则再收编）。

## 3. 偏差阈值结构（对齐 vs 决策的边界）

```
θ = 对齐阈值（个体参数——易受暗示性/亲和性——R56 性格参数）
  |e| < θ  → 自动对齐（无意识——快速——省 g）
  |e| ≥ θ  → 惊讶 → 决策环（慢——耗 g——但可拒绝）
```

**与 R10 同构**：注意闸门 = 误差驱动（显著性）——对齐阈值 = 社会版的注意闸门——
**低误差自动处理（省资源），高误差进入决策（耗资源）——这是框架的资源经济学
（R52 g 稀缺）在社会的应用**——为什么有情绪从众？因为大多数时候自动对齐
（抄答案）是**最优策略**（他人的参考答案 = 集体经验的压缩——R67 社会湖——
"抄答案" = 利用群体河道——C79 群体智慧——独立决策汇聚 vs 抄答案——抄 =
利用他人河道——省学习成本）。

## 4. 双从众关系（可能不同答案——升级机制）

| 面 | 机制 | 结果 |
|---|---|---|
| 情绪从众 | 自动对齐（环外——误差 < θ） | 快速——无意识——省 g——结果 = 对齐后答案 |
| 理性从众 | 决策（环内——误差 ≥ θ 触发） | 慢——意识——耗 g——结果 = 评估后答案 |

- **两通道可能结果不同**：自动对齐（大家都跑——我也跑）vs 理性评估（评估后——
  可能是"不需要跑"——但**结果不一定选理性**——因为决策环的评估 = 地形——
  C90 偏差/恐惧——可能仍选"跑"——用户："结果不一定选择理性"）
- **升级路径**：情绪对齐失败（偏差大）→ 触发决策 → 决策环处理——"从情绪激活到
  理性 = 整体开始决策"——**升级 = 从旁路到环**（R120 边界内的正常路径）
