# 第 122 轮：候选生成 = 目标引导的联想链递归展开（用户模型深化）

> 轮次：2026-08-17 · 第 122 轮
> 提出者：用户（"整体是以联想的方式进行的……关系链可以无限递归下去……什么时候停止——目的-不关心 + 焦点上限/分配上限"）
> 相关猜想：C107-01（新增，深化 C104-01）
> 状态：候选生成的实现机制确立（检索 → 联想链递归展开）

## 1. 用户模型（原话要点）

- **候选生成 = 联想链展开**：看到菜 → 属性（辣）→ 关于自己（能不能吃/好不好吃）→ 吃完后的利益/代价 →（聚餐）→ 自己的目的（判断关不关心）→ 关心 → 想到他人
- **关系链可以无限递归下去**（每个节点又是新联想的起点）
- **停止条件两个**：
  - ① 目的-贡献停止：比如"自己的目的-不关心他人" → 链断
  - ② 焦点（注意力）的上限 / 分配上限

## 2. 框架化：这是受目标引导的联想级联

联想 = 河道激活级联（R24——联想 = 河道激活级联；激活优先级 = 共现强度 × 锚定权重 R30）。
**候选生成 = 目标引导下的联想级联展开**——不是全向检索，是**受控的递归展开**：

```
决策目标（激活的目标河道，g 自上而下 R10）→ 决定展开方向
每个候选节点 → 沿联想河道展开（属性/自身/结果/社会层）
每个展开节点又可以是新联想的起点（递归——C16-01 尺度递归在决策内的应用）
```

- **方向控制 = g 自上而下**（R10）：展开不是全向的——"目的"决定往哪展开（聚餐时"关不关心他人"决定展开到他人还是停止）。**决策目标 = 展开的过滤器**。
- **"关心" = 价值权重**：关心他人 = 他人节点价值贡献高 → 剪枝判断"值得展开" → 展开；不关心 = 贡献低 → 剪枝 → 停止。

## 3. 双停止机制详解

| 停止条件 | 机制 | 与 R121 的关系 |
|---|---|---|
| **目的-贡献剪枝** | 每节点局部判断"继续展开的价值贡献"——贡献趋零 → 剪枝（"不关心 → 展开他人无贡献 → 停"） | **全局成本交叉的微观实现**：局部剪枝 = 每节点"边际收益 < 边际成本"判断；全局交叉点 = 所有节点剪枝的涌现统计（宏观聚合） |
| **g 预算上限** | 联想展开消费焦点资源（R10 单闸门单自由度——R52 焦点-信息耦合对）；**宽度（并行展开的链数）与深度（递归层数）都受 g 预算约束** | 补 R121 空缺：R121 只提了搜索时间（深度维），用户补了**分配维**（宽度维——g 同时只能支撑有限展开流） |

**R121 修正**：候选数 N ≈ 搜索时间 × 激活速率 → 扩展为
**N ≈ g 预算（宽度）× 展开时间（深度）× 每节点剪枝阈值（目的/价值）**
——三个因子，其中剪枝阈值是价值信号对展开的逐节点控制。

## 4. 递归无限性与"想太多"

- **理论无限**：联想链无天然终点（用户：可以无限递归）——递归展开是开放系统（R58 不完备性在决策内的回声：永远有新 G = 永远有可展开的新节点）
- **实际有限**：价值剪枝（目的不贡献就断）+ g 预算（资源耗尽就停）——**无限递归被两个有限器约束**
- **"想太多/停不下来"** = 剪枝判断失效：威胁干扰（R53——怕选错 → 每条链都"值得"展开 → 剪枝阈值被恐惧压低 → 展开无界）——与 R106 完美主义/犹豫同构（损失函数扭曲）
- **"心累"** = g 预算耗尽的体验面（R77 意志力 = g 资源——R91 崩坏——联想展开消费 g → 想太多 = 累）
- **走神 vs 专注**：目标松（低 g 集中度）→ 展开漂移出目标域（R48 无约束级联的轻量版——R120 边界内）；目标紧 → 展开受限在域内（专注 = 剪枝严格执行）

## 5. 与创造力的连接（R54）

**展开越过目标域 = 桥事件**：目标松驰时联想链跨界展开 → 新桥 → 创造力。
专注（目标紧）产出正确候选；松弛（目标松）产出新候选——**候选生成与创造力是同一展开机制的目标松紧两端**。
