## 1. 自我损耗理论（Baumeister 1998——"意志力像肌肉"）

**核心主张**：自我控制资源有限——使用会暂时耗尽——耗尽后后续自控表现下降。

**经典范式（双任务）**：
```
任务 1（消耗）：抵制巧克力只吃萝卜 / Stroop / 情绪抑制……
任务 2（测量）：解难题 / 持续手压 / 拼词……
结果：先做消耗任务者任务 2 表现更差（d ≈ 0.6 最初元分析——中等效应）
```

**机制解释**：单一资源池（最初假说 = 血糖 glucose——Gailliot 2007——后被推翻）。

**理论地位**：成为"意志力 = 资源"的教科书证据——框架 C77 曾引用它（g 预算——
"g 资源耗尽——崩坏 = g 资源耗尽"）。

## 2. 复现危机中的崩塌

| 研究 | 发现 |
|---|---|
| **Hagger et al. 2016（23 实验室预注册）** | 效应量 **d ≈ 0.04（接近零）**——大规模复现失败 |
| **Carter et al. 2015（元分析——校正出版偏倚）** | 漏斗图校正后效应接近零——原始 d≈0.6 是出版偏倚的产物 |
| **血糖假说** | Gailliot 2007 血糖研究复现失败——能量假说被推翻 |
| 现状 | 自我损耗 = 复制危机最著名案例之一（与启动研究并列）——部分实验室仍复现成功（异质性——特定范式可能仍有真实弱效应） |

**为什么失败**（可能原因）：
- 出版偏倚（只有显著结果发表——原始文献选择性地"成功"）
- 小样本（原始研究 n 小——效应量高估）
- p-hacking（数据挖掘出显著）
- **也可能：真实效应存在但极弱**（d < 0.1——需要超大样本才能检测）

## 3. 框架的消化：g 预算 ≠ 能量模型

**关键区分（三个东西不能混）**：

| 概念 | 状态 | 框架 |
|---|---|---|
| **g 真实消耗**（神经层面） | 真实存在 | R10 单闸门——注意力资源有限（瞳孔/前额代谢/任务切换成本——客观可测） |
| **"损耗感"**（自我报告的疲惫） | 复现失败 ≠ 不存在——但测量不可靠 | **可能是决策输出**（R60——"不想继续" = 价值评估变化——R152 同构："累感" = 权重变化非能量耗尽） |
| **"损耗效应"**（任务 2 表现下降） | 跨域复现失败 | 见 §4——近转移预测 |

**框架预测修正（P20）**：g 消耗 = 客观指标（任务切换成本/瞳孔扩张/前额代谢）——
损耗感 = 动机重估（决策环输出）非能量耗尽。

## 4. 关键洞察：能量模型 vs g 预算的区分预测（为什么复现失败支持框架）

| | 能量模型（Baumeister） | 框架 g 预算（R10/R123） |
|---|---|---|
| 资源性质 | 单一资源池（通用——任何自控共用） | 单闸门 + **模板特异**（g 分配按河道——C77 g 重分配——消耗 = 特定河道/域） |
| 转移预测 | **跨域转移**（任何任务 1 耗尽 → 任何任务 2 变差） | **近域转移**（同域/同模板族转移——跨域弱——R123 分配模式） |
| 复现失败解释 | 无法解释（理论预测跨域——实验没找到） | **预期**（跨域损耗本来就该弱——复现失败 = 框架预测被证实） |

**框架预测 P23：损耗效应 = 同域近转移**——任务 1 与任务 2 共享认知域/模板时
损耗存在；跨域时消失——**这解释了复现失败的异质性**（成功的复现 = 同域配对；
失败 = 跨域配对——Hagger 2016 的异质性与任务配对相关——可检验）。

## 5. 与框架的统一

- **"累"的完整机制** = g 真实消耗（客观——小）+ 动机重估（决策——大）——
  与 R152 从众统一同构（"自动感" = 权重——"累感" = 价值变化）
- **R95 当下主义**："继续与否"每次当下重估（R124 元决策——停止 = 评估输出）——
  损耗感 = 元决策的评估信号（"不值得继续" 的体验面）
- **意志力的重新定位**：不是"资源池的存量"——是 **g 分配策略的决策历史**
  （R123 分配模式——意志力 = 持续维持集中模式的元决策序列——C77 修正）
