## 1. 用户机制 = 框架三件套

| 用户步骤 | 框架机制 |
|---|---|
| 实词深/修饰词浅 | 侵蚀不均 = 锚定度差异（R30 实词有感觉锚定/修饰词抽象依赖语境——先侵蚀 R40） |
| 形容词位置被冲淡 | 浅河道被功能侵蚀（λW） |
| 结构完整选相近词 | 复现 = 模板实例化（R21 槽位必须填） |
| 近义词选择 | 扩散汇聚（R35 语义邻近激活——R60 候选竞争） |

**复现不是放录像，是重建**（模板 + 剩余河道 + 噪声）。

## 2. "选对词但记忆已错"

- 重建选择会**再沉积**（R42 重放=重构）——选中词强化、原词浅河道被覆盖
- **原记忆已被替换**——记忆在每次重建中被修改

## 3. 结论：记忆错误 = 重建的必然产物

- 非"存储损坏"——是**重建偏移**
- LLM 对比：KV cache 固定存储 vs 框架记忆每次重建（"根本不同"清单候选）

## 4. 框架预测

1. 修饰词最易记错（骨架对、细节换词）
2. 回忆次数越多偏移越大（每次重建再沉积）
3. 结构越强错误越少（模板稳定句子 > 自由结构——槽位预测强）
