> 相关猜想：C60-01（新增，补充 C53-01）

## 1. 用户论证 → 框架对应

| 用户论点 | 框架 |
|---|---|
| 生物 = 输入-处理-输出 | R7 边界函数化（T_in/T_out 两端） |
| 输入输出不可缺 | 感觉-运动闭环（R10）——生物 = 感知-行动环 |
| 缺输入/输出 = 死亡 | 生理学：循环停止 = 死亡——半环 = 非闭环 |

## 2. 为什么输入输出对体验重要

- 输入 = 误差来源（R1 注入扰动）——无输入 = 无变化 = 同步域静止 = 体验空洞（R52 时间感）
- 输出 = 行动反馈（闭环另一半）——无输出 = 无反馈环 = 非活环

## 3. 体验蛋最终形态

**体验蛋 = 边界函数（R7 输入输出）× 内部过程（同步域 R46）× 完整活环（R62 闭环）**
——三者缺一不可；体验 = 活的环的当下状态（回到 R1 首要动机）。
