## 2. 三个发现

**发现 1（学习域 = A2 的主场 + 框架的"元域"）**：所有学习现象 = **S5（记忆地形）×
A2（沉积-侵蚀）家族**的组合。更重要的是：**学习域是框架的"元域"——其他域的参数
全部由学习产生**：
- 社会域的参数（排斥敏感度/责任权重）= 学习域训练的
- 价值域的权重（生存权重/趋利偏向）= 学习域沉积的
- 认知域的河道密度（直觉/创造力的布局密度）= 学习域积累的
**表达式矩阵显示：其他域的"参数"列 = 学习域的输出**——学习域给所有现象提供参数，
这是补链 4 域后浮现的最高层结构。

**发现 2（学习域与 R120 决策环的循环闭合）**：学习域表达式 = S5 × L1 × A2——
而决策环五层（S1）的⑤反馈层 = 学习域——**S1 是学习域的用户，学习域是 S1 的
生产者**：环消费地形（S5）做决策，决策结果经反馈层更新地形（学习域）——五层环
与学习域构成闭合（R137 的 S1⑤ 反馈层 = 学习域在结构层的镜像——表达式证实）

**发现 3（学习的统一参数语法）**：学习域 5 现象的"参数"列高度统一——全部是
**河流量参数**（流量/写回速率/过水/沉积深度/侵蚀率）——学习 = 水流量的管理：
- 测试效应 = 流量控制（g 集中 → 目标河道流量大）
- 遗忘曲线 = 流量衰减（侵蚀率）
- 玩耍 = 主动过水（流量供给）
- 后天疾病 = 流量失败（过水失败/坏输入）
**与 v4 一致（水流是唯一直接机制——一切调制 = 流量间接控制）——学习域 = v4 的
直接应用区**
