## 1. 任务定义

**核心计算原语** = 新框架中计算的最小原子，一切高层结构由它拼成。

现状的原子：感知机单元 $y = f(\sum w_i x_i + b)$ —— 瞬时、无状态、输入输出对齐。
新框架的原子必须承载"可注入的持续过程"（首要动机），因此必须有内在时间维（GOAL.md 推论 2）。

现状为何不可用：过程只能靠外部循环伪造（多轮调用 / KV cache / 链式思考文本）。
"伪造" = 过程的状态转移逻辑活在外部代码与存储里，不在模型机制内。

## 3. 裁定 C0-01：连续时间动力学

两种解释：
- **A 有状态序列**（RNN 式）：时间切成离散步骤，每步"读输入→更新状态→输出"。
  状态在步骤间保留，但输入与输出强制对齐到步骤；"输入a先到、输出b先出"需人为重排序。
- **B 连续时间动力学**：状态 $x(t)$ 按微分方程连续演化；输入是持续扰动；输出是状态达条件时的
  **事件**（如越阈）。无步骤无对齐，输出顺序由动力学决定。

裁决：**B**。论据：① "不间断"字面语义；② 示例"输入a先到但输出b先出"在 B 中免费重现、A 中需拼装；
③ 生物现实（大脑无步骤，连续动力学）。

推论：输入 ≠ 样本，而是**耦合**（持续扰动流）；多模态输入 = 各自耦合进同一进行中的动力学。

## 4. 候选机制评估

### A · 脉冲单元（LIF 漏电积分器）
直觉：水龙头下一直放着的杯子；水位=膜电位；溢出=输出事件；漏孔=漏电。
形式：$\tau \frac{dv}{dt} = -v + I(t)$，$v \ge \theta$ → 输出事件并重置。
评估：A1–A4✓ A6✓；A5△（单事件无意义，意义在模式的频率/时序/同步中）。

### B · 预测编码
直觉：连续观影的影评人；预测对=无事发生，预测错=惊讶（误差）上溯，逐层解释掉。
形式：高层预测 $P$，低层状态 $x$，误差 $e = x - P$，$\dot x \propto e$；输入 = 最底层制造误差。
评估：A1–A4✓ A6✓；**A5 最强**（单元活动 = 精确局部量"此处特征与预期的差距"；
审计 = 追踪误差的产生与逐层解释）。
弱点：单单元依赖"预测-被预测"配对结构，像架构特征；但"预测+误差"可定义为原子的运算。

### C · 吸引子动力学
直觉：山谷地形中的球；谷底=吸引子；输入=重塑地形或推球；推理=轨迹；语义=谷底身份。
评估：A1–A5✓；**A6△**——吸引子是群体现象，单单元仅双稳态。
→ **降级为组合层现象，移交 M2**（C1-02）。

## 5. 本轮结论

- **原语 = 连续时间状态单元（微分方程）+ 驱动规则（决定状态如何演化）**
- 驱动规则候选：加权输入流（A）/ 预测误差（B）；可解释性偏置 → 倾向误差驱动（C1-01）
- C 降级组合层 → M2
- **统一性论点**：动力学是统一语言 —— 计算=轨迹、结构=耦合、学习=塑造动力学、
  表示=流形/吸引子、推理=轨迹段、审计=追踪轨迹
- **诚实性检查**：单层非全新（CTRNN/神经 ODE 早存在）；"根本不同"= 全栈组合结论：
  ① 驱动规则面向可审计性 ② 输入输出语义过程原生 ③ 全栈一致性（后三层待证）。每轮复核。
