## 2. 用户的递归主张（框架化）

> "焦点像不断滴落的水珠，信息的布局/整理是平面上的水滩，没有水的地方是未知"

| 用户意象 | 框架 |
|---|---|
| 水珠（焦点） | g——注意（R10——不断滴落 = 焦点持续迁移） |
| 水滩（信息布局） | 地形（已建立河道的关系结构——R5 沉积的"已知"区域） |
| 无水处（未知） | 无河道区（未学习区域——预测失败 = 惊讶 = 误差） |

**递归 = 焦点-地形动力学的必然**：

```
水滩（已知）有边缘（未知区）
  → 边缘 = 新奇（R10 误差驱动——未知 = 预测失败 = 惊讶——自下而上吸引）
  → 焦点（水珠）被吸引到边缘滴落
  → 沉积（R5——新河道建立——水滩扩大）
  → 新边缘出现（已知区永远有限——R58 开放系统——不完备性）
  → 再滴落……（无限循环 = 递归的生成性）
```

**递归的无限性 = 三个公理级事实的推论**：焦点持续存在（g）+ 地形有限（已知有限）+ 未知永远存在（R58 开放系统不完备）——**不需要先天规则（Chomsky）、不需要 h₀ 结构偏好（R147 假设）——只需要焦点-地形动力学本身**。

**与 R58 统一**：认知层级突破循环（必然→黑天鹅→重构→新必然——永续）= 同一"边缘追踪"动力学——递归（语言/认知）= 水滩扩张的必然形态。

## 3. 递归 = 通用认知动力学（消解"人类特异"）

Chomsky 认为递归 = 人类独有（Hauser, Chomsky & Fitch 2002——"唯一人类特异的认知能力"）。
**框架消解**：递归 = 焦点-地形扩展的必然——**任何有焦点迁移 + 地形学习的系统都有递归**
（动物也有——如乌鸦的嵌套工具使用/海豚的序列学习——只是表达通道不同）——
语言递归 = 通用递归在表达转导层（A6）的体现——**"人类特异" = 表达通道的复杂度
（语音/手势的转导精细度——A6 差异）非递归机制本身**。

**预测 P15**：动物嵌套行为能力 ∝ 焦点迁移效率 × 地形扩展速度——可测（乌鸦/海豚
嵌套行为与注意灵活性相关——如果注意灵活性高的个体嵌套能力更强 = 支持）。
