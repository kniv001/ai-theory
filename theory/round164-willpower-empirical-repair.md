## 1. 开口回顾：C77 的实证面

自我损耗（Baumeister）大规模复现失败（Hagger 2016——d≈0.04）——能量模型垮台——
框架换锚（P20：g 消耗 = 客观指标）——但 P20 本身未验证——**"意志力 = g 预算"
在行为层仍无可靠实证**。

## 2. 客观指标盘点（复现稳健——与自我损耗形成对比）

| 指标 | 内容 | 复现稳健性 |
|---|---|---|
| **瞳孔扩张**（Beatty 1982） | 任务难度/认知负荷 → 瞳孔扩张——客观负荷读数 | ✅ 稳健（经典且复现多） |
| **任务切换成本**（Rogers & Monsell 1995） | 任务切换时反应时增加——g 重新分配的代价 | ✅ 稳健 |
| **前额叶代谢**（精神疲劳 fMRI——Boksem 2006 等） | 持续认知任务 → 前额激活变化/代谢消耗 | ✅ 稳健（mental fatigue 领域） |
| **神经振荡变化** | 疲劳 → α/θ 功率变化 | ✅ 稳健（疲劳 EEG 领域） |

**关键对比**：这些客观指标**全部复现稳健**（vs 自我损耗的行为效应失败）——
**"资源消耗"的客观面真实存在——失败的是"行为表现下降"的跨域转移**
（P23 近域转移——同族）。

## 3. P20 精确化：三分离

```
g 消耗（客观）——真实存在（瞳孔/切换成本/代谢——稳健指标）
损耗感（自我报告）——≈ 决策输出（元决策——R124："不值得继续"的评估信号）
行为下降（任务 2 表现）——近域转移（P23——同域存在/跨域消失）
```

**"累" = 元决策环的输出**（R124——停止 = 评估输出）——与 R152 从众统一同构：
"自动感" = 权重差距（决策快速收敛）——**"累感" = 价值重估**（继续的收益下降/
成本上升 → 输出"不值得继续"）——损耗感不是资源读数，是决策信号。

## 4. 自然检验：心流（P28）

**心流（Csikszentmihalyi）**——专注投入时"不觉得累"——即使客观消耗极高：

```
心流 = g 高消耗（客观——瞳孔/代谢应高）× 价值高（R60——任务值得——动机）
     → 元决策输出"继续"（不累）
无聊 = g 消耗低（客观）× 价值低 → 元决策输出"停止"（累——"不值得"）
```

**框架预测（P28）：心流任务中客观指标（瞳孔/代谢/切换成本）高——但自我报告
疲劳低——客观与主观分裂**——"累" = 决策（价值重估）非资源读数：
- 心流：客观高 + 报告不累
- 无聊（同等任务量）：客观低/中 + 报告累
- **可测**：双测量实验（心流任务 vs 无聊任务——等时长——客观 + 报告）

**这与能量模型的决定性区分**：能量模型预测"消耗高 → 报告累"（资源→感觉线性）；
框架预测"消耗与感觉可解耦"（感觉 = 决策——由价值调节）——**心流 = 能量模型
的反例 + 框架的预测案例**。

## 5. 验证设计（若执行）

```
任务 A（心流）：高兴趣游戏/演奏（进入流状态）
任务 B（无聊）：等时长重复单调任务
测量：瞳孔（客观负荷）+ EEG（前额代谢代理）+ 自我报告疲劳 + 继续意愿（元决策输出）
预测：A：客观高 + 报告低 + 继续意愿高
     B：客观低/中 + 报告高 + 继续意愿低
     → 客观-主观解耦 = P28 兑现（能量模型预测耦合——框架预测解耦）
```
