**记忆修改权 = 生存信号（R36 威胁警报）vs 趋利信号（R8）竞争**：
- 生存警报 > 趋利 → 记忆被保护（强标记——PTSD）
- 趋利 > 生存警报 → 记忆被修改（美化/淡忘——趋利重建）

## 3. 可修改性谱（统一 R19/R76/R98）

生存接近度（R19）越高 → 修改权越低（被保护）；
越低 → 修改权越高（可趋利修改）。
**生存威胁 = 记忆修改的禁区**（修改 = 忘记危险 = 死——R76"生存正确"）。
两机制不冲突——同一竞争的两种结果（信号强度决定）。
