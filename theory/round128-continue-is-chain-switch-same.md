# 第 128 轮：继续 = 换链的特例 — "选择"原语的跨尺度递归（用户统一）

> 提出者：用户问题（"继续和换链是否为同源——继续是深入当前链，换链是在原节点之上深入另一链——继续是否是一种特殊的换链"）
> 相关猜想：C113-01（新增——统一 C112-01 输出空间）

## 1. 用户统一主张

联想展开 = 树（R122 递归展开）。当前站在节点 N，可展开分支 {B1…Bn}：

- **继续** = 沿当前分支 Bi 深入（选当前分支）
- **换链** = 从 N 选另一分支 Bj（j≠i）深入（**同样在"原有开启的节点"之上**）

**两者是同一个操作**：从当前节点选一条分支深入——区别只是选哪条。
**继续 = 换链的特例（换到当前分支）——用户主张成立。**

## 2. 为什么"继续"是默认？（激活梯度）

- 当前分支 Bi 正处于激活态（联想级联自然延续——R30 激活优先级 = 共现强度 × 锚定权重）
- → 评估默认选中 Bi（激活强度自然最高——无需重新分配 g）
- **继续 = 跟随激活梯度**（低代价默认输出）
- **换链 = 偏离激活梯度**（需显式激活新分支 Bj——重新分配 g——R123）

所以区分变量（R127 的 g 消耗率）的根源 = **激活梯度**：
继续的 g 消耗低是因为"跟着梯度走"，换链的 g 消耗高是因为"逆着梯度拉"。

## 3. 输出空间再简

```
元决策输出空间（最终）：
  {停止 / 选择分支}
    选择分支-当前（继续）= 跟随激活梯度——默认——低 g
    选择分支-其他（换链）= 偏离激活梯度——显式——高 g
    停止 = 不选（结束展开）
```

| R125 | {继续/停止/随机/委托/转向} |
| R126 | {继续/停止/委托/转向} |

**停止也可看作"选终止分支"**（树出口）——但保留特殊性（g 释放、信息停止、R127 记账不同）。

## 4. 深化："选择"原语的跨尺度递归

**决策环本身 = 分支选择的宏观版**：

```
决策环（R120）   = 候选竞争——在行动候选间选择（宏观——候选 = 分支）
元决策（R124）   = 继续/换链——在联想分支间选择（微观——分支 = 候选）
→ 同一"选择"操作在两个尺度——C16-01 尺度递归的又一应用
```

**统一：思考 = 决策的微观实例**——R124"思考 = 决策环的输出"现在获得对称面：
**决策 = 思考的宏观实例**（行动候选竞争 = 联想分支选择的放大）。
决策环以自身为内容（R124 元决策族）→ **递归在"选择"处闭合**：
内部的选择（思考）与对外的选择（行动）是同一原语。

**递归原则收编到最底层**：从 R120 的"一切机制 = 决策环实例化"，再进一步：
**一切选择 = 分支选择原语**——思考（内部分支）与行动（外部候选）不分家。
思考-行动的边界 = 输出转导（R7——内部选择经 T_out 成行动）——"想"与"做"的
区别 = 是否过转导层，选择机制相同。
