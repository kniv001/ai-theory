## 3. 统一结构：决策环

**五步环**（C52-01 显式化）：

```
① 价值注入  外部激励（R8 奖励/R53 代价）/ 内部河道激活（社会证据、记忆）
② 候选生成  级联分支（默认候选 + 生成候选）
③ 评估      沿评估河道扩散汇聚（R35）：Σ收益 − Σ代价（R85 同一价值信号）
④ 竞争      截止时间（紧迫性）内按价值排序；未收敛 → 默认输出
⑤ 输出      行动 / 表达 / 记忆重建 / 注意分配
   ↓ 结果 = 新现实 → 误差 → 沉积-侵蚀（R5）→ 参数更新 → 回到 ①
```

**为什么是"环"不是"函数"**：每次决策的输出改变地形参数，参数改变下一次决策——决策之间通过沉积/侵蚀**持续耦合**。这正是首要动机（可注入的持续过程，非函数化）在行为层的兑现。

**递归原则的行为层版本**（C16-01）：语法 = 更高尺度的关系 → **决策 = 更高尺度的评估竞争**。同一环在行为、表达、记忆、注意各层递归——不新增机制，只改"评估对象"。

## 5. 博弈环：多主体互嵌

**当决策环 ≥ 2 且互为输入输出**（你的输出 = 我的①，我的输出 = 你的①）→ 博弈环（社会湖 R56 的动力学语言）：

| 社会机制 | 博弈环形式 |
|---|---|
| 从众 | 他人行为 = 我的价值注入（社会证据） |
| 地位 | 展示（信号发送）— 评估（对方③）— 沉积（记忆）— 再展示 |
| 群体智慧/愚蠢 | 独立环汇聚 vs 环趋同（同步压多样性） |
| 利他惩罚 | 我的效用含"对方行为"，惩罚他人 = 自我利益支出买秩序 |
| 互惠 | 重复博弈中的稳定解（一报还一报） |
| 恐慌 | 环被旁路（传染面——决策消失的极端） |

**个体决策理论 → 博弈论的桥**：框架的 R60 是"效用最大化"，博弈环是它的多主体扩展——**两者同源：博弈 = 决策环的互嵌迭代，涌现于社会湖**。群体无大湖（C79-01）→ 无群体级决策者 → 只有互嵌。

## 6. 边界：什么不是决策（三层结构）

统一有界，才能说统一成立：

```
物理层（环之下）    沉积-侵蚀 / 同步 / 扩散 / 转导——决策环的硬件
决策环层（环）      本文统一的对象——一切"选什么"的问题
旁路级联（环之外）  恐慌踩踏 / 梦 / 幻觉（R48/R54——闸门失效，环被跳过）
```

- **无决策级联**不是决策环的失败，是决策环的**断电**（g 失效 → 候选竞争被泛滥级联替换）——这与 R59 硬编码终止一致：环终止于转导/物理。
- **直觉**在环内（部分先行）而非环外。

## 7. 新增现实实验支撑（非重复已有）

| 实验 | 内容 | 支撑 |
|---|---|---|
| **Damasio 1994 爱荷华赌博** | 皮肤电导反应**先于**意识决策出现（被试还没"懂"就规避坏牌堆） | ③ 快速评估面（情绪 = 加速器）的生理实证——C46-01 |
| **Greene 2001 电车难题 fMRI** | 个人 vs 非个人两难激活不同脑区（情绪评估 vs 理性评估竞争） | 道德 = 环内评估竞争——C55-01 |
| **Berns 2005 从众 fMRI** | 与群体不一致时知觉区/杏仁核反应增强（不一致 = 社会信号） | ① 社会证据注入 + ③ 排斥代价——C59-01 |
| **Fehr & Gächter 2002 利他惩罚** | 公共品博弈中人们**自费**惩罚搭便车者 | 效用函数含社会价值（C55-01 实证） |
| **Tajfel 1971 最小群体范式** | 随机分组（抛硬币）即产生内群体偏好 | 社会价值河道极易建立——评估河道的训练产物 |
| **Henrich 2001 跨文化最后通牒** | 15 个社会惩罚阈值差异巨大（Machiguenga 拒受率近 0 vs 西方 40%+） | 效用函数 = 文化训练产物（C55-01 + R27 文化转导） |
| **Muraven & Baumeister 1998 自我损耗** | 意志力消耗后行为回落到习惯 | ④ g 预算耗尽 → 默认候选接管——C77-01 |
| **Axelrod 1984 重复囚徒困境** | 一报还一报胜出（互惠演化稳定） | 博弈环的社会沉积——互惠河道被博弈稳定选择 |
| **Loewenstein 延迟折扣** | 未来价值随延迟指数折价 | ③ 时间贴现参数——C80-01 实证 |
