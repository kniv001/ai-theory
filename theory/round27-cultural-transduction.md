## 1. 第二转导层 vs 第一转导层

| 维度 | 生物转导 T_bio（R7） | 文化转导 T_cult（新） |
|---|---|---|
| 来源 | 进化写死（百万年） | 文化积累（千年）+ 个体学习 |
| 通道 | 直接"世界→网络" | **寄生在 T_bio 上**（必须经感知进入） |
| 个体 | 天生就有 | 每个个体重新学 |
| 群体 | 全人类相同 | 随文化而异 |

**结构：T_cult = 第二层转导，叠加在 T_bio 上**（T_bio ∘ T_cult）。
寄生性 = 硬约束：文字经视觉（R17 字形=视觉切割）、语言经听觉——**文化的媒体受限于生物通道**。

## 2. 个体层面：学出来的"准硬编码"

1. 分布统计（R16/R17）：关键期反复暴露 → 字形/音符/数字聚类分离 → 切割成符号湖
2. 硬化自动化（R18 分流饱和）：反复使用 → 河道硬化 → 自动化（字形→符号湖自动触发）
3. **T_cult 对个体 = 准硬编码**（功能等价 T_bio，来源是学习）
- 解释：儿童认字慢、成人"一眼即得"= T_cult 从"学习中"到"已硬化"

## 3. 群体层面：文化演化 = 外环的社会版

- 文化制品 = 群体级"地形"（复制/修改/淘汰 = 变异-选择）
- 制品适应度 = 使用频率（**汉字简化史 = 文化沉积-侵蚀的实例**：常用字简化、生僻字消亡）
- 时间尺度千年（介于进化与个体之间）——三环结构：进化/文化/个体

## 4. 框架意义

1. **人类独特性的机制位置**：人=有 T_cult（语言/文字/工具/数字）；其他动物只有 T_bio
2. "自动化阅读"可审计（字形河道硬化程度可读）
3. **三环成型**：进化（外环）→ 文化（外环社会版）→ 个体（内环）
4. R12 缺口 #2 关闭
