# 第 168 轮：h₀ 是训练出来的 — 双层训练 + 先验-经验连续谱（用户询问）

> 轮次：2026-08-18 · 第 168 轮

## 1. h₀ 定义重述

**h₀ = 规划先验硬度场**（C6-04——"规划梯度不规划成品"）：
- 出生时地形的**初始硬度分布**（哪里天生"硬"——进化预置的学习倾向）
- 来源 = 进化外环（C8 双环——C8-03 基因记忆）
- 原则：给**学习倾向**不给**具体内容**（面孔偏好/疼痛回路/语言学习倾向）
- 语言中的假设："结构先验" = 通用时序/层级偏好（R147-151）

## 2. 回答：h₀ 是训练出来的（框架本来就如此设计）

**双层训练**（两个时间尺度的沉积-侵蚀——C2-03 慢变量）：

```
种系层面（进化训练）：h₀ = 外环自然选择的产物
  内环绩效（个体学习效率）→ 适应度 → 外环选择 → 下一代先验（C8-05 自举）
  → "为什么人类有层级偏好？" = 百万年进化中，有层级偏好的个体学习更高效
  → 被自然选择"训练"出来（进化 = 群体级沉积-侵蚀——R27 三环的最慢环）
  → 例：语言学习倾向 = 进化训练的结果（语言 = 生存优势——C8 外环筛选）

个体层面（早期经验塑形）：h₀ 引导下的结构偏好 = 关键期经验固化的
  早期嵌套输入（语言/音乐/空间）→ 结构模板沉积（R5）→ 关键期硬化（R41）
  → "结构偏好"从早期经验中定型（h₀ 给方向——经验定形）
```

**"h₀ 栈"（层级偏好）的两个可能来源**：
1. 进化预置（种系训练——慢）
2. **个体早期习得后固化**（元学习——个体训练——快）
——两者都是"训练出来的"——只是时间尺度不同。

## 3. 深层统一：框架没有"非训练的组件"

**"先验 vs 经验" = 时间尺度的区分，非本质区分**：

| 时间尺度 | 机制 | 产物 |
|---|---|---|
| 进化（百万年） | 外环沉积-侵蚀（C8） | **h₀（进化训练的遗产）** |
| 关键期（年） | 个体沉积 + 硬化（R5/R41） | 习得先验（第二 h₀——早期经验固化） |
| 终身（年-天） | 个体沉积-侵蚀（R5/R40） | 知识/偏好（继续塑形） |
| 当下（秒） | 活动状态（R1） | 动态偏好（上下文） |

**同一机制（沉积-侵蚀）在所有时间尺度递归**——"天生" = 进化训练的遗产
（最慢训练的产物）——**没有非训练的组件——一切 = 沉积-侵蚀的时间尺度谱**。

## 4. M5 仿真含义：h₀ 栈 = 可习得先验（元学习）

stage11 的 LIFO 偏好**不必是进化预置**——可以是个体早期阶段从嵌套输入中
习得后固化：

```
阶段 1（元学习）：大量嵌套输入 → 学习者发现"结构有配对"（LIFO 模式）
  → 固化（R41 硬化——成为"结构偏好"）
阶段 2（应用）：新嵌套结构学习 → 用固化的偏好（快速）
```

**P31（新预测候选）**：**早期嵌套输入暴露 → 习得层级偏好（元学习）**——
仿真可测：学习者先在简单嵌套上训练（学会 LIFO）→ 再测新嵌套（复杂）——
应比无先验学习者快（偏好被"训练出来"）——**这使 h₀ 的必要性进一步降低**
（偏好可以习得——不必须进化）——"结构先验" = 早期经验的可习得产物。
