## 2. 修正："随机"不是输出，是外部事件的认知标记

R125 输出空间 {继续/停止/**随机**/委托/转向} 有错——**内部从不产生随机输出**。
内部只会"委托"（引入外部源）。真正的随机性只存在于：

```
现实世界事件（硬币落地/骰子/他人选择）
  → 内部无法预测其规律（预测河道无误差可建）
  → 判定为"随机"
```

**"随机" = 认知标记**（对不可预测性的标记）——与 R45 完美镜像：
- **必然 = 统计必然**（零误差普遍河道——可预测）
- **随机 = 统计随机**（零可预测性——无河道可建）
- 两者都是认知对世界规律性的标记，不是世界的绝对属性
- 用户已点出：现实世界也不存在绝对随机（物理决定论/量子概率）——"随机"连在外部
  也是近似标记（我们的预测能力极限），不是世界的本体属性

**输出空间修正**：{继续/停止/**委托**/转向}——"抛硬币" = 委托的表象，
不是随机生成。内部三个出口（继续/停止/委托）+ 转向，全部确定性。

## 3. 抛硬币 = 三个决策环的嵌套序列

```
决策 1（元决策）：输出"委托"——引入外部随机源
  （产生"抛硬币"的想法 = 决策成果——与放弃同类：排序失败/价值接近 → 降级委托）
  ↓
事件：硬币落地（现实世界强加——唯一"判为随机"的部分）
  ↓
决策 2：接受 vs 拒绝 vs 再委托
  （"看正反后是否说服自己" = 决策环）
    评估：硬币结果 vs 内部预测（抛前的偏好——R8 期望信号）
    → 误差（失望/满意）= RPE（R8）→ 价值重新评估
    → 输出"接受" = 结果成为决策参数 / "拒绝" = 再委托 / "忽略"
```

**"要不要再抛一次" = 决策 2 输出"拒绝"**（RPE 负——硬币结果与偏好不符）——
R121 的"偏好探针"获得完整机制：不是"抛时暴露偏好"，是**决策 2 的 RPE 评估**：
失望 = 负 RPE = 硬币结果价值低 → 拒绝 → 再抛——直到结果与偏好一致（正 RPE → 接受）。

## 4. 硬币 = 决策环 ① 价值注入环节的外部化

R120 环的第一步是"价值注入"。抛硬币 = **把价值注入外包给外部事件**：

```
正常：① 内部河道激活 → 价值（自给自足）
抛硬币：① 外部事件 → 结果 → 与内部预测比较 → 误差 = 价值信号（R8 RPE）
       ——硬币不是决策者，是价值信号的来源——决策者永远是内部环
```

**完整图景**：抛硬币看似"放弃决策"（R125），实际是**把价值评估委托给外部**——
环继续正常工作（③ 评估 ④ 竞争 ⑤ 输出），只是 ① 的注入源变成了外部事件。
"说服自己" = 决策 2 把外部结果整合进评估河道（沉积 R5——"硬币说去 A 我失望"→
A 的河道被负 RPE 修正——下次决策 A 价值已变）。

## 5. 与委托的统一（修正 C110-01）

| 委托对象 | 例子 | 机制 |
|---|---|---|
| 外部随机源 | 抛硬币/掷骰子 | ① 注入外部事件结果（RPE 比较） |

**三者同构**：委托 = ① 价值注入环节的外部化——输出空间从"三变体"进一步
简化为**一个委托出口 + 三种委托源**。C110-01 中"随机"出口删除。
