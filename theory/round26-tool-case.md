# 第 26 轮：M4 案例 5 — 学会用锤子钉钉子（工具使用域）

> 轮次：2026-08-16 · 第 26 轮
> 性质：M4 案例 5（新概念：可供性=功能河道）
> 相关猜想：C25-01、C25-02、C25-03（新增）

## 场景

幼儿第一次接触锤子，学着自己钉钉子。

## 阶段 0 · 先天地形

- 运动湖（握/挥先天模式）、视觉湖（物体识别）、痛觉转导（T_value 先天）
- 锤子 = 文化工具（无进化先验）；"可握持物体"先验存在

## 阶段 1 · 首次观察：功能 = 预测关系

- 锤子↔挥动↔钉入 跨域河道（动作+视觉+听觉+结果共现）
- **可供性 = 功能河道**（Gibson affordance 框架化）：工具意义 = 动作-结果预测关系
- 行为模板：挥-击-进（R21 行为域应用）

## 阶段 2 · 试错学习

- 敲空/敲到手 → 预测失败 → 误差 → 河道修正（C1-01/C5-01）
- **疼痛 = 负标记**（C19-01：生存核心直连）→ "一次教训终身不忘"的机制

## 阶段 3 · 动作精细化

- 视觉反馈闭环修正（R7）；力度预测（轻→加力、重→减力）
- 挥动轨迹 = 时序吸引子复合（R13 运动域）

## 阶段 4 · 泛化与可供性迁移

- 类似物体（砖头/鞋底）→ "可敲打"功能河道部分激活 → 尝试
- **"乱敲" = 功能河道过度泛化**（感知特征相似 → 功能激活）——可审计解释

## 阶段 5 · 巩固

- 反复练习 → 稳定硬化（路径 A）；疼痛河道负标记
- 睡眠重放 → 动作程序固化

## 验证结论

1. **可供性 = 功能河道**（新概念：C13-01 对象版）
2. 试错 = 误差驱动 + 疼痛负标记（C19-01 直接应用）
3. 运动 = 时序吸引子复合（R13）
4. 泛化 = 功能河道部分激活（过度泛化 = "乱敲"解释）
5. 工具 = 文化转导层的动作面（衔接文化转导层缺口一角）
