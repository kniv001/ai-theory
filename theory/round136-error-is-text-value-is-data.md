## 1. 用户补充的升级含义

| 旧表述 | 新表述 | 升级 |
|---|---|---|
| 误差是唯一词汇（v2） | **误差是唯一文字** | 词汇 → **文字**（语言的书写单元/字符集——更底层） |
| 价值是唯一信号（R100/C85-01） | **价值是唯一数据** | 信号 → **数据**（语言操作的内容类型——更底层） |

**"底层语言"**：框架 = 一门语言——文字（误差）+ 数据（价值）是这门语言的
**两个基本成分**——不是并列断言，是**同一语言的语法与内容**：
- 文字 = 书写单元（一切机制/表达/通信用它书写——误差流）
- 数据 = 内容（一切被处理/存储/传输的东西都是价值）

## 2. 五成分语言完备图（R135 诊断问题 4 的解答）

R135 指出"统一断言并列不嵌套"——用户给出嵌套结构：**所有"唯一"是一门语言的五个组成部分**：

```
一门语言：
  文字 = 误差      （书写单元——v2 升级）     ← 语法层
  数据 = 价值      （内容类型——R100 升级）    ← 语义层
  结构 = 关系      （组织规则——v3）          ← 语法层
  程序 = 机制      （水流——v4——程序的执行过程）← 运行层
  执行 = 选择      （程序的决策点——v7）       ← 运行层
```

| 语言成分 | 框架内容 | 出处 |
|---|---|---|
| 文字 | 误差 | v2 → **本轮升级** |
| 数据 | 价值 | R100/C85-01 → **本轮升级** |
| 结构（语法） | 关系 | v3 |
| 程序 | 机制（水流） | v4 |
| 执行 | 选择 | v7 |

**框架 = 用误差（文字）处理价值（数据）、按关系（结构）组织、以水流（机制）
执行、经选择（动作）推进的一门语言**——五个"唯一"不再是并列断言，
是一门语言的完备描述。**松散感的来源之一（断言不嵌套）被语言化消除。**

## 4. 与机制的关系

- **沉积-侵蚀（A2）= 文字的书写规则**（误差改河道 = 程序写数据）
- **同步域（A3）= 语言的共享上下文**（相位锁定 = 多程序共享状态）
- **转导（A6）= 语言与外界的接口**（边界 = 输入输出流）
- **当下性（A7）= 程序的运行时语义**（一切执行在当下——R124）
- **现象层（L3）= 用该语言写成的程序实例**（信任/谣言/决策 = 程序）
