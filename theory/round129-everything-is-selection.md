## 1. 用户裁决

输出空间不再有分支——全部合并为一个模块：**选择**。
继续 = 选择当前分支；换链 = 选择其他分支；停止 = 选择终止分支——都是选择。

## 3. 选择模块 = 决策环的别名（非更小原语）

选择不空洞：必须绑定候选集与评估——

```
选择模块 = {候选激活（R122 联想展开——候选从哪来）
          + 价值评估（R123 排序——为什么选它）
          + 选择输出（挑一个）}
```

**这正是决策环的五步**（注入/生成/评估/竞争/输出——R120）——选择不是更小的原语，
是环的别名：五环节都是"为选择服务"的过程。所以"合并为选择"的准确含义：

**元决策 = 决策环 = 选择——它们本来就是一个东西**（R124 元决策族 + R128 跨尺度
同构 → 完全合并）。选择 = 唯一输出；环 = 选择的完整过程。

| 版本 | 论点 |
