# 第 130 轮：决策环分层 — 树（数据）/ 竞争（服务）/ 选择（行为）+ 注入与沉积（用户结构视角）

## 1. 用户三层（确认）

| 层 | 内容 | 框架对应 |
|---|---|---|
| **数据层** | 树状关系图 | 联想展开树（R122/R128——候选域——"有什么可选"） |
| **服务层** | 代价/利益竞争 | 候选级联竞争 + 价值排序（R60/R123——"为什么选它"） |
| **行为层** | 选择模块 | 选择原语（R129——"选什么"） |

用户的划分 = 经典三层架构类比（数据/业务逻辑/表现）——决策环的**结构视角**。

## 2. 缺失的两层（环要闭合必须有）

| 层 | 内容 | 框架对应 |
|---|---|---|
| **输入层（信号/价值注入）** | 代价/利益的**来源** | R120 环①：内部价值河道激活（R85——河道强度即价值）/ 外部注入（R126 硬币/委托——①外部化）/ 社会证据（R70）/ 身体稳态（R36）；竞争的前提 = 代价/利益数据在场——**"竞争什么"由注入决定** |
| **反馈层（沉积-侵蚀/学习）** | 选择结果 → **树更新** | R5 沉积-侵蚀 + R40 侵蚀双层化 + R41 硬化——选择 → 结果 → 误差 → **树生长/断流/剪枝**（新分支/硬化河道/废弃分支）；**没有这一层，树是静态的，环不闭合，学习不发生** |

**补充理由**：用户三层 = 静态计算视图（数据→处理→输出）。但 R120 环 = 持续过程
（输出→沉积→参数→下次决策）——**树不是固定输入，是被选择结果持续修改的地形**。
"学习"发生在反馈层；"动机"来自输入层。缺这两层，环是开环的（LLM 式单次前向），
闭环（持续过程）才是框架的本质（R120/R124 首要动机）。

## 3. 完整五层 + 与五步环映射

```
① 输入层（价值注入）     —— 代价/利益信号在场（R85/R126/R70/R36）
② 数据层（树状关系图）   —— 候选域（R122/R128——联想树）
③ 服务层（代价/利益竞争） —— 评估排序（R60/R123）
④ 行为层（选择模块）     —— 输出（R129）
⑤ 反馈层（沉积-侵蚀）    —— 结果→误差→树更新（R5/R40/R41）→ 回到②
```

| R120 五步环 | 分层 |
|---|---|
| ① 价值注入 | 输入层 |
| ② 候选生成 | 数据层（树的展开） |
| ③ 评估 | 服务层（竞争的前半） |
| ④ 竞争 | 服务层（竞争的后半） |
| ⑤ 输出 | 行为层 |
| （⑤ 后）沉积-侵蚀 | **反馈层**（补） |

## 4. 分层意义

- **树的"形状" = 数据层**——候选域随经验生长（R5——树不是先验的，是沉积产物——
  R2-02 结构涌现的树版本：**树状关系图是训练产物**）
- **竞争参数 = 服务层**——代价/利益的权重（R123 排序——g 分配序）
- **选择 = 行为层**——唯一动作（R129 v7）
- **注入源 = 输入层**——价值从哪来（内部/外部/社会/身体）
- **沉积 = 反馈层**——闭环 + 学习（树的生长机制）
- **时间参数**（R105 截止/紧迫性）= 服务层的属性（竞争的时间窗——服务层内）
- **转导边界**（R7）= 输入/行为层与外界接口（数据进出）
