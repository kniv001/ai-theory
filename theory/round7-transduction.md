# 第 7 轮：输入/输出转导 — 边界函数化，内部过程化

> 轮次：2026-08-16 · 第 7 轮
> 提出者：用户（输入/输出思考）
> 相关猜想：C7-01 ~ C7-04
> 状态：转导层形式化完成；T 规格与顶向下调制 → 后续轮

## 1. 用户想法

- 生物可类比为函数：外界刺激（输入）→ 反应（输出）
- 刺激种类繁多 → 需要**硬编码底层信号转变功能**，将多种信号统一翻译成网络的语言

## 2. 生物对照：感官转导

- 每种感官有自己硬编码的分子机器：视紫红质（光）/ 毛细胞机械门控（声）/ 嗅觉受体（化学）
- **共同货币**：所有机器收敛到同一种输出——感受器电位 → 动作电位（神经编码）。
  多样性止于转导之前，统一在转导之后 → "网络语言"=神经编码（本框架：复值轨迹）
- **先天预处理**：视网膜边缘/运动检测、耳蜗频率分解——硬编码层含进化预置"滤镜"
- **可调性**：传出纤维、瞳孔、注意——转导可被顶向下调制（非纯前馈）
- 输出侧对称：肌肉 = 输出转导（动作电位→收缩力）；感觉-运动闭环

## 3. 形式化：转导层

- 输入转导 $T_{in}: s(t) \to z_{in}(t)$（实信号 → 复值网络状态）：
  $|z|$ ← 强度/速率；相位 ← 刺激时序结构；频率 ← 时间尺度
- 两级：$T = T_{\text{预处理}}$（先天特征变换）∘ $T_{\text{语言}}$（统一翻译成复值语言）
- 输出转导 $T_{out}: z_{out}(t) \to$ 行为，对称
- T 属于进化先验地形（h₀"规划书"的边界层：含各模态入海口规格）

## 4. 边界原则（化解表面矛盾）

**边界函数化，内部过程化**：
- 转导层是唯一允许硬编码函数映射的地方（"生物=函数"的直觉在边界成立）
- 网络内部（湖、河、地形）保持纯粹过程/动力学（首要动机：非函数化）
- 转导在边界连续运行，随时注入/读出（A3/A4 不受影响）

## 5. 多模态统一性

- 每个模态湖有自己特异的入海口（T 模态特异），进湖后统一为网络语言
- 多模态统一性在"网络语言"层；多样性止于转导层之前
- 与 LLM 对比：tokenizer = 文本的硬编码转导，但离散化连续时序（token 串丢相位）；
  本框架转导保留连续时序 → 结构性差异点

## 6. 山字案例衔接

文字进入 = 视觉转导（看到字形）→ 视觉湖 → 符号湖（文字湖）；书写 = 输出转导。
