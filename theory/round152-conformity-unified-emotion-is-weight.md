## 2. 统一模型：从众 = 决策环 + 高权重价值项

```
从众 = S1 决策环（R60/C59）——候选：对齐 vs 独立
  评估：Σ收益 − Σ代价
    独立代价 = 排斥风险（社会疼痛 R53——权重极高）
    对齐收益 = 归属安全（R67——社会湖价值）
  情绪 = 这些代价/利益的**感受面**（A4——同一价值信号——非独立输入）
  结果：权重差距大 → 快速收敛到对齐——"抄答案"
```

**"抄答案"的体验像"自动"——但机制是决策**：社会疼痛代价权重巨大（R53——
生存威胁级——R66 社会 = 第二生存核心）→ 候选"对齐"的价值压倒性高 →
决策快速收敛（几乎必选）——**体验为"没得选"——实为"权重差距太大"**——
与 R60 一致：自由感 = 利益接近时（权重差距小→犹豫→自由感强）——权重差距大 →
无自由感 → "自动"。

## 3. "自动感"与"进入决策"的觉知解释（R46）

**R151 的"偏差阈值 θ"现象保留——但重新解释**：

| R151 解释（已否决） | R152 解释（用户裁决） |
|---|---|
| |e| < θ = 无决策的自动对齐（环外旁路） | **决策一直在——只是收敛快——未进入觉知**（R46——觉知 = 广播内容——快速收敛未广播——体验为"自动"） |
| |e| ≥ θ = 进入决策（环内） | **决策也一直在——收敛慢（权重接近）——进入觉知**（g 分配——犹豫 = 广播中的竞争——体验为"在决策"） |

**"感觉自动" vs "感觉在决策" = 觉知（广播）的差异——不是决策与否的差异**。
"偏差大才觉得在决策" = 偏差大 → 权重接近 → 收敛慢 → g 持续关注 → 觉知广播 →
"我在想"。低偏差 = 权重差距大 → 瞬时收敛 → 未广播 → "想都没想"。

**与 R46 一致**：大部分决策在觉知外完成（无意识处理——Soon 2008 消化——R143——
决定在觉知前已作出）——"自动感" = 决策环的未广播运行。

## 4. 统一的好处

- **从众 = 单机制**（决策环）——比双机制（对齐+决策）更简——递归原则坚持

  "情绪影响深" = "该代价项权重巨大"（威胁/归属——生存级）
- **旁路级联家族收缩**：仅剩 g 失效类（恐慌/梦/幻觉——R48）——"自动对齐"不入族
- **R151 的"升级路径"修正**：不是"旁路转环"——是"未广播转广播"（觉知切换——
  与 R48 清醒梦同族：觉知部分恢复）
