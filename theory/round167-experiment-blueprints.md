## 行为实验（5 条）

### P5：觉知滞后（决策环在觉知前运行）

| 项 | 设计 |
|---|---|
| 范式 | 决策-报告时距测量：被试做简单选择（如两图选一）→ 随机延迟后报告"何时做出决定"（Libet 式）——同时记录客观决策时间（反应时） |
| 测量 | 主观报告时刻 vs 客观决策时刻的差（滞后量） |
| 对照 | 与决策难度（价值接近度——R60）的关系 |
| 框架预期 | **滞后存在且随难度增加**（简单决策未广播——滞后大；复杂决策广播——滞后小——R152 从众统一同族：觉知 = 广播） |
| 替代理论 | Libet/经典：滞后恒定或不存在 |
| 裁决 | 滞后量随难度单调变化 = 框架 |

### P16：对齐速度 ∝ 偏差倒数（情绪从众 C125 的收敛梯度）

| 项 | 设计 |
|---|---|
| 范式 | 判断任务（如数量估计）：先给被试自己的初估 → 再给"他人答案"（偏差可控 0-30%）→ 记录修正速度/幅度 |
| 测量 | 修正幅度 vs 偏差大小（收敛梯度） |
| 对照 | 偏差 0%（无修正基线） |
| 框架预期 | 修正 ∝ 1/偏差（小偏差快速收敛——大偏差犹豫——C125 θ 结构） |
| 裁决 | 修正-偏差曲线出现 θ 拐点 = 框架 |

### P17：θ 个体差异（对齐阈值可测）

| 项 | 设计 |
|---|---|
| 范式 | 同 P16——但扫描偏差递增（0→40% 步进）——每偏差点测"是否修正" |
| 测量 | 每被试的"开始犹豫"偏差点（θ——阈值） |
| 对照 | θ 与易受暗示性（催眠感受性量表）/亲和性（大五）相关 |
| 框架预期 | θ 个体差异大且与暗示性/亲和性正相关（R56 性格参数） |
| 裁决 | θ 与性格参数相关 = 框架（可同时验证 C125 的 θ = 个体参数） |

### P22：提取诱发遗忘 ∝ 记忆竞争度（RIF 梯度）

| 项 | 设计 |
|---|---|
| 范式 | RIF 范式（Anderson 1994）——但操纵目标-竞争者的**重叠度**（同类别/同属性/无关——梯度） |
| 测量 | RIF 效应量（提取目标 → 竞争者的遗忘量）vs 重叠度 |
| 框架预期 | **RIF ∝ 重叠度**（竞争抑制 R35——解释力竞争——重叠 = 竞争强度） |
| 裁决 | 梯度显著 = 框架（已兑现的 C127 引用审计中 RIF 复现稳健——实验可行） |

### P29：信念打破阈值 ∝ 固化 × 屏蔽

| 项 | 设计 |
|---|---|
| 范式 | 信念改变研究：宗教/政治信念被试——对照信息环境（同质 vs 异质——R90 确认偏误）——呈现反例（强度梯度） |
| 测量 | 信念动摇速度 vs 反例强度 × 环境封闭度 |
| 框架预期 | 打破阈值 ∝ 固化度（信念深度）× 屏蔽度（环境封闭）——强反例 + 开放环境 = 最快动摇 |
| 裁决 | 双因素交互显著 = 框架（P30 同族可合并测量认知负荷） |

## 神经实验（3 条）

### P7：多频段大湖（意识 = 跨频整合非 gamma 独有）

| 项 | 设计 |
|---|---|
| 范式 | 意识状态对比（清醒/麻醉/睡眠/冥想）——EEG 跨频相位耦合分析（theta-gamma 耦合——跨区） |
| 测量 | 跨频耦合指数（非单频 gamma）vs 意识状态 |
| 框架预期 | **意识 ∝ 跨频整合（大湖）**——麻醉下 gamma 可能保留但跨频耦合崩（P27a 同族——PCI 类） |
| 替代理论 | 单频（gamma 绑定论）预测 gamma 功率下降 |
| 裁决 | 跨频耦合区分意识 > 单频 = 框架（已有文献部分支持——theta-gamma 耦合研究） |

### P19：根激活衰减曲线（嵌套处理中根节点衰减）

| 项 | 设计 |
|---|---|
| 范式 | fMRI/EEG 嵌套句理解（"我知道你知道他……"层级控制）——追踪"根节点"激活 |
| 测量 | 根激活随时间衰减 + 断链时刻（行为上"跟丢"） |
| 框架预期 | **根激活衰减到阈值 θ_root 时行为断链**（R153——时间相关） |
| 裁决 | 衰减-断链时间相关显著 = 框架（C126 数值预测） |

### P21：脊髓损伤情绪（中央评估保留/身体性情绪减弱）

| 项 | 设计 |
|---|---|
| 范式 | 高位脊髓损伤 vs 对照——情绪诱发（图片/电影——分类：认知性 vs 身体性） |
| 测量 | 两类情绪的自评强度 |
| 框架预期 | **中央评估类情绪保留、身体性情绪（心跳/紧张感）减弱**（R53 双源——身体 = 一源非唯一） |
| 裁决 | 双源分离显著 = 框架（反詹姆斯-兰格的区分性预测） |

## 临床实验（2 条）
