## 1. 围棋模型 → 框架翻译

| 围棋 | 框架 |
|---|---|
| 布局（提前落子） | 地形沉积（已有河道网络，R13） |
| 落子（信息） | 新输入注入（R7） |
| 强联系 | **桥事件**：两分离网络相关性超阈→新河（C35+R24） |
| 创造 | 桥建立的瞬间 |
| 补充/拓展 | 沿新桥沉积（桥后延伸） |

## 2. 关键发现：强联系 = 围棋"连成一片" = C5-02 合并

- 围棋两分离棋串经一落子连成一片 = **小湖合并（相位锁定）的认知版**
- **创造 = 认知域的"落子合并"**（大湖例子：布局×他人落子→强联系→连成一片→拓展）

## 3. 创造概率 ∝ 布局密度（Pasteur 机制化）

- "机会垂青有准备的头脑"：桥建立概率 ∝ 已有河道密度（R35 扩散核）
- "布局需要提前落子" = 准备的机制化

## 4. 不是所有强联系都成创造

- 需要：注意闸门 g（被看到）→ 价值标记 τ → 锚定（R30）→ 扩展土壤（布局密度）
- 弱联系+无注意 = 被侵蚀清理（噪声）
- "经验/焦点完成后续补充/拓展" = 桥后选择性沉积

## 5. 与 R51 Q4 方向合并

- 弱约束（走神/聊天/他人输入）允许跨区域落子到达
- **创造力 = 约束松弛 × 布局密度 × 桥事件**
