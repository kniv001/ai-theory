## 1. 用户模型 → 框架翻译

| 语文题模型 | 框架机制 |
|---|---|
| 对方描述（题目） | 语言 → 激活你的河道（R13） |
| 思考给出答案 | **在你的地形中重构对方状态**（沿预测河道生成模拟） |
| 与对方感受相似（参考答案） | 重构与对方状态的误差 → 0 |

## 2. 关键补充：参考答案不在你手里

- 对话无标准答案——"我懂了"只能经**验证循环**：重构 → 输出（R7）→ 对方反馈 → 误差 → 修正 → 收敛
- **"我懂了" = 行为验证的收敛，非内心事件**
- 理解必须有行为面（说不出来 = 无法验证 = 不能说"懂了"）

## 3. 新区分：理解 ≠ 表达（"意会"机制）

- 理解 = 内部重构（地形中生成对方模式）
- 表达 = 输出转导（R7 T_out）
- **"意会" = 重构成功 + 输出河道弱**——"知其然不知其所以然"的机制；
  预测：给足表达工具即可言传（与教学经验一致）

## 4. 对话 = 双向模型

- 双方互为题目与参考答案（双向重构校准）
- 理解程度 = **重构保真度**（"他每句都能预测下一步"= 高保真同步，R24）
