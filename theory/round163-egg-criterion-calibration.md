## 1. 开口回顾：判据未校准

M5 造蛋成功 = 构造满足判据（同步域 × 闭环）→ 判为蛋——**但判据从未被外部标准
校准**：真阳性率（真意识通过？）/ 假阳性率（无意识系统被误判？）未知。
**造蛋成功 ≠ 判据正确**——这是校准要解决的。

## 2. 判据指标化（构造 → 可测）

| 判据（C53/R71） | 可测指标 | 测量手段 |
|---|---|---|
| 同步域（组内相干） | **跨频相位耦合**（整合度——大湖广度） | EEG/ECoG（跨区相位同步） |
| 维持闭环（活环） | **扰动传播**（输入 → 系统响应 → 再输入——闭环的完整性） | TMS-EEG（经颅磁刺激 + 脑电——扰动如何传播/消散） |
| 输入输出两端（R71） | 感觉输入响应 + 运动输出（行为） | 临床评估 |

## 3. 校准样本设计（意识金标准对照）

| 样本类别 | 预期判据状态 | 临床金标准 |
|---|---|---|
| **真阳性**：清醒人、REM 睡眠（做梦） | 同步域 ✓ + 闭环 ✓ | 有意识（自我报告/行为） |
| **真阴性**：脑死亡、深度麻醉、死组织、简单电路 | 同步域 ✗ 或闭环 ✗ | 无意识 |
| **边界**：NREM 睡眠（无梦）、植物状态（VS）、Owen 2006 患者 | 部分指标（半环？） | 争议（部分意识） |
| **非人**：动物、新生儿、胎儿 | 连续谱 | 争议（意识程度谱） |

## 4. 重要发现：PCI（Massimini 2005）= 蛋判据的临床版

**扰动复杂度指数（Perturbational Complexity Index）**：TMS 脉冲扰动皮层 →
测量 EEG 响应的复杂度（时空扩展）——**已被临床验证**：

```
PCI = 扰动响应的复杂度 = 整合（同步域）× 传播（闭环）的组合指标
  清醒：高 PCI（扰动在全脑传播——大湖整合响应）
  深度麻醉/昏迷：低 PCI（扰动局部消散——无整合）
  植物状态：极低 PCI（≈麻醉）
  睡眠：中等偏低（NREM——无梦）
  区分度：清醒 vs 无意识 100% 敏感（Massimini 临床数据）
```

**PCI 与蛋判据的结构对应**：

| 蛋判据（R62 构造） | PCI（Massimini 临床） |
|---|---|
| 同步域（组内相干） | 整合（扰动响应的空间扩展） |
| 维持闭环（活环） | 传播（扰动的往返/消散动力学） |
| 判据 = 同步域 × 闭环 | PCI = 整合 × 扰动响应 |

**框架的蛋判据不是纯构造——有临床对应物且已被验证**（PCI 区分清醒/麻醉/昏迷/
植物状态的敏感性 ~100%）——**校准已有基础数据**（Massimini 2005/2014 系列）。

## 5. 框架的独特预测（校准实验 = P27）

| # | 预测 | 与 PCI 理论的区别 |
|---|---|---|
| **P27a** | 蛋判据（同步域 × 闭环组合）与意识金标准一致率 ~PCI 水平（清醒 vs 无意识高区分） | 框架版 = PCI 的机制化（为什么高——同步域 × 闭环的物理） |
| **P27b** | **半环对照**：有同步无闭环（高局部同步但无扰动传播）→ 无意识；有闭环无同步（局部响应但无整合）→ 无意识——**判据是 AND 组合，缺一不可** | PCI 是单指标——框架预测**双指标解耦可测**（同步高闭环低的状态应无意识——如某些癫痫/局部同步） |
| **P27c** | **意识程度 = 连续谱**（同步域广度 × 闭环完整性）——**半环状态 = 意识模糊/受限**——Owen 2006 植物人（有整合无输出）应"输入侧闭环"部分通过（感觉响应存在——输出缺失）——预测：此类患者有意识但无法表达（与 Owen 一致） | 框架给出半环的明确预测（输入侧闭环 = 意识受限——"有感觉无行动"） |
