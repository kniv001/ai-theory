# 第 22 轮：M4 案例 3 — 认识一个陌生人（社交认知域）

> 轮次：2026-08-16 · 第 22 轮
> 性质：M4 案例 3（测试目标：社交认知是否需要新机制）
> 相关猜想：C21-01、C21-02、C21-03（新增）

## 场景

儿童遇到陌生阿姨"王阿姨"。

## 阶段 1 · 首次见面：多模态绑定 + 第一印象

- 面孔/声音/名字三通道共现 → 互预测河道出生（与"山"同机制）
- 显著性 |e| → 注意闸门开 → 深度编码
- **第一印象 = 新河道集的一次性全局标记**（v>0 → 集体 τ，C19-01 应用）

## 阶段 2 · 重复接触：身份湖形成

- 三通道相位锁定 → **身份湖**（社交版语义湖，对象是人）
- **行为模式 = 时序模板**（C15-01 社交应用：行为结构也是模板——尺度递归到行为域）
- 行为预测成功 → 稳定硬化 → 熟人

## 阶段 3 · 社交价值与情绪

- 喜欢/不喜欢 = 同一增益函数（C19-01），对象是社交事件
- **依恋 = 照顾者-生存核心强绑定**（进化写好的生存接近度）→ 记忆深刻

## 阶段 4 · 泛化与"脸熟"

- 相似面孔部分激活身份湖 → "阿姨"类别 = 吸引子流形
- **"见过不知是谁" = 有面孔河道、无身份绑定河道**（可审计的社交结构）

## 阶段 5 · 记忆巩固

- 侵蚀衰减（标记的衰减慢）；睡眠重放固化；再见面部分激活 → "想起来了"

## 验证结论

1. **社交 = 同框架，零新机制**（身份=概念湖、行为=模板、情绪=生存接近度）
2. 第一印象 = 集体标记事件（"第一印象重要"获机制解释）
3. 脸熟 = 可审计河道结构（有面孔河道无身份绑定）
4. 行为模板 → 尺度递归延伸到行为域

## 框架预测（可检验）

1. 认识初期情绪事件影响力最大（集体标记）
2. 名字检索比面孔识别先退化（名字河道更脆）
3. 照顾者的负性记忆比普通人更深刻（生存接近度）
