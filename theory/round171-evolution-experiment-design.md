## 4. 实现方案（最小生态模拟器）

```
世界：100×100 平面（连续坐标）
生物：x, y, speed, volume, satiety（饱食度）
  trade-off：speed + volume·k = 常数（体积大 → 慢；体积小 → 快）
  饱食度衰减 ∝ 体积（体积大消耗快——trade-off 的另一面）
行为（每步）：
  决策：视野内目标（食物回报 10 / 可吃生物回报 = 对方体积）——
        目标价值 = 回报/距离 × 紧迫性（饱食度低 → 紧迫性高）
  移动：朝最高价值目标（speed 决定步长）
  接触：食物 → 饱食度+；小生物 → 吃掉（对方死亡）
繁殖：饱食度 > 阈值 → 分裂（参数变异 ±10%——饱食度分摊）
死亡：饱食度 ≤ 0
统计：种群数 / 平均速度体积 / 参数演化轨迹
实验：
  exp1 基线（中等食物密度——种群存活 + 参数演化）
  exp2 食物密度效应（稀疏 → 速度优势？密集 → 体积优势？）
  exp3 捕食动力学（体积 vs 速度共存）
  exp4 参数演化轨迹（速度/体积分布随代变化）
```

  "双环反馈"的完整实现（外环选择参数 → 内环用参数做决策 → 生存结果 → 外环再选）**
