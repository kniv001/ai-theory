# 第 42 轮：多巴胺间接化 — 保存按钮，不是保存本身

> 轮次：2026-08-16 · 第 42 轮
> 提出者：用户（"多巴胺硬化河道理论可否转为间接影响"）
> 相关猜想：C38-01（新增）；C11-01 修正；重放触发缺口关闭
> 状态：多巴胺→重放→硬化链确立；OVERVIEW 开放问题全部关闭

## 1. 完整链条

多巴胺（RPE）→ ① 更新预期 ② 门控 ε ③ 标记 τ
→ τ 触发重放（睡眠/离线）→ 重复流量 → 稳定信号 → 硬化（C6-02/R41）

- 任何一步都不是"多巴胺直接改 h"——多巴胺只控制流量
- **唯一直接硬化机制 = 水流硬化**（R41）

## 2. 框架修改

- R11 的 α_tag·τ（直接硬化）**删除**，替换为：τ → 重放 → 流量 → 硬化（间接链）
- **重放触发缺口解决**：触发信号 = τ 标记（+ 睡眠窗口）——标记优先重放
- R11 + R41 + 重放（C6-03）咬合成一条链

## 3. 生物支撑

- 突触标记捕获（Frey & Morris）：结构变化由细胞机器完成，多巴胺=保存信号
- 多巴胺调节睡眠重放（标记→优先重放，有研究支持）
- 间接化不是妥协，是更准（多巴胺从不直接改突触）

## 4. 统一性论点完成态

唯一直接机制 = 水流硬化；一切调制（多巴胺/注意/调质/价值）= 流量的间接控制者。
误差（含 RPE）驱动流量、流量驱动硬化——没有第三个直接作用点。
