## 2. 三个发现

**发现 1（价值域 = A4 的主场）**：8 个价值现象全部以 **A4（价值统一）**为基座——
价值域是"价值唯一数据"（A0）的直接应用区——与认知域（A3 主场）、社会域（S1 主场）
形成三域分工：**同步面（认知）/ 决策面（社会）/ 价值面（价值）**——三面互不
重叠、互相供养。

**发现 2（价值域三模式）**：

| 模式 | 结构 | 现象 |
|---|---|---|
| **信号投影** | A4 信号 → 扩散桥 → 感知层投影 | 美/音乐（身体信号被投影到感知） |
| **状态复合** | 多层结构叠加（身体/社会/文化） | 爱/死亡认知/情绪（变量数层级） |
| **权重调节** | 价值权重参数的设置 | 生存动力/趋利重建/生存权重 |

**发现 3（生物→文化抽象 = 价值域的模式）**：美/数学（R45）/爱/死亡——**生物功能
→ 文化抽象 → 独立价值**——是价值域最常见的演化模式（R66 爱已标注，表达式证实
它在价值域普遍存在）——S6 文化转导在价值域的核心角色：**价值现象 = 身体信号
（A4）经文化层（S6）抽象化后的独立运行**。
