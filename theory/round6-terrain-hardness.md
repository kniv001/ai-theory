# 第 6 轮：环境异质可塑性 — 地形硬度、功能分块涌现与前期规划

> 轮次：2026-08-16 · 第 6 轮
> 提出者：用户（环境思考 + 前期规划补充）
> 相关猜想：C6-01 ~ C6-04
> 状态：形式化完成；稳态项数学与快环境形式化 → 第 7 轮

## 1. 用户想法

- 区域可塑性异质（易变/不易变）→ 网络单元自行进化出功能分块：硬区=长时记忆、软区=短时记忆
- **补充（中断）**：软硬区域化是后期（神经节→脑分化）现象；但前期可以做规划

## 2. 生物对照

- **CLS（McClelland 1995）**：海马=快速学习（软地形）、皮层=慢速巩固（硬地形）、
  睡眠重放=软→硬固化。用户想法独立重复了该理论。
- **元可塑性**：突触成熟（高频稳定→更难变）= 沉积压实成岩；海马终身可塑性（成年神经发生）= 基线软度
- **稳态可塑性**：防失稳的平衡力
- **前期规划（用户补充，生物事实）**：
  - 神经管早期区域化：morphogen 梯度（Shh/Wnt/BMP/FGF）在功能发生前设定脑区身份
  - 海马先天软（遗传决定）；脑干反射 = 进化硬化的先天地形（先天行为=一开始就硬）
  - **evo-devo 原则**：进化选择发育程序而非成品设计 → 规划梯度，不规划结构

## 3. 形式化

地形 $\theta = \{\gamma, \omega, W\} + \text{硬度场 } h_i$（每单元标量）：

$$\frac{dW_{ij}}{dt} = \varepsilon(h_i)\cdot e_i \cdot \overline{z_j} - \lambda(h_i)\cdot W_{ij}$$

$\varepsilon(h)$、$\lambda(h)$ 均随 $h$ 递减：**硬=难刻也难蚀**（岩石记得住，沙地留不住）。

元可塑性：

$$\frac{dh_i}{dt} = \text{稳定性信号（低误差→硬化）} - \text{新奇性信号（高误差→软化)} + \text{稳态调节（防崩塌）}$$

自增强循环（稳定→更硬→更稳定）= 功能分块的分叉机制。

**前期规划落点**：$h_0$ = 规划先验硬度场（进化程序）——
- 先天软区（学习区：感官输入湖）→ 新信息快速捕获
- 先天硬区（行为区：反射/本能）→ 无需学习即有稳定结构
- 发育/经验 = 在脚手架上细化
- **规划梯度，不规划成品** → 分块细节仍自组织（守住 C2-02 结构涌现）

## 4. 记忆 = 地形（涌现功能分块）

- 硬区：W 稳定 = 长时记忆（地形本身即记忆：河道=记录）
- 软区：W 快速流动 = 短时/工作记忆
- 固化 = 软→硬重复冲刷（巩固/重放，CLS 对应）
- 记忆是地形属性的连续谱涌现，非独立模块
- 与 LLM 差异：LLM = 全局固定权重 + 外部 KV cache；本框架 = 内建地形异质性

## 5. 陷阱预警

- 正反馈全硬崩塌 → 稳态项必需（基线软度/新奇软化）；前期规划（脚手架）降低崩塌风险但不能替代稳态项
- 硬度场初始化 = h₀ 规划的一部分（进化先验梯度）

## 6. 快环境连接

ε 双通道：慢 = 硬度 h；快 = 调质/注意（第 7 轮形式化）
