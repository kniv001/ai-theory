# 第 115 轮：问题 A 深化 — 遗忘曲线 = 软-硬耦合动力学

> 轮次：2026-08-17 · 第 115 轮
> 提出者：用户（两段：硬区不断提升 + 软区快速下降；中间软区过少时硬区提升减速）
> 相关猜想：C97-01（新增）
> 状态：遗忘曲线完整动力学确立

## 1. 用户模型 → 形式化

| 用户话 | 方程 |
|---|---|
| 软区快速下降 | dS/dt = -λ_s·S + 复习（缓存指数衰减 R18——复习 = S 补充） |
| 硬区不断提升 | dH/dt = k·S - λ_h·H（**写回速率 ∝ 软区存量**——R42 写回） |
| 中间软区过少→硬区减速 | S 耗尽 → dH/dt 变小（没缓存可写回） |

**核心耦合：写回速率 ∝ 软区存量**（dH/dt = k·S）。

## 2. 曲线三阶段

| 阶段 | 动力学 | 曲线 |
|---|---|---|
| 早期 | S 快速丢失 + H 写回量小 | 快速下降 |
| 中期 | S 少 → 写回减速 → H 提升减速 | 平缓 |
| 后期 | S 空 → 无写回 → 只剩 H 慢侵蚀（R40） | 极平缓 |

## 3. 间隔复习 = 周期补充缓存

- 复习 = S 重新填满 → 写回恢复——间隔复习 = 缓存-写回循环周期
- **集中复习问题 = S 满时写回饱和**（一次写回量有限——重复填满不增加写回——浪费）
- **间隔优于集中 = 框架的机制解释**
