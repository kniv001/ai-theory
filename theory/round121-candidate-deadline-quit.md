## 1. 用户补充 = 问题 1 的关键数据点

> "点菜确实需要想很多（如果对这件事很认真）"

这修正了问题 1 中"有时只想 2-3 个选项"的暗示——**候选数量不是固定的，是资源投入的函数**：
认真（高价值评估 v）→ 候选多；随便（低 v）→ 候选少。"认真"直接控制候选生成的深度。
这个数据点将贯穿全部三个问题（也是问题 2 截止时间的内部机制）。

## 2. 问题 1：候选从哪来？

### 直觉

点菜时你能想到的菜 = 地形中与"吃"相关河道的检索结果：吃过的好菜（R5 沉积）、看过的推荐（R42）、组合出新菜（R54 桥事件）。**候选 = 检索的输出**，不是凭空产生。

### 机制（形式化）

```
候选生成 = 注意闸门 g 引导的检索过程：
  候选数 N ≈ 搜索时间 t × 激活速率 a(t)
  a(t) 随时间衰减（强河道先激活——R85 直觉=C72-01：部分先行）
```

**两个停止条件**（决定搜索何时停）：
1. **边际收益递减**：新增候选的预期改善 < 搜索成本 → 停（经济理性）
2. **截止时间**：外部 deadline 强制停（见问题 2）

### "认真 → 想很多"的机制（用户数据点）

认真 = 决策的价值权重 v 大（R8 价值信号）→ **决策质量损失函数陡**（选错很亏）→
继续搜索的收益持续高于成本 → 搜索时间长 → 候选多。

随便 = v 小 → 质量损失函数平（选错无所谓）→ 交叉点早到 → 搜索短 → 候选少（"随便"= 快速停止）。

### "紧张时脑子一片空白"的机制

空白不是"没有候选"，是**候选通道被堵塞**：
- 紧张 = 威胁信号强（R53）→ 价值评估河道被"逃离/战斗"占道（分流饱和 R18——单河道占满流量）
- 其他候选（正常行动方案）的激活被抑制 → 检索空转 → 空白
- 恐慌极端版 = 无决策级联（R48/R59——g 失效 → 环被旁路——R120 边界）

### 与已有机制的关系

| 已有机制 | 关系 |
|---|---|
| 直觉 C72-01 | 候选生成也是部分先行（强河道先出候选） |
| 创造力 C54-01 | 候选生成 = 小规模桥事件搜索——布局密度高（专家）→ 候选多且好 |
| 注意闸门 R10 | g = 检索的聚光灯——g 集中 → 单河道深搜；g 分散 → 多河道浅搜 |

## 3. 问题 2：截止时间从哪来？

### 直觉

考试"时间到"是外部截止；但大部分决策没有铃声——你"觉得差不多了"才停。**这个"觉得"就是内部截止**：继续想的代价 > 想下去的好处。

### 机制：截止时间 = 两个成本函数的交叉

```
决策时刻 t* = 总代价最小处：
  总代价(t) = 搜索成本(t) + 决策质量损失(t)
  搜索成本上升（时间 = 稀缺资源——机会成本）
  质量损失下降（想得越久，选错概率越低）
  → 交叉点 t* = 决策时刻（继续搜索的边际收益 < 边际成本）
```

**这就是"认真"数据点的直接应用**：认真 = 质量损失函数陡 → 交叉点远 → 决策晚、候选多；
随便 = 质量损失函数平 → 交叉点近 → 决策快、候选少。**截止时间不是外部时钟，是内部成本函数——认真程度通过改变质量损失函数控制截止时刻。**

### 紧迫感 = 威胁信号注入

- 外部 deadline 临近：预测"时间不够 → 结果坏"（R49 预测失败）→ 威胁河道激活（R53）→ 继续搜索的负价值累积加速 → 交叉点提前
- **紧迫感 = 威胁项对搜索成本函数的加成**——同一交叉机制，参数被环境拉高

### 与拖延的统一（C80-01 深化）

- 拖延 = 未来威胁折扣大（当下主义 R95）→ 质量损失函数被折扣压平 → 交叉点无限远 → "现在不决策"
- deadline 前爆发 = 威胁随临近上升 → 折扣下降 → 质量损失函数回升 → 交叉点突然出现 → 决策在爆发期完成
- **拖延与截止是同一个交叉机制的两个相位**——不是"拖延是一种失败，截止是一种能力"

## 4. 问题 3：放弃决策（"算了 / 随缘 / 抛硬币"）

### 三个变体 = 同一终止条件的不同参数

| 变体 | 机制 | 触发参数 |
|---|---|---|
| "算了不想了" | 主动提前终止——评估的负价值累积（越想越烦 = 内耗 R91 成本）超过改善收益 | 搜索成本含情绪项（烦恼 = 负 v）→ 交叉点前移 |
| 抛硬币 | 随机默认——把竞争判据从"价值最大化"降级为"等概率" | 候选无法排序（价值噪声大）或价值接近（R60 自由感） |
| 随缘/掷骰子 | 外部委托——接受环境/他人决定 | 低 v（无所谓）→ 不值得评估 → 默认 |

**共同结构：决策环在"评估-竞争"环节的降级终止**——不是环的故障，是环的停止规则（终止条件被不同参数触发）。

### 抛硬币的深层机制（两件事同时发生）

1. **卸责（责任参数下调）**：硬币 = 外部代理——"让硬币决定" = 把决策外包（与 Milgram 责任转移 C94-01 同类——R101 价值扩展的镜像）。即使结果坏，"不是我的错"（责任权重低 → 负价值折扣）
2. **偏好探针（意外功能）**：硬币在空中时你瞬间的"希望是哪面" = 真实偏好的无遮蔽读取——抛之前评估河道仍在激活，期望信号（R8 RPE 的预期面）暴露真实 v。**"抛硬币帮你做决定"的机制：不是硬币决定，是硬币触发一次无遮蔽的偏好读取**——正面朝上时你失望 = 你其实想选反面（"要不要再抛一次" = 探针读数）

### 犹豫不决的人 vs 抛硬币的人（地形差异）

| 类型 | 机制 |
|---|---|
| 犹豫不决（高终止阈值） | 评估河道**分辨率不足**——所有候选都"差不多"→ 无法排序 → 无法满足终止条件（不是不想停，是停不了）；或完美主义 = 错误代价估计过高（怕选错 = 威胁过强 R53）→ 质量损失函数被恐惧扭曲 → 交叉点被推到极远 |
| 习惯抛硬币（低终止阈值） | 学会了"硬币 = 零责任"技巧（责任参数下调的习惯化 R5）——终止阈值被刻意压低 |
| 果断（正常） | 终止阈值匹配领域（专家 = 评估河道分辨率高——"一眼看出" = C72-01 强河道先行即出高置信候选——交叉点天然近） |

**自由感连接**（R60）：利益接近 → 自由感强 = 无法排序的体验面——抛硬币正是"利益接近"的极端解。

## 5. 统一：决策环的"终止动力学"补齐

R120 的五步环补齐了时间结构：

```
① 注入 → ② 候选生成（g 引导检索；停止 = 边际收益/截止）
→ ③ 评估（Σ收益−Σ代价；分辨率 = 排序能力）
→ ④ 竞争（截止 = 搜索成本×质量损失交叉；放弃 = 终止降级）
→ ⑤ 输出 → 沉积 → 参数更新 → 再循环
```

**核心洞察**：②④的停止与放弃 = **同一成本交叉机制的三个表现**（搜索成本 > 改善收益→停；
情绪成本 > 改善收益→弃；无法排序→随机）。决策环不需要"决策何时决策"的元规则——
**截止时间内生于环本身**（自终止——与 R41 关键期无独立时钟同构：水流硬化涌现出关键期，成本交叉涌现出截止）。
