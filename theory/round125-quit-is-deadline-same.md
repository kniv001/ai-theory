## 1. 用户裁定

**问题 3（放弃决策）= 问题 2（截止时间）= 同一个解释**：都是"时间代价 > 思考利益"
的评估——即元决策环的输出（C109-01）。放弃不是第三种机制，是截止的同一输出。

## 2. 统一：元决策输出空间

R124 确立：截止 = 元决策环（继续 vs 停止 vs 转向）的当下输出。
用户裁定：放弃 = 同一环的同一评估。合并：

```
元决策环（每次评估：思考利益 vs 时间代价+g 消耗——当下的）
  → 输出"继续"    = 再循环
  → 输出"停止"    = 截止（问题 2——质量损失已小于代价）
  → 输出"随机"    = 抛硬币（R121 变体 2——排序失败/价值接近时的降级输出）
  → 输出"委托"    = 随缘（R121 变体 3——不值得评估时的降级输出）
  → 输出"转向"    = 换链（R123 分配模式）
```

**R121 三变体重述**：不再是"终止条件的三个参数触发"（看起来像三机制），而是
**同一元决策环输出空间中的三个候选出口**——评估都是"时间代价 vs 思考利益"，
区别只在输出的降级方式（停止=直接终止/随机=等概率替代排序/委托=外包）。
"算了不想了"（R121 变体 1——情绪成本累积）= 思考利益为负时的"停止"输出——
与截止同出口，仅参数（情绪项加入代价）不同。

| 简化前（R121） | 简化后（R125） |

**R120 决策环的完备性**：环的输出空间 = {行动/表达/记忆/注意} ∪ {继续/停止/随机/委托/转向}——
**决策环可以输出"对自己的操作"（元决策），也可以输出"对评估的降级"（随机/委托）**。
