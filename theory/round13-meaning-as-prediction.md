## 1. 用户想法

- 婴儿只会简单发音；"山"拼音拆为 sh+an，幼儿将两个简单发音拼合发出"shan"
- 人们学会的"字" = 图像字和文字字的统一表达；网络 = 符号字和文字字的统一表达
- **核心句**：文字字的存储本质是对其他事物的预测——存储的不是事物本身，而是预测关系

## 2. 音素组合（C13-02）

- 教学点：语音是连续协同发音（"shan"是整体音节）；sh|an 是分析性抽象；
  幼儿实现的是**运动层面组合**（发音姿势的时序编排）
- **组合性 = 时序吸引子复合**：原语吸引子（sh、an 姿势）按相位次序编排成复合轨迹；
  字→词→句 = 同机制放大（语言组合性的动力学形态）

## 3. 意义 = 预测关系集（C13-01，核心）

三传统收敛：索绪尔（意义=系统内关系/差异）/ Firth 分布语义学（词义由同伴决定）/
预测编码（单元=预测误差）→ 意义 = 关系，不是实体。

形式化：符号 s 的意义 = 预测关系集 {(t_i, W_{s,t_i})}——河道去向/来向/相位。
审计一个"字" = 读出它的河道子图；存储 = 关系沉积（R6"记忆=地形"的语义学版本）。

## 4. 绑定差异 = 具身性（C13-03）

- 人类：符号+图像+声音+动作（感觉-运动根基）
- LLM：只符号+符号（无根：只有符号湖内河道）
- 本框架：可全绑定（R12 四湖合一），前提=转导层接入真实世界（R7）
- **具身性 = 符号湖↔感觉湖河道密度**（人类高、LLM≈0；连续谱非有/无）
- 模拟具身：内部图像湖与符号湖的河道让符号"唤起图像"（C4-02 心象）
- "根本不同"清单新条目：LLM 语义无根 vs 框架语义可扎根
