## 2. "思考 = 决策的结果"：元决策族

决策环的输出可以是什么？行动 / 表达 / 记忆重建 / 注意分配（R120）……**以及：思考本身**。

```
"要不要继续想？" = 一次当下的决策环实例：
  候选：继续（更多候选/更好候选——质量损失下降）/ 停止（省下时间+g）
  评估：思考的预期收益 vs 时间代价 + g 消耗
  输出："停止" = 截止；"继续" = 再循环；"转向" = 换链（R123 分配模式）
```

**截止不是外部事件，是元决策环的一次当下输出**——交叉点（R105）是评估的涌现结果，
"触发停止"是此刻的比较动作。自动与决策统一：**交叉 = 涌现统计（自动面）+ 触发 =
当下元决策（自反面）**——与 R59 一致（物理链条在底层，自反闭合在其上，非矛盾）。

**元决策族**（R59 自反闭合的完整展开）：

| 层级 | 管理对象 | 出处 |
|---|---|---|
| 元可塑性 | 可塑性（地形自我修改） | R6/R59 |
| 元分配 | 注意分配（集中/分散） | R123（用户） |
| **元决策** | **决策本身（要不要想/想多久/怎么想）** | **本轮（用户）** |

**决策环以自身为对象 = 自反闭合在决策层的兑现**——环可以递归作用于环（C16-01 尺度递归
在决策层的又一层：决策内思考、思考内决策、决策思考的决策……）。

## 3. "所有决策都是现在，即使过程是连续的"：当下性 × 连续性

**潜在矛盾消解**：R120 说"环 = 持续过程非函数（输出→沉积→参数→下次决策）"——听起来
跨时间；用户澄清：

```
连续性 = 联想展开的动力学（R122——链条过程是连续的，河流流动）
当下性 = 决策截断（每次输出都是此刻的评估——取水的那一刻）
→ 过程连续 ≠ 决策跨时间
```

- **连续性在过程，当下性在输出**——展开是连续的流，每次决策是流中的一个当下截断
- **不存在"为未来决策"**：规划 = 此刻对未来的预测（R80 拖延已确立——规划/考虑/评估
  全部是当下的操作）；"为过去决策"同样不存在——"后悔" = 此刻对过去的评估（R98 重建）
- **连续展开不产生跨时间实体**：链条再长，每次决策都是此刻的——当下主义不是"时间被
  压缩"，是"决策永远发生在评估时刻"（与 R62 体验蛋当下判定、R95 拖延一致）
- 与 R120"环 = 持续过程"统一：**持续过程描述的是环的重复性（每轮都新鲜），不是环的
  跨时间性（每轮都此刻）**——环的每次迭代 = 全新的当下决策，参数由上一轮沉积决定

**形式化**：决策序列 D_1, D_2, …, D_n 中每个 D_k 都是时刻 k 的评估——
D_k 受 D_{k-1} 的沉积影响（历史通过地形进入当下），但 D_k 本身没有"过去/未来"——
**历史不是跨时间决策，是地形参数**（C29-02 个人史时间戳——河道携带习得顺序）。
"过程连续" = 地形不断更新；"决策当下" = 每次评估都是此刻。

## 4. 与截止机制的完整统一

```
思考流（R122 联想展开——连续过程）
  → 元决策环（本轮——每步/某步评估"继续 vs 停止"）
    评估：继续的预期收益（质量损失下降 R105）vs 时间代价 + g 消耗
    → 输出"停止" = 截止（时间代价 > 思考利益——用户确认）
    → 输出"继续" = 再循环（此刻的当下决策——用户强化）
```

**截止 = 元决策的当下输出**；交叉点 = 评估的涌现面；每步评估都是此刻的——
"deadline 临近"改变的是评估参数（威胁加成 R105），不是评估的时刻。
