## 2. 刺激贫乏论证（Chomsky 核心——Poverty of the Stimulus）

### 输入"贫乏"的四个方面

| 贫乏 | 含义 |
|---|---|
| **有限** | 输入句子有限——但人能产出无限句法（生成性——递归："我知道你知道他知道……"无限嵌套） |
| **错误** | 输入含口误/语法错误/不完整句——儿童仍学会正确语法 |
| **无否定反馈** | 儿童犯错大人一般不纠正（"我走开去了"——大人不会说"语法错了"——只会纠正语义） |
| **无标注** | 输入没有语法标签（没人标注"这是名词/这是从句"） |

### 经典例子：结构依赖（structure dependence）

疑问句转换：**"The man who is tall is here"** → 疑问句应为
**"Is the man who is tall here?"**（移动主句动词 is）

错误的"就近移动"是：**"Is the man who tall is here?"**（移动从句里的 is）

- 儿童**从不**犯就近移动错误——但他们从未听过"结构依赖转换规则"的教学
- Chomsky 论证：若纯靠统计/模仿，儿童应偶尔犯就近错误（线性最近优先是更简单的规则）
- **不犯错误 = 先天知道"句法结构"（层级）而非"线性顺序"**

### 支持先天论的证据

| 证据 | 内容 |
|---|---|
| **过度规则化** | 儿童说"goed"（我 goed）而非"went"——不是模仿（从未听过）——在**生成规则**——语言 = 规则系统 |
| **关键期** | 语言习得有关键期（Lenneberg——Genie 案例：7 岁后无语言环境则终生学不会完整语法）——生物基础 |
| **普遍性** | 所有人类都有语言，只有人类有——进化产物（语言器官） |
| **尼加拉瓜手语** | 聋儿无规范输入，自创手势语且被下一代儿童**语法化**（生成复杂语法）——"贫乏输入中创生语法"——先天语法能力？ |

## 3. 经验主义的反驳

| 反驳 | 内容 |
|---|---|
| **统计学习实证** | Saffran 1996：8 个月婴儿能从连续语音流分割词（统计线索足够）——"输入不贫乏——统计信息丰富" |
| **输入并不那么差** | 母亲语（child-directed speech）简化高结构——但争议：不必要（输入质量假说） |
| **机器学习证明** | LLM 从无标注文本学到大量句法——无先天语法——但反方：LLM 训练量是儿童的百万倍——数据量差距是争议核心 |
| **UG 空洞化** | UG 的内容被不断抽空（原则-参数框架缩减）——"UG 到底含什么？"越来越模糊 |
| **跨语言差异** | 语言间差异巨大——若语法先天，先天的是什么？（普遍性 vs 参数化——UG 越来越抽象） |

## 4. 框架的中间路线（C15-01 补完路径）

**框架不需要二选一**——双环（C8：外环进化 + 内环经验）天然是中间立场：

```
纯白板（LLM 式）          框架（中间）             强先天（Chomsky）
统计学习无先验        统计学习 + 弱结构先验      具体语法规则先天
"什么都能学但数据海量"   h₀ 通用结构偏好          语言器官/UG
```

**框架的 h₀ 结构先验**（A6 进化先验——C8-03 基因记忆）：
- 不是"具体语法规则"（非 Chomsky 的结构依赖原则）
- 而是**通用时序/结构偏好**：序列预测倾向、层级组合倾向、模板化倾向——
  这些可被进化外环选择（对"可学习结构"的自然选择——C8-01 外环）
- **把先天论从"神秘语言器官"转化为"可进化的学习先验"**——先天 = h₀ 参数，
  可解释（进化可审计）、可调整（跨物种/文化差异 = h₀ 差异）

**结构依赖例子如何消化**：统计上结构依赖转换在输入中占绝对优势（主句动词
转换远多于从句动词转换）——统计可部分解释——但框架预测：**复杂层级句法需要
h₀ 结构先验**（P12——简单模板无先验可学/复杂层级需先验——可测）。

**关键期消化**：关键期 = 水流硬化涌现（R41——无独立时钟）——语言关键期 =
语法河道硬化——不是"语言器官的发育窗口"而是"通用学习机制的硬化窗口"——
Genie 案例 = 过水失败（C63 过水原则——预留河道无水流 → 退化 R40）。

## 5. 评估

- 语言先天论 = 框架 C15 的最大对手（R147 压力点）
- **框架的中间路线比两端都强**：
  - vs 强先天论（Chomsky）：h₀ 可进化可审计（不是神秘器官）；UG 空洞化问题不适用
  - vs 纯统计（LLM）：解释关键期/结构依赖/样本效率（儿童 ≈ 1/百万 LLM 数据）
- **框架的独特预测（P12）**：简单模板无先验可学（Saffran 已证）/ 复杂层级句法
  需 h₀ 结构先验——M5 可模拟裁决（无先验 vs 有 h₀ 的模板学习模拟对比）
- **结论**：C15-01 压力点 → 补 h₀ 结构先验（非修正——是 C15 的完整化）——
  框架立场明确为"统计 + 弱结构先验"中间路线
