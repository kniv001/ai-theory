# 第 53 轮：问题 3 作答 — 情绪的层级 = 变量数层级

> 轮次：2026-08-16 · 第 53 轮
> 提出者：用户（恐惧/愤怒=威胁+可控性；悲伤/快乐更早更基本）
> 相关猜想：C46-01（新增）
> 状态：情绪层级结构确立

## 1. 用户模型 → 框架翻译

| 情绪 | 变量 | 框架机制 |
|---|---|---|
| 快乐 | v>0（单） | RPE 正误差（C8-02） |
| 悲伤 | v<0（单） | RPE 负误差 |
| 恐惧 | v<0+不可控 | 威胁+不可预测（持续惊讶=R50 噪音） |
| 愤怒 | v<0+可控 | 威胁+可预测→接近倾向 |
| 社会情绪 | 3+ 变量 | 价值+可控+社会评估（自我模型） |

**情绪的层级 = 变量数层级**（复杂度提升=变量增加，底色仍生存）。

## 2. "更早更基本" = 进化第一层

- 快乐/悲伤 = RPE 两面（趋利避害，进化最古老——C8-02）
- 恐惧/愤怒需第二层评估（威胁+可控性桥，R13）
- 社会情绪需第三层（他人模型，R22）

## 3. 疼痛 = 强悲伤（研究支撑）

- 社会疼痛研究（Eisenberger）：社会排斥激活与身体疼痛相同的前扣带回——
  "心痛"字面成立（疼痛与悲伤共享底层回路）

## 4. 训练产物 = 桥的学习

- 底层（快乐/悲伤）= 身体模型直接信号（R36 天生）
- 上层 = 评估桥训练产物："怕什么"是学来的（恐惧条件化经典实验）；
  可控性评估 = 经验河道（R13）
- **情绪 = 底层价值信号（天生）× 评估桥（训练）**
