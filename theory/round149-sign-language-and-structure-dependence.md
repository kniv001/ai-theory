## 2. 要点 1：手语 = 关系转导（非先天语法"启动"）

**尼加拉瓜手语（贫乏输入创生语法）的框架解释**：

```
儿童已有：关系结构（概念/语义/事件的关系河道——C13-01——语言前已存在）
   ↓ 表达需求（A4 价值——沟通/分享）
   ↓ 转导学习（A6——运动通道——手势 = 输出的新实现）
   ↓ 结果：手势系统结构化（"语法化" = 关系映射到手势通道的统计定型）
```

- **语言的核心从来是关系**（C13-01）——不是"语法规则"——手势/语音/文字 = 关系的**输出转导**（A6 的一环——与 C17-01 符号湖同构：字形 = 视觉切割的新湖——手势 = 运动域的新通道）
- **"创生语法" = 已有关系结构找到新表达通道**——不是先天语法启动——是**关系结构的表达需求 + 转导通道的统计定型**
- 与发声语言同机制：关系 → 表达转导——只是输出通道不同（手 vs 喉）
- **语言多样性（跨语言差异——挑战 ⑦）也由此解释**：关系结构相似（人类共有概念关系）但转导通道/统计不同（不同语言 = 不同手势/语音统计）——不需要"原则-参数"（Chomsky）——**参数 = 转导层的统计差异**

## 3. 要点 2：结构依赖 = 零河道原理（关系统计）

**儿童为什么不犯"就近移动"错误**（Chomsky 最强例证）——框架回答：

```
就近移动模式：输入中**不存在**该关系模式（没有合法句子用它）
→ 零河道（无沉积 R5——没有输入就没有河道）
→ 评估中不生成该候选（C104——候选 = 联想展开——无河道无候选）
→ "不犯错误" = 关系统计的必然——非先天规则阻止
```

**与"句子简单/困难"同原理**（用户）：
- 简单句子 = 强河道（输入密集——R5 沉积深——激活快——C72 直觉先行）
- 困难句子 = 弱河道（输入稀疏——沉积浅——激活慢）
- 结构依赖转换 = 强河道（输入中唯一出现过的转换模式）
- 就近移动 = 零河道（从未出现）——**不犯 = 不存在**——与"不懂就问"的"不犯错误"同一统计机制（零河道 = 不生成）

**对刺激贫乏的回击**：Chomsky 说"儿童没听过结构依赖规则却会用"——框架答："儿童学的是**关系模式统计**（C13-01）——结构依赖转换模式在输入中反复出现（每次疑问句都在用）——河道建立——无需规则陈述"——**"规则" = 关系统计的压缩描述，不是先天内容**。
