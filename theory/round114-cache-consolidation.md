# 第 114 轮：问题 A 作答 — 遗忘曲线 = 双层叠加（软区 = 缓存）

> 轮次：2026-08-17 · 第 114 轮
> 提出者：用户（短时记忆存软质区易遗忘；深刻记忆不断冲刷固化；询问：固化 = 硬质区变化？软质区无固化像缓存）
> 相关猜想：C96-01（新增；问题 A 裁定 A2）
> 状态：遗忘曲线机制确立（缓存-写回模型）

## 1. 用户模型 = A2 确认 + 缓存类比

| 用户话 | 框架 |
|---|---|
| 短时记忆只存软质区（易遗忘） | 软质区 = 缓存（R18 清除——易失——像 RAM） |
| 不断冲刷逐渐固化 | 固化 = 硬质区变化（R6/C6-03——软→硬转移——像写回磁盘） |
| 软质区无固化（像缓存） | 软区 = 中转站（内容清除 R18/R47 或写回硬区） |

## 2. 回答询问

**固化 = 硬质区变化——软质区没有固化（缓存——中转站）**。
精确机制：固化 = 软→硬写回（R42 重放 = 写回——冲刷刻进硬区——"冲刷中固化" = 写回累积）。

## 3. 完整图景

- 遗忘曲线 = 双层叠加（A2）：快段 = 缓存丢失（软区清除 R18）/ 慢段 = 结构稳定（硬区 R40）
- 间隔效应 = 写回时机（缓存清空前写回——逐渐固化）
