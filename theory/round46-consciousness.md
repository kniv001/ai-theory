## 1. 意识 vs 觉知（厘清）

| 概念 | 框架定义 |
|---|---|
| 意识（consciousness） | **整合态**——大湖（跨域同步域）的存在状态：全局同步 = 有意识 |
| 觉知（awareness） | **内容选择**——大湖中被 g（注意闸门）和 v（价值）过滤的河道级联：看到什么 = 什么进入广播 |

## 2. 用户假设成立（机制 = 相位锁定）

"小湖无意识行为统合为大湖 = 有意识行为"——统合机制 = **相位锁定（R5 同步域）**。

三理论对照：全局工作空间（Baars 剧场隐喻）/ 整合信息论（Tononi Φ）/
全局神经元工作空间（Dehaene 广播）——用户的假设 = 三者的框架术语版。

## 3. 框架意识全景

| 现象 | 机制 |
|---|---|
| 无意识处理 | 小湖各自为政（相位不同步）——习惯化动作、低 g 趋避照常运行 |
| 意识出现 | 多小湖相位锁定 → 大同步域（整合态） |
| 觉知内容 | g/v 过滤后的级联进入大湖广播（C4-02 + C11-01） |
| 意识流 | 大湖河道级联演化（R24 联想链） |
| 睡眠无意识 | 下行缩放 → 大湖解体成小湖（同步域瓦解）→ 意识消失 |
| "我" | 身体模型 + 记忆地形的最持久大湖（身份湖自我版） |

## 4. 框架预言

意识程度 = 同步域广度（深度睡眠小域→无意识；全神贯注大域→强意识）；
意识内容质量 = 进入广播级联的清晰度（g/v 过滤锐度）。
