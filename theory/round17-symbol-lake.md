# 第 17 轮：问题 3 — 符号湖 = 视觉切割的新湖，强关联而非嵌套

> 轮次：2026-08-16 · 第 17 轮
> 提出者：用户（问题 3 作答）
> 相关猜想：C17-01（新增）
> 状态：湖间关系类型学确立（关联 vs 嵌套）

## 1. 用户作答（问题 3）

- 符号湖不是子湖，而是**新湖**
- 看到的字 = 视觉图像下切割出来的图像字；**本质仍然是图像**
- 与文字字有**强关联**

## 2. 理论对照

- **神经再利用假说（Dehaene）**：阅读=视觉系统回收利用——VWFA 位于视觉腹侧通路
  （本负责物体识别）；"字形本质是图像"与 fMRI 一致
- **文字演化史**：所有文字源自图画（象形字"山"=图画风格化）；
  书写系统演化 = 从图像切割到符号化（象形→指事→会意→形声）

## 3. 框架落点

- **符号湖 = 新湖，切割自视觉湖**："切割"机制 = 结构涌现（C2-02）视觉案例——
  高频重复图案（字形）聚类分离成独立吸引子域（功能分块 C6-01 视觉版）
- **本质视觉**：字形 = 视觉模式吸引子（图像字）
- **强关联 = 强河道**：字形湖 ↔ 语音湖/语义湖/词类湖 的强河道（文字字）
- **概念级合并**：R12 四湖合一细化为两步——域级（字形湖切割自视觉）
  → 强河道 → 概念级相位锁定合并（"山"语义湖）

## 4. 湖间关系类型学（核心区分）

| 关系 | 机制 | 例子 |
|---|---|---|
| 关联（河道） | 强河道耦合，湖保持独立身份 | 字形湖 ↔ 语言湖群 |
| 嵌套（子湖） | 从母湖生长，属于母湖 | 词类子湖 ∈ 语言湖群（R16） |

- 符号湖与语言湖群 = **关联**非嵌套（保持视觉域身份）
- 嵌套发生在域内（词类湖）；跨域是关联（字形湖↔语言）
- 框架预测：字体变体（楷/宋/手写）= 字形湖同一吸引子域变体（认字不挑字体）
