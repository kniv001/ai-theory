## 1. 用户作答（问题 2）

- 听看输入中自发记住句子结构（主谓宾）；字词先学会
- 组句 = 从名词湖等词类湖检索词 + 按学会的结构排列（顺序）
- 没见过的排列（即使错误）不影响理解，同时也会记忆
- **补充**：与"文字字"内容差不多，差别只在一个是字的关系、一个是词的关系

## 2. 理论对照

- 统计学习（Saffran 1996：8 月婴儿切分声音流）→ 结构=统计提取，非天生规则库
- 构式语法（Goldberg：结构=形式-意义配对，词填空槽）→ SVO=三槽模板
- 分布聚类（词类 = 位置聚类）→ 名词湖/动词湖

## 3. 框架映射

- **语法 = 时序模板（相位规则）**：SVO = 三槽模板（槽A名词→槽B动词→槽C名词），
  槽间相位次序；模板从句子统计中提取（C15-01）
- **词类子湖 = 分布聚类涌现**：词按位置/共现模式相位锁定成子湖（C6-01 语言版，C15-02）
- **组句 = 检索吸引子 + 模板相位编排** = 模板实例化（C13-02 正式化）
- **错误排列仍可理解**：意义=预测关系集（C13-01）→ 结构只是时序引导，
  词级预测关系照常触发；未见排列也沉积（C15-03）

## 4. 尺度递归原则（用户补充，C16-01）

**同一机制在所有尺度递归适用**：字↔字关系、词↔词关系、句结构模板 =
"预测关系集"在不同尺度的实例。后果：
1. **无需语法模块**：结构 = 更高尺度的关系（统一性论点升级：误差是唯一词汇，关系是唯一结构）
2. **语言分形性**：字→词→句→篇章，每层 = 下层组合 + 本层关系；
   对照 Chomsky 递归性 + C2-04（小湖→大湖→湖群）+ C13-02（音节→字→词）
3. 唯一差别 = 关系的对象（字吸引子 vs 词吸引子=字吸引子复合）
