# 第 65 轮：戒断与蚁行症 — 多巴胺暴跌 = 触觉闸门失效

> 轮次：2026-08-16 · 第 65 轮

## 1. 病理链（教学）

长期用药 → 多巴胺受体下调（耐受）→ 停用 → 多巴胺活性暴跌（戒断性低多巴胺态）
→ 神经兴奋性反弹（谷氨酸↑/GABA↓）→ 感觉系统异常（自发放电不被抑制）
→ **蚁行症**（触觉幻觉——"有东西在爬"）

关键：多巴胺 ≠ 快乐分子——它是**感觉门控的调质**（帕金森也有蚁行症=同一机制）。

## 2. 框架翻译

| 病理步骤 | 框架机制 |
|---|---|
| 多巴胺暴跌 | 调质广播失效（R10/R42 间接化） |
| 感觉闸门失控 | 闸门 g 失效（触觉噪声不再被抑制） |
| 触觉噪声进入 | 无约束级联（R48） |
| "有东西在爬" | 触觉幻觉 = 无约束级联触觉域实例（R56） |

**蚁行症/幻听/精神分裂幻觉 = 同一机制（闸门失效无约束级联）不同感觉域**——
幻觉不是精神疾病专利，是门控失效的普遍后果。

## 3. 漂亮推论：幻觉为什么"真实"

- 触觉河道真的被激活（噪声级联 → 身体信号 → 体验侧）——患者真去抓皮肤
- **"虚假的激活 = 真实的体验"**（R55：激活=体验——无论来源真假——
  这就是梦真、幻觉真、蚁行症痒的原因）

## 4. 回到成瘾（问题 2）

- 成瘾 = **门控者（多巴胺系统）被劫持**——药物垄断流量+标记（R42 供水）→
  其他河道断水萎缩（R18）→ 地形被单一河道占领
- 停用 = 劫持者撤走 → 门控失稳（暴跌）→ 全身级联失控
  （焦虑=威胁桥 R53 / 蚁行=触觉闸门 / 痉挛=运动闸门）
- **戒断 = 地形重建期**（萎缩河道重新供水——难熬的原因）
