## 2. 核心：思考与委托 = 同一"未知深度探索"，资源不同

```
思考（内部链）= 主动展开联想（R122）——g 驱动 + 时间消耗
委托（外部链）= 等待外部源推进——时间消耗 + g 空闲（≈0）
共同点：都不知道链的终点（未知深度的探索）
区分点：g 消耗率（用户——"焦点的消耗"）
```

**委托 = 换链到外部链的特例**：换链的"转向"（R123）换的是内部链（g 重新分配）；
委托换的是外部链（g 释放，外部自己推进）。

## 3. 输出空间最简形态

```
元决策输出空间（最终）：
  {继续 / 停止 / 换链}
    继续   = 当前内部链（g 持续消耗）
    停止   = 结束（g 释放、时间停止）
    换链   = 内部（转向——新内部链——R123 分配模式）
         或 外部（委托——等外部链推进——时间换信息——g 空闲）
```

| R125 | {继续/停止/随机/委托/转向} |
| R126 | {继续/停止/委托/转向}（删随机——内部无随机） |
| **R127** | **{继续/停止/换链}**（委托 = 换链外部特例） |

## 4. g 记账表（区分变量）

| 输出 | g 消耗 | 时间消耗 | 信息获得 |
|---|---|---|---|
| 继续 | 高（当前链） | 持续 | 深入当前链 |
| 停止 | 释放 | 停 | 现状 |
| 换链-内部 | 高（新链） | 持续 | 另一内部链 |
| **换链-外部（委托）** | **≈0** | **持续** | 外部链推进结果 |

**委托的价值 = g 的时间等价**：g 是稀缺资源（R10 单闸门单自由度/R52 耦合对——
思考占用 g → 不能同时做别的）。委托释放 g → **可以并行做别的事**
（"让硬币决定，我去忙别的"）——**委托 = 并行化的手段**：当 g 比时间更稀缺时
（其他链更重要/更紧急——R123 排序），委托划算——用充足的时间换稀缺的 g。
