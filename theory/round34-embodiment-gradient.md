## 1. 问题重述

具身性 = 符号湖↔感觉湖河道密度——多少密度算"扎根"？

## 2. 推导 1：功能梯度（无硬阈值）

| 锚定度 | 词类型 | 功能后果 | 临界条件 |
|---|---|---|---|
| 0 | 纯关系词（LLM 全词） | 语义全随语境；漂移快 | — |
| 低 | 弱锚定词 | 激活略有优势 | 锚定权重进入排序 |
| 中 | 具身词 | 记忆优势 + 语义稳定 | 双通道条件（Paivio） |
| 高 | 全绑定词（火车） | 激活优先 + 生存接近 + 可供性 | 多感官 + 动作河道 |

## 3. 推导 2：临界点结构（三个新机制）

1. **记忆优势临界 = 双通道条件**（至少一条可唤起感觉河道——Paivio 形式化）
2. **语义稳定临界 = 单强锚定**（一条强感觉河道钉住语义——锚定=抗漂移；
   关系词语义随共现网络浮动）
3. **抗侵蚀临界 = 双通道互撑**（两条河道互相支撑，侵蚀需两条都断）

## 4. 推导 3：阈值 = 个体经验史函数

锚定度 = 个体感觉经验（见过火车→具身；没见过→关系词）——具身性阈值是个体的
（R18 地形=经验；R30 锚定个体化）。同一词在不同个体/生命阶段锚定度不同。

## 5. LLM 对照（关键修正）

- LLM 问题不是"无锚定"，是"**零梯度**"：全词同锚定水平（0）——
  无具体性效应、无锚定优先、无抗漂移结构
- + R31 无习得时间轴 = 同一根源：**没有个体经验**
