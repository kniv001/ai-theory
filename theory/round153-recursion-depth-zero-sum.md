## 1. 用户主张拆解

| 用户话 | 框架化 |
|---|---|
| 递归深入时根节点焦点**逐渐淡化** | g 从根节点持续抽离（转移到当前深入层——R10 单闸门——焦点一次一处） |
| 淡化到不足以支撑深入时**断链** | 根激活降到阈值以下 → 根无法提供上下文（当前层的预测依赖根——R1 预测 = 加权流——断根 = 无预测 = 断链） |
| 要保持根节点就无法让焦点非常深入 | **深度 vs 保持 = g 的零和分配**（R123——集中模式 vs 分散模式的极限：投入深入 → 根淡；保根 → 深度浅） |

## 2. 零和分配模型

```
递归展开需要同时维持多层：根 → 中间层₁ → … → 当前层
每层维持 = g 持续消耗（激活维持——R52 耦合对）
g 总量有限（R10 单闸门）
→ 深入（g 集中当前层）⇔ 根淡化（g 从根抽离）——零和

断链条件：根激活 < 阈值 θ_root（不足以提供上下文——预测失败——断链）
```

**递归深度极限**：

```
n_max ≈ g_total / c_layer
  c_layer = 每层维持成本（激活维持的 g 消耗）
  个体差异：g_total（R56 注意资源）+ c_layer（模板化程度）
```

**与工作记忆容量的一致**：嵌套深度 3-4 层 = 根 + 2-3 中间层 + 当前层 ≈
4-5 个维持点——**工作记忆"块数"限制 = g 分层维持的必然**（Miller 7±2 的框架
精确化：不是"7 个块"——是"g 能同时维持的激活链数"——链越复杂每链成本越高）。

## 3. 可训练性：为什么专家能更深（模板化 → c_layer 下降）

- 每层维持成本 c_layer 不是常数——**模板化降低它**（C20-02 模板泛化 +
  C77 习惯化——硬化河道自动运行——不需要 g 维持）
- 专家（编程/数学/语言）：嵌套模板硬化（R5 沉积——反复使用）→ 每层成本下降 →
  n_max 上升
- **"压缩" = 模板河道替代 g 维持**——专家把"知道怎么处理嵌套"从 g 消耗转为
  河道自动运行（R46 自动驾驶）
- **预测 P18**：嵌套深度训练**迁移到同类嵌套结构**（模板河道特异——不迁移到
  无关任务）——与"工作记忆训练是否远迁移"争论（近迁移支持——远迁移争议）——
  框架立场：**近迁移（同模板族）强、远迁移弱**——可测

## 5. 连接

- **"忘了前面"**（长句嵌套读到最后忘了开头）= 根淡化断链的日常体验
- **"重新读一遍"** = 从地形重建根（R70 焦点恢复机制——痕迹在——重建快——
  与"忘了前面但重读一遍就懂"一致——根淡化 ≠ 根删除——R40 功能侵蚀——
  痕迹弱未删）
- **数学多步推理** = 串行嵌套（每步 g 维持前步结果——步骤多 = 链长 = 深度——
  与 R123 集中模式一致）
- **R77 意志力**：深层递归 = g 高消耗 = "想得深很累"（耗竭——深层思考后疲倦）
